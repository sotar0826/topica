# 答案作成・条文読解ガイド Implementation Plan

**Goal:** 「法律 答案 書き方」「条文 読み方」の検索意図に単独で答える学習ガイド2本を追加し、既存の326教材・70判例へ読者を案内する。

**Architecture:** 既存の `column` コレクションとArticleテンプレートを再利用する。新規ガイド専用の成果物監査をビルドチェーンへ追加し、本文量・構成・確認問題・内部リンク・検索/広告公開設定を継続的に保証する。トップと既存ガイドから文脈に合う入口だけを追加し、ナビ全体は変更しない。

**Tech Stack:** Astro 6.4.6、Markdown content collections、Node.js ESM、Pagefind、`@astrojs/sitemap`

## Quality Constraints

- 各ガイドは可視本文2,500字以上、h2 6個以上、確認問題2問以上、内部リンク8本以上とする。
- 一般論と実践手順を中心にし、特定の試験で必ず得点できるとの保証や個別事件への法的助言はしない。
- 条文例は現行e-Gov法令、答案例はサイト内で解説済みの民法・行政法の基本論点だけを使う。
- canonical、Article構造化データ、Pagefind本文指定、AdSense、サイトマップ収録をビルド成果物で監査する。
- サブエージェントは使わず、ユーザーの継続実装・公開の事前承認に基づいてmain上で実行する。
