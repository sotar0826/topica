# 民訴・会社法重要判例3件 Implementation Plan

**Goal:** 既存教材で繰り返し扱っているのに個別ページがなかった民事訴訟法2件・会社法1件を、事案、判旨、判断構造、射程、答案での使い方まで備えた判例解説として公開する。

**Target Cases:**

1. 貸出稟議書・自己利用文書決定（最決平成11年11月12日、courtsId 52281）
2. 入会権確認訴訟・固有必要的共同訴訟判決（最判昭和41年11月25日、courtsId 53682）
3. 非公開会社の特別決議欠缺と新株発行無効判決（最判平成24年4月24日、courtsId 82215）

**Architecture:** 裁判所公式の事件情報・裁判要旨と、抽出に成功した場合だけ公式PDF全文を一次資料とする。個別解説を `hanrei`、全文を `zenbun` コレクションへ置き、公開判定は既存の `INDEXABLE_HANREI_SET` に統合する。対象3件専用の成果物監査を追加し、百選級の構成と検索公開設定を継続的に保証する。

## Quality Constraints

- 各解説は可視本文3,200字以上、h2 8個以上とし、事実、訴訟経過、判旨、判断構造、射程、答案での使い方、関連トピックを含める。
- 判決文の引用は公式PDFまたは裁判所公式裁判要旨にある文言だけとし、引用と解説を明確に分ける。
- 旧法下の事件は、判決当時の規律と現行法上の位置付けを区別する。
- PDF抽出が文字化け判定で失敗した事件は全文ページを作らず、公式裁判要旨の範囲で記述する。
- 解説ページだけをindex・広告・Pagefind・sitemap対象とし、公式全文ページはnoindex・広告なし・検索/サイトマップ除外を維持する。
- サブエージェントは使わず、ユーザーの継続実装・公開の事前承認に基づいてmain上で実行する。
