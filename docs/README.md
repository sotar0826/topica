# docs/ — セッション間共有フォルダ

複数の Claude セッション（Code / Cowork / Chat）を横断して、進捗・決定事項・コンテキストを共有するための置き場。  
**セッションの人格をまたいでも齟齬が出ないよう、ここのファイルを「唯一の正」とする。**

---

## 🚦 セッション開始時にやること（必須）

1. **`docs/SESSION_NOTES.md` を読む** — 直近の進捗・「次にやること」・オープン事項を把握する
2. 必要に応じて **`docs/ROADMAP.md`**（全体計画）と **`../HANDOFF.md`**（恒久仕様）を参照する
3. 今日のフォーカスをユーザーと擦り合わせる

## ✍️ セッション終了時にやること（必須）

1. **`docs/SESSION_NOTES.md`** の「直近セッションログ」先頭に今日のエントリを追記する
2. 「オープン事項」を更新（解決済みを削除・新規を追加）
3. トピックを完成・デプロイした場合は **`../HANDOFF.md`** §5「現在の進捗」も更新する

> 迷ったら「次に別のセッションが読んだとき、これで再開できるか？」を基準に書く。

## 📂 ファイル一覧と役割

| ファイル | 役割 | 更新頻度 | 権威 |
|---|---|---|---|
| `docs/README.md`（本ファイル） | 共有フォルダの使い方・規約 | 規約変更時のみ | 運用ルールの正 |
| `docs/SESSION_NOTES.md` | ローリングログ（進捗・決定・引き継ぎ） | **毎セッション** | 直近状況の正 |
| `docs/ROADMAP.md` | 今後の計画（5論点：記事WF・外見・UI・SEO・運用） | 方針変更時 | 計画の正 |
| `../HANDOFF.md`（リポジトリ直下） | 恒久仕様（環境・アーキ・執筆方針・現在の進捗表） | 仕様・進捗変更時 | 確定仕様の正 |
| `../CLAUDE.md`（リポジトリ直下） | Code セッションに自動読込される最重要指示。冒頭で本フォルダへ誘導 | 方針変更時 | — |

## 🧭 どこに何を書くか（振り分けルール）

書く内容に迷ったら下表で判断する。

| 書きたいこと | 置き場所 |
|---|---|
| 「前回どこまでやったか」「次に何をするか」 | `SESSION_NOTES.md`（直近ログ） |
| 「この方針でいくと決めた」（一度決めたら覆さない） | `SESSION_NOTES.md`（決定事項）→ 恒久化したら `HANDOFF.md` |
| 未解決・判断待ちの論点 | `SESSION_NOTES.md`（オープン事項） |
| 中長期の計画・アイデア | `ROADMAP.md` |
| 環境・コマンド・アーキテクチャの確定仕様 | `HANDOFF.md` |
| 執筆スタイルの確定ルール | `../CLAUDE.md` / `HANDOFF.md` §4 |

## ⚠️ セッション種別ごとの注意

- **Code セッション**：`CLAUDE.md` が自動で読み込まれるので、その誘導に従い開始時に本フォルダを読む。ファイルの読み書き可。
- **Cowork（ファイル・調査エージェント）**：リポジトリに接続していれば読み書き可。開始時にこのフォルダを読む。調査結果は `SESSION_NOTES.md` かスタブファイルに残す。
- **Chat（claude.ai の通常チャット）**：ローカルファイルに**アクセスできない**。この場合は、ユーザーが `SESSION_NOTES.md` の中身を貼り付けるか、Cowork/Code 経由で共有する。Chat 側で決めたことは、後続の Code セッションで必ず `SESSION_NOTES.md` に書き戻す。

## 原則

- **1つの事実は1箇所に書く**（同じ情報を複数ファイルに重複させない。重複したら権威列に従って片方をリンクにする）
- **決定は追記、状況は上書き**（決定事項は履歴として積む。進捗状況は最新で上書きする）
- **書いてからデプロイ、デプロイしたら書く**（作業とノート更新をセットにする）
