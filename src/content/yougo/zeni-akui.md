## 意味

法律用語としての善意とは、ある事実を**知らないこと**をいい、悪意とは、ある事実を知っていることをいいます。日常用語のように道徳的な善し悪しや、相手を害する意図の有無を意味するものではありません。たとえば94条2項の「善意の第三者」とは、当事者間の意思表示が虚偽表示であることを知らなかった第三者のことです。

善意・悪意が問題となるのは、主として「権利の外観を信頼した者を保護するかどうか」を決める場面です。事情を知らずに取引に入った者は保護に値し、事情を知りながら取引に入った者は保護に値しないという価値判断が、各条文の要件として表現されています。

> **端的にいうと**：善意は「知らない」、悪意は「知っている」という認識の有無を表す言葉であり、倫理的評価は含まない。

## 条文ごとの主観的要件

保護を受ける者に要求される主観的要件は、条文ごとに異なります。善意だけで足りるのか、無過失まで必要なのかを正確に区別することが重要です。

| 条文 | 場面 | 要求される主観 |
|---|---|---|
| 93条2項 | 心裡留保の無効と第三者 | 善意 |
| 94条2項 | 虚偽表示の無効と第三者 | 善意 |
| 95条4項 | 錯誤取消しと第三者 | 善意かつ無過失 |
| 96条3項 | 詐欺取消しと第三者 | 善意かつ無過失 |
| 109条・112条 | 表見代理の相手方 | 善意かつ無過失（過失があれば保護されない） |
| 162条2項 | 10年の取得時効 | 占有開始時に善意かつ無過失 |
| 192条 | 即時取得 | 善意かつ無過失 |

善意だけで保護される場面は、真の権利者側の帰責性が大きい場合（自ら虚偽の外観を作出した虚偽表示など）です。帰責性が小さくなるほど、保護を受ける側にも無過失が要求されるという関係にあります。無過失の意味については[過失・無過失](/yougo/kashitsu-mukashitsu/)で整理しています。

🎯 **試験で狙われる**：94条2項は「善意」のみ、95条4項・96条3項は「善意でかつ過失がない」と規定されています。この違いは短答式で頻出であり、改正前の96条3項が「善意」のみを要件としていた点とあわせて問われることがあります。

## 善意の推定と立証責任

占有者は、所有の意思をもって、善意で、平穏に、かつ、公然と占有をするものと推定されます（186条1項）。したがって、取得時効や即時取得の場面では、占有者の善意は推定され、相手方が悪意を立証しなければなりません。

もっとも、186条1項は無過失までは推定していません。10年の取得時効（162条2項）を主張する者は、自ら無過失を立証する必要があると解されています。他方、即時取得（192条）については、前主の占有に権利の推定（188条）が働くことから、取得者の無過失も推定されるとするのが判例です。

⚠️ **つまずきやすい**：同じ「善意かつ無過失」が要件であっても、無過失の立証責任の所在は取得時効と即時取得とで異なります。条文だけでなく推定規定との関係まで押さえる必要があります。

## 悪意の特殊な類型

### 背信的悪意者

177条の「第三者」については、判例上、善意・悪意を問わないとされています。単に先行する物権変動を知っていたにすぎない悪意者は、登記を備えれば保護されます。ただし、登記の欠缺を主張することが信義に反すると認められる事情がある背信的悪意者は、177条の第三者から除外されます。取得時効との関係で背信的悪意者の認定基準を示したものとして、[最判平成18年1月17日](/hanrei/haishinteki-akuisha-h18/)があります。

### 悪意の受益者

不当利得では、法律上の原因がないことを知っている受益者（悪意の受益者）は、受けた利益に利息を付して返還しなければならず、なお損害があるときはその賠償責任も負います（704条）。善意の受益者は、利益の存する限度で返還すれば足ります（703条）。

## 具体例で確認

**設例**：Aは、債権者からの差押えを免れるため、Bと通謀して自己所有の土地をBに仮装譲渡し、B名義の登記をした。Bは、この土地を事情を知らないCに売却した。

1. AB間の売買は、相手方と通じてした虚偽の意思表示であり、無効です（94条1項）。
2. もっとも、この無効は善意の第三者に対抗することができません（94条2項）。Cは、仮装譲渡を前提として新たに土地を譲り受けた者であり、94条2項の第三者にあたります。
3. 94条2項は「善意」のみを要件としており、Cが仮装譲渡を知らなかったことについて過失があったとしても、Cは保護されます。また、判例上、Cが保護されるために登記を備えている必要もありません。

これに対し、設例が「AがBの詐欺によって土地を売却した」という事案であれば、Aの取消しに対してCが保護されるには、善意に加えて無過失であることが必要です（96条3項）。事案の類型によって、同じ「事情を知らない第三者」でも保護の要件が変わる点を確認しておきましょう。

## 区別したい用語

| 用語 | 違い |
|---|---|
| 善意 | 事実を知らないこと。知らないことについての過失の有無は問わない |
| 善意無過失 | 知らず、かつ知らないことに過失がないこと |
| 悪意 | 事実を知っていること。害意の有無は問わない |
| 背信的悪意者 | 悪意に加えて、登記の欠缺を主張することが信義に反する事情がある者 |
| 故意（709条） | 不法行為の故意は権利侵害の結果を認識しつつあえて行為することをいい、善意・悪意とは別の概念 |
