## このページで学ぶこと

- 無効と取消しの違い、取消権者と追認の要件を確認します
- 法定追認の事由と、取消権の期間制限を整理します
- ゴール：条件の成就を妨げた場合の扱い、期限の利益の喪失事由を説明できるようになる

> **端的にいうと**：無効は初めから効力がなく、取消しは取り消されるまでは有効で取り消されると遡って無効になります。取り消すことができる行為は、追認や法定追認によって確定的に有効となり、取消権は追認できる時から5年・行為の時から20年で消滅します。

## 無効と取消し

| | 無効 | 取消し |
|---|---|---|
| 効力 | 初めから効力を生じない | 取り消されるまでは有効。取り消されると初めから無効であったものとみなす（121条） |
| 主張できる者 | 原則として誰でも | 取消権者に限る（120条） |
| 追認 | 追認によっても効力を生じない。当事者が無効であることを知って追認したときは、新たな行為をしたものとみなす（119条） | 追認により確定的に有効となる（122条） |
| 期間制限 | なし | 追認できる時から5年、行為の時から20年（126条） |
| 例 | 意思無能力、公序良俗違反、虚偽表示 | 制限行為能力、錯誤、詐欺、強迫 |

## 取消権者（120条）

1. 行為能力の制限によって取り消すことができる行為：**制限行為能力者**（他の制限行為能力者の法定代理人としてした行為にあっては、当該他の制限行為能力者を含む）又はその**代理人、承継人**若しくは**同意をすることができる者**
2. 錯誤、詐欺又は強迫によって取り消すことができる行為：瑕疵ある意思表示をした者又はその代理人若しくは承継人

制限行為能力者本人も、法定代理人の同意を得ずに単独で取り消すことができます。取消しの意思表示自体を、さらに取り消すことはできません。

## 原状回復義務（121条の2）

- 無効な行為に基づく債務の履行として給付を受けた者は、相手方を**原状に復させる義務**を負う（1項）
- 無効な無償行為に基づく債務の履行として給付を受けた者は、給付を受けた当時その行為が無効であること（取り消すことができること）を知らなかったときは、**現に利益を受けている限度**において返還の義務を負う（2項）
- 行為の時に意思能力を有しなかった者、制限行為能力者であった者は、その行為によって**現に利益を受けている限度**において返還の義務を負う（3項）

## 追認

### 追認の要件（124条）

取り消すことができる行為の追認は、**取消しの原因となっていた状況が消滅し**、かつ、**取消権を有することを知った後**にしなければ、その効力を生じません（1項）。ただし、次の場合は、状況の消滅は不要です（2項）。

1. 法定代理人又は制限行為能力者の保佐人若しくは補助人が追認をするとき
2. 制限行為能力者（成年被後見人を除く）が法定代理人、保佐人又は補助人の同意を得て追認をするとき

### 法定追認（125条）

追認をすることができる時以後に、取り消すことができる行為について次の事実があったときは、追認をしたものとみなします。ただし、異議をとどめたときは、この限りでありません。

1. 全部又は一部の履行
2. 履行の請求
3. 更改
4. 担保の供与
5. 取り消すことができる行為によって取得した権利の全部又は一部の譲渡
6. 強制執行

🎯 **試験で狙われる**：法定追認となる「履行の請求」は、取消権者の側から請求した場合です。相手方から履行を請求されたにとどまる場合は含まれないと解されています。また、法定追認は取消権を有することを知っている必要はないとするのが判例です。

## 取消権の期間制限（126条）

取消権は、**追認をすることができる時から5年間**行使しないときは、時効によって消滅します。**行為の時から20年**を経過したときも、同様です。

## 条件

| 用語 | 意味 |
|---|---|
| 停止条件 | 条件が成就した時から法律行為の効力が生ずる（127条1項） |
| 解除条件 | 条件が成就した時から法律行為の効力を失う（127条2項） |
| 既成条件 | 条件が法律行為の時に既に成就・不成就が確定している（131条） |
| 不法条件 | 不法な条件を付した法律行為、不法な行為をしないことを条件とする法律行為は無効（132条） |
| 不能条件 | 不能の停止条件を付した法律行為は無効、不能の解除条件を付した法律行為は無条件（133条） |
| 随意条件 | 停止条件付法律行為は、その条件が単に債務者の意思のみに係るときは、無効（134条） |

### 条件の成就の妨害等（130条）

- 条件が成就することによって不利益を受ける当事者が**故意にその条件の成就を妨げた**ときは、相手方は、その条件が**成就したものとみなす**ことができる（1項）
- 条件が成就することによって利益を受ける当事者が**不正にその条件を成就させた**ときは、相手方は、その条件が**成就しなかったものとみなす**ことができる（2項）

条件の成否が未定である間における当事者の権利（期待権）も、処分・相続・保存・担保することができ、相手方は条件の成就によって生ずべき相手方の利益を害することができません（128条・129条）。

## 期限

- 始期・終期：期限の到来した時から履行を請求でき（135条1項）、終期の到来した時に法律行為の効力が消滅する（135条2項）
- 確定期限・不確定期限：到来する時期が確定しているか否か

### 期限の利益（136条・137条）

- 期限は、**債務者の利益のために定めたものと推定**する（136条1項）
- 期限の利益は、放棄することができる。ただし、これによって相手方の利益を害することはできない（136条2項）

次の場合には、債務者は期限の利益を主張することができません（137条）。

1. 債務者が**破産手続開始の決定**を受けたとき
2. 債務者が担保を滅失させ、損傷させ、又は減少させたとき
3. 債務者が担保を供する義務を負う場合において、これを供しないとき

## 期間の計算（138条〜143条）

- 日・週・月・年によって期間を定めたときは、期間の**初日は算入しない**。ただし、その期間が午前零時から始まるときは、この限りでない（140条）
- 期間は、その末日の終了をもって満了する（141条）
- 期間の末日が日曜日、国民の祝日その他の休日に当たるときは、その日に取引をしない慣習がある場合に限り、期間は、その翌日に満了する（142条）
- 週・月・年の期間は暦に従って計算し、最後の週・月・年においてその起算日に応当する日の前日に満了する（143条）

⚠️ **つまずきやすい**：年齢の計算は、年齢計算ニ関スル法律により出生の日から起算します（初日算入）。民法の初日不算入の原則とは異なります。

## よくある勘違い

- ❌「無効な行為を当事者が追認すれば、行為の時に遡って有効となる」→ 追認によっても効力を生じず、無効と知って追認したときは新たな行為をしたものとみなされます
- ❌「制限行為能力者は、法定代理人の同意がなければ取消しをすることができない」→ 制限行為能力者本人も単独で取り消せます
- ❌「取消権は、行為の時から5年で時効により消滅する」→ 追認できる時から5年、行為の時から20年です
