## このページで学ぶこと

- 事務管理の成立要件と、管理者が本人に請求できるもの・できないものを確認します
- 不当利得の返還範囲を、受益者の善意・悪意で区別します
- ゴール：不法原因給付の効果と、給付があったといえる時期を判例に即して説明できるようになる

> **端的にいうと**：義務がないのに他人のために事務を管理した者は、本人に有益な費用の償還を請求できますが、報酬は請求できません。法律上の原因なく他人の財産によって利益を受けた者は、善意なら現存利益、悪意なら受けた利益に利息を付して返還しなければなりません。

## 事務管理（697条〜702条）

### 成立要件

1. **法律上の義務がない**こと
2. **他人のために**する意思があること（自己のためにする意思と併存してもよい）
3. 他人の事務を管理すること
4. 本人の意思に反すること又は本人に不利であることが明らかでないこと

### 管理者の義務

| 義務 | 内容 |
|---|---|
| 管理の方法（697条） | その事務の性質に従い、最も本人の利益に適合する方法によって管理しなければならない。本人の意思を知っているとき、又はこれを推知することができるときは、その意思に従って管理しなければならない |
| 注意義務 | 善良な管理者の注意（通説） |
| 緊急事務管理（698条） | 本人の身体、名誉又は財産に対する**急迫の危害を免れさせるため**に事務管理をしたときは、**悪意又は重大な過失**があるのでなければ、これによって生じた損害を賠償する責任を負わない |
| 通知（699条） | 事務管理を始めたことを遅滞なく本人に通知しなければならない（本人が既にこれを知っているときを除く） |
| 管理の継続（700条） | 本人又はその相続人若しくは法定代理人が管理をすることができるに至るまで、事務管理を継続しなければならない（継続が本人の意思に反し、又は本人に不利であることが明らかであるときを除く） |
| 報告・引渡し（701条） | 委任の規定（645条〜647条）が準用される |

### 管理者の権利（702条）

| 請求 | 可否 |
|---|---|
| 本人のために**有益な費用**の償還 | できる（必要費を含む）。本人の意思に反して事務管理をしたときは、本人が**現に利益を受けている限度**においてのみ |
| 本人のために負担した有益な債務の代弁済 | できる（650条2項の準用） |
| **報酬** | **できない**（特別法に定めがある場合を除く） |
| 管理中に受けた**損害の賠償** | **できない**（委任の650条3項は準用されていない） |

🎯 **試験で狙われる**：事務管理者は、費用の償還は請求できますが、報酬と損害賠償は請求できません。委任の受任者が無過失損害賠償を請求できる（650条3項）のと対比して出題されます。

事務管理は、管理者と本人の間の内部関係を規律するにとどまり、管理者が本人の名でした法律行為の効果は、当然には本人に帰属しません（本人の追認がない限り無権代理となる。判例）。

## 不当利得（703条〜708条）

### 成立要件

1. 他人の財産又は労務によって**利益**を受けたこと（受益）
2. そのために他人に**損失**を及ぼしたこと
3. 受益と損失との間に**因果関係**があること
4. **法律上の原因がない**こと

### 返還の範囲

| 受益者 | 返還の範囲 |
|---|---|
| 善意の受益者（703条） | その利益の存する限度（**現存利益**）において返還する |
| 悪意の受益者（704条） | その受けた利益に**利息を付して**返還しなければならない。なお損害があるときは、その賠償の責任を負う |

- 利得した金銭を生活費に充てた場合は、他の出費を免れたものとして現存利益があるとされる。浪費した場合は現存利益がない
- 善意の受益者が利益の存しないことの主張・立証責任を負うとするのが判例

なお、無効な行為に基づく給付の返還（給付不当利得）については、原則として原状回復義務を定めた121条の2が適用されます。

### 不当利得の特則

| 条文 | 場面 | 効果 |
|---|---|---|
| 705条（非債弁済） | 債務の弁済として給付をした者が、その時において**債務の存在しないことを知っていた**とき | 給付したものの返還を請求することができない（強制されてやむを得ず弁済した場合などは返還請求可） |
| 706条（期限前の弁済） | 債務者が、弁済期にない債務の弁済として給付をしたとき | 給付したものの返還を請求することができない。ただし、債務者が**錯誤**によってその給付をしたときは、債権者は、これによって得た**利益**を返還しなければならない |
| 707条（他人の債務の弁済） | 債務者でない者が錯誤によって債務の弁済をした場合において、債権者が善意で証書を滅失・損傷し、担保を放棄し、又は時効によってその債権を失ったとき | 弁済者は返還請求できない。弁済者は債務者に求償できる |

### 不法原因給付（708条）

**不法な原因**のために給付をした者は、その給付したものの返還を請求することができません。ただし、不法な原因が**受益者についてのみ**存したときは、この限りでありません。

| 論点 | 判例の考え方 |
|---|---|
| 「不法」の意味 | 公序良俗に反すること（単なる強行法規違反では足りない場合がある） |
| 「給付」の時期 | 未登記の建物は**引渡し**により給付があったとされる。既登記の建物は、引渡しだけでは足りず、**所有権移転登記**が必要 |
| 所有権の帰属 | 贈与が公序良俗に反し無効であっても、給付者が708条により不当利得返還請求をすることができないときは、その反射的効果として、目的物の**所有権は受贈者に帰属**する（最大判昭和45年10月21日の要旨）。給付者は所有権に基づく返還請求もできない |
| 不法性の比較 | 給付者の不法性が受益者の不法性に比べて極めて微弱な場合には、返還請求が認められる |
| 返還の特約 | 給付後に当事者間で任意に返還する旨の合意をすることは有効 |

⚠️ **つまずきやすい**：708条によって返還請求できないのは「給付」が完了した場合です。既登記不動産については登記移転までされて初めて給付があったとされるため、引渡しのみの段階では、給付者は返還を請求できます。

### 転用物訴権

契約の相手方から利益を受けた第三者に対して、契約の給付をした者が不当利得の返還を請求できるかという問題です。判例は、建物賃借人から修繕を請け負った者が建物所有者に対して不当利得返還請求をした事案で、所有者が賃貸借契約全体からみて**対価関係なしに**利益を受けたときに限り、所有者が法律上の原因なくして利益を受けたといえるとしています（最判平成7年9月19日の要旨）。

## よくある勘違い

- ❌「事務管理者は、本人に対して相当の報酬を請求することができる」→ 報酬は請求できません
- ❌「悪意の受益者は、現存利益の限度で返還すれば足りる」→ 受けた利益に利息を付して返還し、損害があれば賠償します
- ❌「不法原因給付をした者は、所有権に基づいて目的物の返還を請求できる」→ 判例は所有権に基づく返還請求も否定しています

## 確認問題

<details>
<summary>【○×】管理者は、本人のために有益な費用を支出したときは、本人に対し、その償還を請求することができる。</summary>

**答え：○**
702条1項のとおりです。
</details>

<details>
<summary>【○×】事務管理者は、事務管理によって自己に過失なく損害を受けたときは、本人に対しその賠償を請求することができる。</summary>

**答え：×**
委任の650条3項は事務管理に準用されていないため、損害賠償は請求できません。
</details>

<details>
<summary>【○×】債務の弁済として給付をした者は、その時において債務の存在しないことを知っていたときは、その給付したものの返還を請求することができない。</summary>

**答え：○**
705条の非債弁済です。
</details>

<details>
<summary>【○×】判例によれば、既登記の建物を不法原因給付として贈与した場合、引渡しがされれば、所有権移転登記がされていなくても、708条の給付があったものとされる。</summary>

**答え：×**
既登記建物については所有権移転登記が必要とされています。
</details>

<details>
<summary>【記述式】Aは、隣人Bの留守中に台風でBの家の窓ガラスが割れたため、自費で修理業者に依頼して修理させた。AはBに対して何を請求でき、何を請求できないか。40字程度で記述しなさい。</summary>

**解答例**
Aは事務管理として有益な費用の償還を請求できるが、報酬や損害賠償は請求できない。（39字）
</details>
