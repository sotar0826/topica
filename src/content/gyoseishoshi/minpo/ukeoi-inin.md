## このページで学ぶこと

- 請負の報酬の支払時期と、仕事が完成しなかった場合の割合的報酬を確認します
- 委任の当事者の義務と、任意解除・終了事由を整理します
- ゴール：請負・委任・寄託の注意義務・報酬・解除の違いを比較して説明できるようになる

> **端的にいうと**：請負は仕事の完成を目的とし、報酬は目的物の引渡しと同時に支払うのが原則です。委任は事務の処理を目的とし、無償が原則で、受任者は無償でも善管注意義務を負います。委任は各当事者がいつでも解除できます。

## 請負

請負は、当事者の一方がある**仕事を完成**することを約し、相手方がその仕事の結果に対してその報酬を支払うことを約することによって、その効力を生じます（632条）。

| 事項 | 内容 |
|---|---|
| 報酬の支払時期（633条） | 仕事の目的物の**引渡しと同時に**支払わなければならない。物の引渡しを要しないときは、仕事完成後（後払い） |
| 割合的報酬（634条） | ①注文者の責めに帰することができない事由によって仕事を完成することができなくなったとき、②請負が仕事の完成前に解除されたときは、請負人が既にした仕事の結果のうち可分な部分の給付によって注文者が利益を受けるときは、その部分を仕事の完成とみなし、注文者が受ける**利益の割合に応じて報酬を請求**できる |
| 契約不適合責任 | 売買の規定（562条〜564条）が準用される。注文者の供した材料の性質又は注文者の与えた指図によって生じた不適合については、請負人がその材料又は指図が不適当であることを知りながら告げなかったときを除き、注文者は責任を追及できない（636条） |
| 期間制限（637条） | 注文者がその不適合を**知った時から1年以内**にその旨を請負人に通知しないときは、責任を追及できない（請負人が引渡し時に悪意・重過失のときを除く） |
| 注文者の解除（641条） | 請負人が仕事を完成しない間は、注文者は、いつでも**損害を賠償して**契約の解除をすることができる |
| 注文者の破産（642条） | 注文者が破産手続開始の決定を受けたときは、請負人又は破産管財人は、契約の解除をすることができる（請負人は仕事完成後は解除不可） |

### 完成建物の所有権の帰属（判例）

| 場面 | 帰属 |
|---|---|
| 注文者が材料の全部又は主要部分を提供した場合 | 原始的に注文者に帰属 |
| 請負人が材料の全部又は主要部分を提供した場合 | 原則として請負人に帰属し、引渡しによって注文者に移転する |
| 請負人が材料を提供したが、注文者が代金の全部又は大部分を支払っている場合 | 特約があるものと推認され、注文者に原始的に帰属する |

## 委任

委任は、当事者の一方が**法律行為をすること**を相手方に委託し、相手方がこれを承諾することによって、その効力を生じます（643条）。法律行為でない事務の委託（準委任）にも委任の規定が準用されます（656条）。

### 受任者の義務

| 義務 | 内容 |
|---|---|
| 善管注意義務（644条） | 委任の本旨に従い、**善良な管理者の注意**をもって、委任事務を処理する義務を負う（有償・無償を問わない） |
| 復受任者の選任（644条の2） | 委任者の**許諾**を得たとき、又は**やむを得ない事由**があるときでなければ、復受任者を選任することができない |
| 報告（645条） | 委任者の請求があるときは、いつでも委任事務の処理の状況を報告し、委任が終了した後は、遅滞なくその経過及び結果を報告しなければならない |
| 受取物の引渡し等（646条） | 委任事務を処理するに当たって受け取った金銭その他の物を委任者に引き渡さなければならない。委任者のために自己の名で取得した権利を移転しなければならない |
| 金銭の消費（647条） | 委任者に引き渡すべき金額等を自己のために消費したときは、消費した日以後の利息を支払わなければならず、損害があるときはその賠償の責任も負う |

### 受任者の権利

| 権利 | 内容 |
|---|---|
| 報酬（648条） | **特約がなければ**、委任者に対して報酬を請求することができない。報酬を受けるべき場合には、委任事務を履行した**後**でなければ請求できない（期間によって報酬を定めたときは期間経過後） |
| 割合的報酬（648条3項） | 委任者の責めに帰することができない事由によって委任事務の履行をすることができなくなったとき、委任が履行の中途で終了したときは、既にした履行の割合に応じて報酬を請求できる |
| 成果報酬（648条の2） | 委任事務の履行により得られる成果に対して報酬を支払うことを約した場合において、その成果が引渡しを要するときは、報酬は、その成果の引渡しと同時に支払わなければならない |
| 費用の前払（649条） | 委任事務を処理するについて費用を要するときは、委任者は、受任者の請求により、その前払をしなければならない |
| 費用償還等（650条） | 必要と認められる費用を支出したときは、その費用及び支出の日以後における利息の償還を請求できる。受任者は、委任事務を処理するため自己に過失なく損害を受けたときは、委任者に対し、その賠償を請求することができる（委任者の**無過失責任**） |

### 委任の解除（651条）

委任は、各当事者が**いつでも**その解除をすることができます。ただし、次の場合には、相手方の損害を賠償しなければなりません（やむを得ない事由があったときを除く）。

1. 相手方に不利な時期に委任を解除したとき
2. 委任者が受任者の利益（専ら報酬を得ることによるものを除く）をも目的とする委任を解除したとき

委任の解除は、将来に向かってのみその効力を生じます（652条・620条）。

### 委任の終了事由（653条）

| 事由 | 委任者に生じた場合 | 受任者に生じた場合 |
|---|---|---|
| 死亡 | 終了 | 終了 |
| 破産手続開始の決定 | 終了 | 終了 |
| 後見開始の審判 | **終了しない** | 終了 |

委任が終了した場合において、急迫の事情があるときは、受任者等は、委任者等が委任事務を処理することができるに至るまで、必要な処分をしなければなりません（654条）。委任の終了事由は、これを相手方に通知したとき、又は相手方がこれを知っていたときでなければ、これをもってその相手方に対抗することができません（655条）。

🎯 **試験で狙われる**：委任者が後見開始の審判を受けても委任は終了しませんが、受任者が後見開始の審判を受けると委任は終了します。また、受任者は無償であっても善管注意義務を負います。

## 寄託

寄託は、当事者の一方がある物を保管することを相手方に委託し、相手方がこれを承諾することによって、その効力を生じます（657条、諾成契約）。

| 事項 | 内容 |
|---|---|
| 受取り前の解除（657条の2） | 寄託者は、受寄者が寄託物を受け取るまで、契約の解除をすることができる（受寄者に損害があれば賠償）。無報酬の受寄者は、書面による寄託でない場合、寄託物を受け取るまで解除できる |
| 注意義務（659条） | **無報酬**の受寄者は、**自己の財産に対するのと同一の注意**をもって、寄託物を保管する義務を負う。有償の受寄者は善管注意義務 |
| 再寄託（658条） | 寄託者の承諾を得たとき、又はやむを得ない事由があるときでなければ、寄託物を第三者に保管させることができない |
| 返還請求（662条） | 当事者が寄託物の返還の時期を定めたときであっても、寄託者は、**いつでも**その返還を請求することができる（受寄者に損害があれば賠償） |
| 受寄者からの返還（663条） | 返還の時期を定めなかったときは、受寄者は、いつでも返還をすることができる。返還の時期を定めたときは、やむを得ない事由がなければ、期限前に返還をすることができない |

## 請負・委任・寄託の比較

| | 請負 | 委任 | 寄託 |
|---|---|---|---|
| 目的 | 仕事の完成 | 事務の処理 | 物の保管 |
| 報酬 | 必須（有償） | 特約がなければ無償 | 特約がなければ無償 |
| 無償の場合の注意義務 | — | 善管注意 | 自己の財産に対するのと同一の注意 |
| 解除 | 注文者は完成前いつでも（損害賠償） | 各当事者いつでも | 寄託者はいつでも返還請求 |

## よくある勘違い

- ❌「無償の受任者は、自己の財産に対するのと同一の注意をもって委任事務を処理すれば足りる」→ 無償でも善管注意義務を負います
- ❌「委任者が後見開始の審判を受けたときは、委任は終了する」→ 委任者の後見開始は終了事由ではありません
- ❌「請負人は、仕事を完成させなかった以上、報酬を一切請求できない」→ 634条の要件を満たせば、注文者が受ける利益の割合に応じて請求できます

## 確認問題

<details>
<summary>【○×】請負人が仕事を完成しない間は、注文者は、いつでも損害を賠償して契約の解除をすることができる。</summary>

**答え：○**
641条のとおりです。
</details>

<details>
<summary>【○×】受任者は、特約がなくても、委任者に対して報酬を請求することができる。</summary>

**答え：×**
648条1項により、特約がなければ報酬を請求できません。
</details>

<details>
<summary>【○×】受任者が委任事務を処理するため自己に過失なく損害を受けたときは、委任者に過失がなくても、受任者は委任者に対しその賠償を請求することができる。</summary>

**答え：○**
650条3項のとおりです（委任者の無過失責任）。
</details>

<details>
<summary>【○×】無報酬で寄託を受けた者は、善良な管理者の注意をもって寄託物を保管する義務を負う。</summary>

**答え：×**
無報酬の受寄者は、自己の財産に対するのと同一の注意で足ります（659条）。
</details>
