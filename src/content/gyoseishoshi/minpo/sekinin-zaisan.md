## このページで学ぶこと

- 債権者代位権の要件と、代位行使できない権利（一身専属権）を確認します
- 詐害行為取消権の一般要件と、行為類型ごとの特則を整理します
- ゴール：両制度の効果（直接の支払請求、取消判決の効力）と期間制限を比較して説明できるようになる

> **端的にいうと**：債権者代位権は、債務者が自分の権利を行使しないときに債権者が代わりに行使する制度、詐害行為取消権は、債務者が財産を減らす行為をしたときに債権者がその取消しを裁判所に求める制度です。どちらも債務者の責任財産を保全するためのものです。

## 債権者代位権（423条）

### 要件

1. 債権者が自己の債権（**被保全債権**）を保全するため**必要があること**（金銭債権の保全の場合は、原則として債務者の**無資力**）
2. 債務者が自ら権利を行使していないこと
3. 代位行使する権利（被代位権利）が、債務者の**一身に専属する権利**及び**差押えを禁じられた権利**でないこと
4. 被保全債権の**期限が到来**していること（ただし、**保存行為**は期限到来前でもできる）
5. 被保全債権が強制執行により実現することのできないものでないこと

### 一身専属権の例

- 離婚請求権、認知請求権などの身分上の権利
- 名誉毀損による慰謝料請求権は、具体的な金額の請求権が当事者間で客観的に確定するまでは、代位行使の対象とならない（最判昭和58年10月6日の要旨）
- 遺留分侵害額請求権（旧遺留分減殺請求権）は、遺留分権利者がこれを第三者に譲渡するなど、権利行使の確定的意思を有することを外部に表明したと認められる特段の事情がある場合を除き、債権者代位の目的とすることができない（最判平成13年11月22日の要旨）

時効の援用権は代位行使できます（金銭債権の債権者は、債務者の資力が不足する場合、債務者に代位して他の債権者に対する債務の消滅時効を援用できるとする判例があります）。

### 行使の方法と効果

| 事項 | 内容 |
|---|---|
| 行使の範囲（423条の2） | 被代位権利の目的が可分であるときは、**自己の債権の額の限度**においてのみ行使できる |
| 直接の支払・引渡し（423条の3） | 被代位権利が金銭の支払又は動産の引渡しを目的とするものであるときは、相手方に対し、その支払又は引渡しを**自己に対してする**ことを求めることができる |
| 相手方の抗弁（423条の4） | 相手方は、債務者に対して主張することができる抗弁をもって、債権者に対抗することができる |
| 債務者の処分権限（423条の5） | 債権者が代位行使した場合でも、債務者は、被代位権利について、**自ら取立てその他の処分をすることを妨げられない**。相手方も債務者に対して履行することを妨げられない |
| 訴訟告知（423条の6） | 債権者は、被代位権利の行使に係る訴えを提起したときは、遅滞なく、債務者に対し、訴訟告知をしなければならない |

### 転用型（423条の7）

登記又は登録をしなければ権利の得喪及び変更を第三者に対抗することができない財産を譲り受けた者は、その譲渡人が第三者に対して有する登記手続又は登録手続をすべきことを請求する権利を行使しないときは、その権利を行使することができます（無資力要件は不要）。

例：A→B→Cと土地が売買されたが登記がAに残っている場合、CはBのAに対する登記請求権を代位行使できる。

⚠️ **つまずきやすい**：改正前は、債権者が代位行使に着手して債務者に通知すると、債務者は処分できなくなると解されていました。現行法では、債務者は自ら取り立てることを妨げられません。

## 詐害行為取消権（424条）

### 一般要件

1. 被保全債権が詐害行為の**前の原因**に基づいて生じたものであること（424条3項）
2. 債務者が**債権者を害することを知って**した行為であること（詐害行為・詐害意思）
3. 受益者がその行為の時において債権者を害することを**知っていた**こと
4. 財産権を目的とする行為であること（424条2項）
5. 被保全債権が強制執行により実現することのできないものでないこと

### 行為類型ごとの特則

| 類型 | 要件 |
|---|---|
| 相当の対価を得てした財産の処分行為（424条の2） | ①不動産の金銭への換価などにより、債務者において隠匿・無償の供与等の処分（隠匿等の処分）をするおそれを現に生じさせるものであること、②債務者が行為の当時、対価として取得した金銭等について隠匿等の処分をする意思を有していたこと、③受益者が債務者の隠匿等の処分をする意思を知っていたこと |
| 特定の債権者に対する担保の供与・債務の消滅に関する行為（424条の3） | ①債務者が**支払不能**の時に行われたものであること、②債務者と受益者とが**通謀して**他の債権者を害する意図をもって行われたものであること（非義務行為は支払不能になる前30日以内の行為も対象） |
| 過大な代物弁済等（424条の4） | 受益者の受けた給付の価額が消滅した債務の額より過大であるもの → 過大な部分について取消し可 |
| 転得者に対する取消し（424条の5） | 受益者に対して取消しを請求できる場合で、転得者が転得の当時、債務者がした行為が債権者を害することを知っていたとき（転得者からさらに転得した者についても同様） |

### 判例上の対象行為

| 対象となる | 原則として対象とならない |
|---|---|
| **遺産分割協議**（最判平成11年6月11日の要旨） | **相続放棄**（身分行為であり、積極的に財産を減少させる行為ではない） |
| 離婚に伴う財産分与のうち、768条3項の規定の趣旨に反して**不相当に過大**であり、財産分与に仮託してされた財産処分であると認めるに足りるような特段の事情がある部分（その限度で取消し：最判平成12年3月9日の要旨） | 相当な財産分与 |

### 行使の方法と効果

| 事項 | 内容 |
|---|---|
| 行使方法 | **裁判所に請求**しなければならない（訴えによる。抗弁による行使は不可） |
| 被告（424条の7） | 受益者又は転得者（債務者は被告とならない）。債権者は、遅滞なく、債務者に対し訴訟告知をしなければならない |
| 請求の内容（424条の6） | 行為の取消しとともに、受益者・転得者が取得した財産の返還を請求できる。返還が困難なときは価額の償還 |
| 範囲（424条の8） | 目的が可分であるときは、自己の債権の額の限度においてのみ取消しを請求できる |
| 直接の支払・引渡し（424条の9） | 金銭の支払又は動産の引渡しを求めるときは、**自己に対して**するよう求めることができる |
| 判決の効力（425条） | 詐害行為取消請求を認容する確定判決は、**債務者及びその全ての債権者**に対してもその効力を有する |
| 期間（426条） | 債務者が債権者を害することを知って行為をしたことを債権者が知った時から**2年**、行為の時から**10年**を経過したときは、提起できない |

🎯 **試験で狙われる**：詐害行為取消権は必ず訴えによって行使し、被告は受益者又は転得者です。債務者を被告とする必要はありませんが、訴訟告知をしなければなりません。認容判決の効力は債務者にも及びます。

## 債権者代位権と詐害行為取消権の比較

| | 債権者代位権 | 詐害行為取消権 |
|---|---|---|
| 行使方法 | 裁判外でも可 | 裁判所への請求が必要 |
| 被保全債権の発生時期 | 被代位権利の発生前後を問わない | 詐害行為の前の原因に基づくもの |
| 期限 | 原則として到来が必要（保存行為を除く） | 到来不要 |
| 直接請求 | 金銭・動産は可 | 金銭・動産は可 |
| 期間制限 | なし（被代位権利の時効による） | 知った時から2年・行為の時から10年 |

## よくある勘違い

- ❌「債権者代位権を行使するには、必ず裁判所に請求しなければならない」→ 裁判外でも行使できます。裁判所への請求が必要なのは詐害行為取消権です
- ❌「相続放棄は詐害行為取消権の対象となる」→ 判例は否定しています（遺産分割協議は対象）
- ❌「詐害行為取消訴訟の被告は、債務者と受益者である」→ 被告は受益者又は転得者です

## 確認問題

<details>
<summary>【○×】債権者は、被保全債権の期限が到来しない間は、保存行為であっても、被代位権利を行使することができない。</summary>

**答え：×**
保存行為は期限到来前でも行使できます（423条2項ただし書）。
</details>

<details>
<summary>【○×】債権者が被代位権利を行使した場合であっても、債務者は、被代位権利について自ら取立てをすることを妨げられない。</summary>

**答え：○**
423条の5のとおりです。
</details>

<details>
<summary>【○×】判例によれば、共同相続人の間で成立した遺産分割協議は、詐害行為取消権の対象となりうる。</summary>

**答え：○**
最判平成11年6月11日のとおりです。
</details>

<details>
<summary>【○×】詐害行為取消請求を認容する確定判決は、債務者に対してはその効力を有しない。</summary>

**答え：×**
債務者及びその全ての債権者に対しても効力を有します（425条）。
</details>
