## このページで学ぶこと

- 不動産賃貸借の対抗要件と、賃貸不動産の譲渡に伴う賃貸人たる地位の移転を確認します
- 無断譲渡・転貸の効果と、転貸借における賃貸人・転借人の関係を理解します
- ゴール：敷金の返還時期・充当、借地借家法の対抗要件、使用貸借との違いを説明できるようになる

> **端的にいうと**：賃借人が賃貸人の承諾なく賃借権を譲渡・転貸したときは、賃貸人は契約を解除できますが、背信的行為と認めるに足りない特段の事情があるときは解除できません。敷金は、賃貸借が終了し、目的物が返還された時に、未払賃料などを差し引いた残額が返還されます。

## 賃貸借の基本

- 賃貸借は、当事者の一方がある物の使用及び収益を相手方にさせることを約し、相手方がこれに対してその賃料を支払うこと及び引渡しを受けた物を契約が終了したときに返還することを約することによって、その効力を生ずる（601条、諾成契約）
- 存続期間は、**50年**を超えることができない（604条）
- 賃料は、動産・建物・宅地については**毎月末**に、その他の土地については毎年末に支払わなければならない（後払いの原則、614条）

## 対抗要件と賃貸人たる地位の移転

- 不動産の賃貸借は、これを**登記**したときは、その不動産について物権を取得した者その他の第三者に対抗することができる（605条）
- 対抗要件を備えた不動産の賃貸借の目的物が譲渡されたときは、その不動産の**賃貸人たる地位は、その譲受人に移転**する（605条の2第1項）。賃借人の承諾は不要
- 賃貸人たる地位の移転は、賃貸物である不動産について**所有権の移転の登記**をしなければ、賃借人に対抗することができない（605条の2第3項）
- 賃貸人たる地位が移転したときは、敷金の返還債務と費用償還債務は、譲受人が承継する（605条の2第4項）
- 対抗要件を備えた不動産の賃借人は、占有を妨害している第三者に対する**妨害の停止**の請求、占有している第三者に対する**返還**の請求をすることができる（605条の4）

## 賃貸人・賃借人の義務

| 事項 | 内容 |
|---|---|
| 修繕義務（606条） | 賃貸人は、賃貸物の使用及び収益に必要な修繕をする義務を負う。ただし、賃借人の責めに帰すべき事由によって修繕が必要となったときは、この限りでない |
| 賃借人による修繕（607条の2） | 賃借人が賃貸人に修繕が必要である旨を通知し、又は賃貸人がその旨を知ったにもかかわらず、賃貸人が相当の期間内に必要な修繕をしないとき、又は急迫の事情があるときは、賃借人は、その修繕をすることができる |
| 必要費（608条1項） | 賃借人は、賃貸人に対し、**直ちに**その償還を請求することができる |
| 有益費（608条2項） | 賃貸借の**終了の時**に、価格の増加が現存する場合に限り、賃貸人の選択に従い、支出した金額又は増価額を償還させることができる |
| 一部滅失等（611条） | 賃借物の一部が滅失その他の事由により使用・収益をすることができなくなった場合において、それが賃借人の責めに帰することができない事由によるものであるときは、賃料は、その割合に応じて、**減額される**（当然減額） |
| 原状回復（621条） | 賃借人は、賃借物を受け取った後にこれに生じた損傷（通常の使用・収益によって生じた損耗並びに賃借物の経年変化を除く）がある場合において、賃貸借が終了したときは、その損傷を原状に復する義務を負う |

## 賃借権の譲渡・転貸

- 賃借人は、賃貸人の**承諾**を得なければ、その賃借権を譲り渡し、又は賃借物を転貸することができない（612条1項）
- 賃借人がこれに違反して第三者に賃借物の使用又は収益をさせたときは、賃貸人は、契約の解除をすることができる（612条2項）

**最判昭和28年9月25日**（信頼関係破壊の法理）

賃借人が賃貸人の承諾なく第三者に賃借物の使用収益をさせた場合でも、賃借人の当該行為が賃貸人に対する**背信的行為と認めるに足らない特段の事情**がある場合においては、612条2項の解除権は発生しないとしました（要旨）。

### 適法な転貸借の効果（613条）

- 賃借人が適法に賃借物を転貸したときは、転借人は、賃貸人と賃借人との間の賃貸借に基づく賃借人の債務の範囲を限度として、賃貸人に対して転貸借に基づく債務を**直接履行する義務**を負う。この場合においては、賃料の前払をもって賃貸人に対抗することができない（1項）
- 賃貸人が賃借人に対してその権利を行使することを妨げない（2項）
- 賃借人が適法に賃借物を転貸した場合には、賃貸人は、賃借人との間の賃貸借を**合意により解除したことをもって転借人に対抗することができない**。ただし、その解除の当時、賃貸人が賃借人の債務不履行による解除権を有していたときは、この限りでない（3項）

賃借人の債務不履行を理由に賃貸借を解除する場合には、賃貸人は、転借人に賃料の支払の機会を与える必要はないとするのが判例です（最判昭和37年3月29日の要旨）。賃貸借が賃借人の債務不履行により解除された場合、転貸借は、原則として、賃貸人が転借人に対して目的物の返還を請求した時に、転貸人の転借人に対する債務の履行不能により終了します（最判平成9年2月25日の要旨）。

## 敷金（622条の2）

敷金とは、いかなる名目によるかを問わず、賃料債務その他の賃貸借に基づいて生ずる賃借人の賃貸人に対する金銭の給付を目的とする債務を担保する目的で、賃借人が賃貸人に交付する金銭をいいます。

| 事項 | 内容 |
|---|---|
| 返還時期 | ①賃貸借が終了し、かつ、**賃貸物の返還を受けたとき**、②賃借人が適法に賃借権を譲り渡したとき |
| 返還額 | 受け取った敷金の額から賃貸借に基づいて生じた賃借人の賃貸人に対する金銭の給付を目的とする債務の額を控除した残額 |
| 充当 | 賃貸人は、賃借人が債務を履行しないときは、敷金をその債務の弁済に充てることができる。**賃借人は、賃貸人に対し、敷金をその債務の弁済に充てることを請求することができない** |
| 賃貸人の交替 | 新賃貸人に承継される（605条の2第4項） |
| 賃借人の交替 | 適法な賃借権の譲渡があっても、特段の事情がない限り、敷金は新賃借人に承継されない（返還事由となる） |

🎯 **試験で狙われる**：敷金の返還と目的物の明渡しは同時履行の関係に立たず、明渡しが先です。賃借人は、明渡しまで敷金返還請求権を理由に留置権を主張することもできません。

## 賃貸借の終了

- 期間の定めのない賃貸借は、各当事者がいつでも解約の申入れをすることができ、土地は申入れの日から**1年**、建物は**3か月**、動産・貸席は**1日**を経過することによって終了する（617条）
- 賃借物の全部が滅失その他の事由により使用及び収益をすることができなくなった場合には、賃貸借は、これによって終了する（616条の2）
- 賃貸借の解除は、将来に向かってのみその効力を生ずる（620条）

## 借地借家法の基本

| | 借地（建物所有目的の地上権・土地賃借権） | 借家（建物の賃貸借） |
|---|---|---|
| 存続期間 | **30年**以上（これより短い定めは30年） | 1年未満の定めは期間の定めがないものとみなす |
| 更新後の期間 | 最初の更新は20年以上、2回目以降は10年以上 | — |
| 対抗要件 | 借地上に借地権者が**登記されている建物**を所有すること（10条1項） | 建物の**引渡し**（31条） |
| 更新拒絶・解約申入れ | 正当事由が必要 | 正当事由が必要。賃貸人からの解約申入れは6か月経過で終了 |
| 終了時の権利 | 建物買取請求権（13条） | 造作買取請求権（33条。特約で排除可） |

借地上の建物の登記は、借地権者本人名義でなければならず、同居の家族名義の登記では対抗要件として認められないとするのが判例です。

## 使用貸借との比較

| | 賃貸借 | 使用貸借（593条） |
|---|---|---|
| 対価 | 有償 | 無償 |
| 成立 | 諾成契約 | 諾成契約（書面によらない場合、貸主は借用物の受取りまで解除可：593条の2） |
| 通常の必要費 | 賃貸人負担 | **借主負担**（595条） |
| 借主の死亡 | 賃借権は相続される | 使用貸借は**終了**する（597条3項） |
| 対抗力 | 登記等で対抗可 | 対抗できない |

## よくある勘違い

- ❌「賃貸不動産が譲渡された場合、賃貸人たる地位の移転には賃借人の承諾が必要である」→ 対抗要件を備えた賃貸借では、承諾なく譲受人に移転します
- ❌「賃借人は、未払賃料に敷金を充当するよう賃貸人に請求できる」→ 充当を請求できるのは賃貸人側だけです
- ❌「賃貸人と賃借人が賃貸借を合意解除すれば、適法な転借人に対しても明渡しを請求できる」→ 合意解除は原則として転借人に対抗できません

**答え：○**
622条の2第1項1号のとおりです。
</details>
