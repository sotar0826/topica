## このページで学ぶこと

- 親族の範囲と、婚姻の成立要件・効果を確認します
- 嫡出推定・嫡出否認・認知のルール（2024年4月施行の改正後）を理解します
- ゴール：普通養子と特別養子の要件・効果の違いを説明できるようになる

> **端的にいうと**：婚姻は届出によって成立し、夫婦は日常の家事に関する債務について連帯責任を負います。婚姻中に懐胎した子は夫の子と推定され、推定を覆すには嫡出否認の訴えによる必要があります。特別養子縁組では、実方の父母との親族関係が終了します。

## 親族の範囲（725条）

1. **6親等内の血族**
2. **配偶者**
3. **3親等内の姻族**

親等は、親族間の世代数を数えて定め、傍系親族は、その一人又はその配偶者から同一の祖先にさかのぼり、その祖先から他の一人に下るまでの世代数によります（726条）。配偶者には親等はありません。

## 婚姻

### 成立要件

| 要件 | 内容 |
|---|---|
| 婚姻意思 | 社会通念上夫婦と認められる関係を設定しようとする意思。子に嫡出子の地位を与えるための便法として婚姻届を出したにすぎない場合は、婚姻は無効（最判昭和44年10月31日の要旨） |
| 届出（739条） | 戸籍法の定めるところにより届け出ることによって効力を生ずる |
| 婚姻適齢（731条） | **18歳**（男女とも） |
| 重婚の禁止（732条） | 配偶者のある者は、重ねて婚姻をすることができない |
| 近親婚の禁止（734条〜736条） | 直系血族・3親等内の傍系血族間、直系姻族間、養親子関係者間の婚姻の禁止 |

女性の再婚禁止期間（旧733条）は、2024年（令和6年）4月1日施行の改正により廃止されました。婚姻適齢の男女統一と成年年齢の引下げ（2022年4月施行）により、未成年者の婚姻に関する父母の同意の規定も削除されています。

### 婚姻の効果

| 効果 | 内容 |
|---|---|
| 夫婦の氏（750条） | 夫婦は、婚姻の際に定めるところに従い、夫又は妻の氏を称する |
| 同居・協力・扶助（752条） | 夫婦は同居し、互いに協力し扶助しなければならない |
| 婚姻費用の分担（760条） | 夫婦は、その資産、収入その他一切の事情を考慮して、婚姻から生ずる費用を分担する |
| 日常家事債務（761条） | 夫婦の一方が日常の家事に関して第三者と法律行為をしたときは、他の一方は、これによって生じた債務について、**連帯してその責任を負う** |
| 夫婦別産制（762条） | 夫婦の一方が婚姻前から有する財産及び婚姻中自己の名で得た財産は、その特有財産とする。帰属不明の財産は共有と推定する |

かつて置かれていた夫婦間の契約の取消権（旧754条）は、2026年（令和8年）4月施行の改正で削除されました。

**日常家事と表見代理**：判例は、761条は夫婦が相互に日常の家事に関する法律行為につき他方を代理する権限を有することをも規定しているとしたうえで、夫婦の一方が日常家事の範囲を越えて第三者と法律行為をした場合には、当然に110条の表見代理が成立するのではなく、その第三者においてその行為が当該夫婦の日常の家事に関する法律行為の範囲内に属すると信ずるにつき**正当の理由**のあるときに限り、110条の趣旨を類推して第三者を保護するとしています（最判昭和44年12月18日の要旨）。

## 離婚

| 種類 | 内容 |
|---|---|
| 協議離婚（763条） | 夫婦は、その協議で、離婚をすることができる（届出が必要）。判例は、離婚意思は届出をする意思で足りるとしている |
| 裁判離婚（770条） | 不貞な行為、悪意の遺棄、3年以上の生死不明、その他婚姻を継続し難い重大な事由があるときなどに、離婚の訴えを提起できる |

### 離婚の効果

- **財産分与**（768条）：協議上の離婚をした者の一方は、相手方に対して財産の分与を請求することができる。協議が調わないときは家庭裁判所に処分を請求できるが、離婚の時から一定期間（2026年4月施行の改正により**5年**。改正前は2年）を経過したときは請求できない
- **復氏**（767条）：婚姻によって氏を改めた夫又は妻は、協議上の離婚によって婚姻前の氏に復する。離婚の日から3か月以内に届け出ることで、離婚の際に称していた氏を称することができる
- **子の親権**：2024年（令和6年）に成立した改正法（2026年4月施行）により、離婚後も、父母の協議又は裁判所の判断によって、父母の双方を親権者とすること（共同親権）ができるようになった

## 実子

### 嫡出推定（772条、2024年4月施行の改正後）

1. 妻が**婚姻中に懐胎**した子は、当該婚姻における夫の子と推定する。女が婚姻前に懐胎した子であって、婚姻が成立した後に生まれたものも、同様とする
2. 婚姻の成立の日から**200日以内**に生まれた子は、婚姻前に懐胎したものと推定し、婚姻の成立の日から200日を経過した後又は婚姻の解消若しくは取消しの日から**300日以内**に生まれた子は、婚姻中に懐胎したものと推定する
3. 女が子を懐胎した時から子の出生の時までの間に2以上の婚姻をしていたときは、その子は、その**出生の直近の婚姻における夫の子**と推定する

### 嫡出否認

| 項目 | 内容 |
|---|---|
| 否認権者 | 父、子、母、前夫（再婚後の夫の子と推定される場合） |
| 方法 | 嫡出否認の訴え |
| 出訴期間 | 原則として**3年**（父は子の出生を知った時から、子・母は子の出生の時から など） |

妻が子を懐胎すべき時期に、夫婦が事実上離婚して別居していたなど、妻が夫の子を懐胎する可能性がないことが外観上明白である場合には、嫡出推定が及ばず（推定の及ばない子）、親子関係不存在確認の訴えによって争うことができます。判例は、DNA鑑定によって生物学上の父子関係が否定された場合であっても、外観上明白な事情がない限り嫡出推定が及ぶとしています（最判平成26年7月17日の要旨）。

### 認知（779条〜789条）

- 嫡出でない子は、その父又は母がこれを認知することができる（779条）。母子関係は分娩の事実により当然に発生するとするのが判例
- 認知は、戸籍法の定めるところにより届け出ることによってする。**遺言**によっても、することができる（781条）
- **成年の子**は、その承諾がなければ、これを認知することができない（782条）
- 父は、**胎内に在る子**でも、認知することができる。この場合においては、**母の承諾**を得なければならない（783条）
- 認知は、出生の時にさかのぼってその効力を生ずる（第三者が既に取得した権利を害することはできない：784条）
- 子、その直系卑属又はこれらの者の法定代理人は、認知の訴えを提起することができる。父又は母の死亡の日から**3年**を経過したときは、この限りでない（787条）
- 父が認知した子は、その父母の婚姻によって嫡出子の身分を取得する（婚姻準正）。婚姻中父母が認知した子も同様（認知準正）（789条）

## 養子

| | 普通養子 | 特別養子（817条の2以下） |
|---|---|---|
| 成立 | 届出（当事者の合意） | **家庭裁判所の審判** |
| 養親 | **20歳**以上（792条） | 配偶者のある者で夫婦共同。**25歳**以上（一方が25歳以上なら他方は20歳以上で可） |
| 養子 | 養親の尊属・年長者でないこと（793条） | 原則として請求時に**15歳未満** |
| 実方との親族関係 | 存続 | **終了** |
| 離縁 | 協議離縁も可能 | 原則不可（養子の利益のため特に必要な場合に家庭裁判所の審判で可能） |

### 普通養子縁組の主な要件

- 後見人が被後見人を養子とするには、家庭裁判所の許可を得なければならない（794条）
- 配偶者のある者が**未成年者**を養子とするには、配偶者とともにしなければならない（配偶者の嫡出である子を養子とする場合等を除く：795条）
- 配偶者のある者が縁組をするには、その配偶者の**同意**を得なければならない（796条）
- 養子となる者が**15歳未満**であるときは、その法定代理人が、これに代わって縁組の承諾をすることができる（代諾縁組、797条）
- **未成年者**を養子とするには、家庭裁判所の許可を得なければならない。ただし、自己又は配偶者の直系卑属を養子とする場合は、この限りでない（798条）

🎯 **試験で狙われる**：普通養子の養親は20歳以上、特別養子の養親は原則25歳以上です。未成年者を養子とする場合の家庭裁判所の許可は、自己又は配偶者の孫・連れ子を養子とする場合には不要です。

## よくある勘違い

- ❌「夫婦の一方が日常家事の範囲を超えて法律行為をした場合、当然に110条の表見代理が成立する」→ 日常家事の範囲内と信ずるにつき正当の理由がある場合に限り、110条の趣旨が類推されます
- ❌「父は、胎内に在る子を認知することができない」→ 母の承諾を得て認知できます
- ❌「特別養子縁組が成立しても、養子と実方の父母との親族関係は存続する」→ 特別養子縁組では原則として終了します
