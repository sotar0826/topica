## このページで学ぶこと

- 相続人の順位、代襲相続の原因、法定相続分を確認します
- 相続の承認・放棄の期間と効果、限定承認の手続を理解します
- ゴール：遺産分割の対象（預貯金債権）、遡及効、配偶者居住権を説明できるようになる

> **端的にいうと**：配偶者は常に相続人となり、子、直系尊属、兄弟姉妹の順で配偶者とともに相続します。相続人は、自己のために相続の開始があったことを知った時から3か月以内に、単純承認・限定承認・放棄のいずれかを選択します。

## 相続人

| 順位 | 相続人 | 代襲相続 |
|---|---|---|
| 常に | **配偶者**（890条） | — |
| 第1順位 | **子**（887条） | あり（孫、さらに再代襲あり） |
| 第2順位 | **直系尊属**（889条。親等の近い者が優先） | — |
| 第3順位 | **兄弟姉妹**（889条） | あり（甥・姪まで。再代襲なし） |

### 代襲相続（887条2項・3項、889条2項）

被相続人の子が、①相続の開始以前に**死亡**したとき、又は②**相続欠格**に該当し、若しくは③**廃除**によって、その相続権を失ったときは、その者の子がこれを代襲して相続人となります。**相続放棄**は代襲原因ではありません。

### 相続欠格（891条）と廃除（892条）

| | 相続欠格 | 推定相続人の廃除 |
|---|---|---|
| 事由 | 故意に被相続人等を死亡させ又は死亡させようとして刑に処せられた者、詐欺・強迫によって遺言をさせ・妨げた者、遺言書を偽造・変造・破棄・隠匿した者など | 被相続人に対する**虐待**、**重大な侮辱**、その他の**著しい非行** |
| 手続 | 法律上当然に相続権を失う | 被相続人が**家庭裁判所に請求**（遺言でも可） |
| 対象 | すべての相続人 | **遺留分を有する**推定相続人（兄弟姉妹は対象外） |
| 取消し | なし | 被相続人はいつでも家庭裁判所に取消しを請求できる |

## 法定相続分（900条）

| 相続人 | 配偶者 | 血族相続人 |
|---|---|---|
| 配偶者と子 | 2分の1 | 2分の1 |
| 配偶者と直系尊属 | 3分の2 | 3分の1 |
| 配偶者と兄弟姉妹 | 4分の3 | 4分の1 |

- 子・直系尊属・兄弟姉妹が数人あるときは、各自の相続分は相等しい
- 嫡出でない子の相続分は、嫡出子と同等（最大決平成25年9月4日による違憲判断を受けて2013年に改正）
- **父母の一方のみを同じくする兄弟姉妹**（半血兄弟姉妹）の相続分は、父母の双方を同じくする兄弟姉妹の相続分の**2分の1**

### 特別受益（903条）と寄与分（904条の2）

- 共同相続人中に、被相続人から遺贈を受け、又は婚姻若しくは養子縁組のため若しくは生計の資本として贈与を受けた者があるときは、その贈与の価額を相続財産に加えたもの（みなし相続財産）を基礎として相続分を算定する（持戻し）。婚姻期間が**20年以上**の夫婦の一方が他方に居住用不動産を遺贈・贈与したときは、持戻し免除の意思表示があったものと推定される（903条4項）
- 共同相続人中に、被相続人の事業に関する労務の提供、療養看護その他の方法により被相続人の財産の維持又は増加について**特別の寄与**をした者があるときは、寄与分を加えた額をその者の相続分とする
- 相続人でない被相続人の親族が療養看護等により特別の寄与をしたときは、相続人に対し、**特別寄与料**の支払を請求することができる（1050条）

## 相続の承認と放棄

### 熟慮期間（915条）

相続人は、**自己のために相続の開始があったことを知った時から3か月以内**に、相続について、単純若しくは限定の承認又は放棄をしなければなりません。この期間は、利害関係人又は検察官の請求によって、家庭裁判所において伸長することができます。

| 選択 | 内容・手続 |
|---|---|
| 単純承認（920条） | 無限に被相続人の権利義務を承継する |
| 法定単純承認（921条） | ①相続財産の全部又は一部を**処分**したとき（保存行為・短期賃貸を除く）、②熟慮期間内に限定承認又は放棄をしなかったとき、③限定承認・放棄後に相続財産を隠匿・消費等したとき → 単純承認したものとみなす |
| 限定承認（922条・923条） | 相続によって得た財産の限度においてのみ被相続人の債務及び遺贈を弁済すべきことを留保して承認する。共同相続人の**全員が共同して**のみすることができる。家庭裁判所に申述する |
| 放棄（938条・939条） | 家庭裁判所に申述する。相続の放棄をした者は、その相続に関しては、**初めから相続人とならなかったもの**とみなす |

相続の承認及び放棄は、熟慮期間内でも、撤回することができません（919条1項）。ただし、制限行為能力や詐欺・強迫などを理由とする取消しは可能です。

⚠️ **つまずきやすい**：相続放棄は各相続人が単独でできますが、限定承認は共同相続人全員でしなければなりません。また、相続放棄をした者の子は代襲相続をしません。

## 遺産分割

| 事項 | 内容 |
|---|---|
| 遺産の共有（898条） | 相続人が数人あるときは、相続財産は、その共有に属する |
| 分割の方法（907条） | 共同相続人は、被相続人が遺言で禁じた場合を除き、いつでも、その協議で、遺産の全部又は一部の分割をすることができる。協議が調わないときは、家庭裁判所に請求できる |
| 分割の禁止（908条） | 被相続人は、遺言で、相続開始の時から**5年**を超えない期間を定めて、遺産の分割を禁ずることができる |
| 効力（909条） | 遺産の分割は、相続開始の時に**さかのぼって**その効力を生ずる。ただし、第三者の権利を害することはできない |
| 金銭債権など可分債権 | 相続開始と同時に当然に法定相続分に応じて分割される（判例） |
| 預貯金債権 | 遺産分割の対象となる（最大決平成28年12月19日の要旨） |
| 預貯金の単独払戻し（909条の2） | 各共同相続人は、遺産に属する預貯金債権のうち、相続開始時の債権額の**3分の1**に当該共同相続人の法定相続分を乗じた額（金融機関ごとに法務省令で定める額＝150万円が上限）については、単独で権利を行使することができる |
| 相続開始から10年経過後の分割 | 原則として特別受益・寄与分を考慮せず、法定相続分等により分割する（904条の3） |

## 配偶者の居住の権利

| | 配偶者居住権（1028条） | 配偶者短期居住権（1037条） |
|---|---|---|
| 要件 | 被相続人の財産に属した建物に相続開始の時に居住していた配偶者が、遺産分割・遺贈・死因贈与により取得 | 被相続人の財産に属した建物に相続開始の時に無償で居住していた配偶者 |
| 存続期間 | 原則として配偶者の**終身** | 遺産分割により帰属が確定した日又は相続開始から6か月を経過する日のいずれか遅い日まで等 |
| 対抗要件 | **登記**（居住建物の所有者は登記を備えさせる義務を負う） | なし |
| 譲渡 | できない | できない |

## 相続人の不存在（951条以下）

相続人のあることが明らかでないときは、相続財産は法人となり、家庭裁判所が相続財産清算人を選任します。相続人が現れないときは、被相続人と生計を同じくしていた者、療養看護に努めた者その他特別の縁故があった者（**特別縁故者**）の請求により、清算後残存すべき相続財産の全部又は一部を与えることができ（958条の2）、なお残る財産は国庫に帰属します（959条）。

🎯 **試験で狙われる**：法定相続分の組み合わせ（2分の1・3分の2・4分の3）と、半血兄弟姉妹の相続分（2分の1）は計算問題で頻出です。

## よくある勘違い

- ❌「相続を放棄した者の子は、放棄した者を代襲して相続人となる」→ 放棄は代襲原因ではありません
- ❌「兄弟姉妹も廃除の対象となる」→ 廃除の対象は遺留分を有する推定相続人に限られます
- ❌「預貯金債権は、相続開始と同時に法定相続分に応じて当然に分割される」→ 判例は遺産分割の対象としています

<details>
<summary>【記述式】被相続人Aには、妻Bと、Aより先に死亡した子Cの子D（Aの孫）、AとBの子Eがいる。Eが相続を放棄した場合、Aの相続人とその法定相続分を40字程度で記述しなさい。</summary>

**解答例**
相続人は配偶者BとCを代襲する孫Dで、Eは放棄により除かれ、B・Dの相続分は各2分の1となる。（46字）
