## このページで学ぶこと

- 連帯債務者の1人について生じた事由の効力（絶対効・相対効）を確認します
- 保証債務の性質と、連帯保証との違いを整理します
- ゴール：個人保証人を保護する規定（書面要件・情報提供義務・極度額・公正証書）を説明できるようになる

> **端的にいうと**：連帯債務者の1人に生じた事由は、更改・相殺・混同を除き、他の連帯債務者に影響しないのが原則です。保証は書面でしなければ効力がなく、連帯保証には催告の抗弁権・検索の抗弁権がありません。

## 多数当事者の債権債務

| 類型 | 内容 |
|---|---|
| 分割債権・分割債務（427条） | 数人の債権者又は債務者がある場合において、別段の意思表示がないときは、各債権者又は各債務者は、**それぞれ等しい割合**で権利を有し、又は義務を負う |
| 不可分債権・不可分債務（428条〜431条） | 債権の目的がその性質上不可分である場合 |
| 連帯債権（432条〜435条の2） | 各債権者がすべての債権者のために全部又は一部の履行を請求でき、債務者は全ての債権者のために各債権者に対して履行できる |
| 連帯債務（436条〜445条） | 債権者は、連帯債務者の1人に対し、又は同時に若しくは順次に全ての連帯債務者に対し、全部又は一部の履行を請求できる |

### 連帯債務者の1人について生じた事由の効力

| 事由 | 効力 |
|---|---|
| 弁済・代物弁済・供託 | 絶対効（債務が消滅） |
| **更改**（438条） | 絶対効（債権は全ての連帯債務者の利益のために消滅） |
| **相殺**（439条1項） | 絶対効（反対債権を有する連帯債務者が相殺を援用したとき） |
| 反対債権を有する者が相殺を援用しない間（439条2項） | その連帯債務者の**負担部分の限度**において、他の連帯債務者は債権者に対して債務の履行を拒むことができる |
| **混同**（440条） | 絶対効（その連帯債務者は弁済をしたものとみなす） |
| 請求・免除・時効の完成・承認など | **相対効**（他の連帯債務者に効力を生じない）。ただし、債権者及び他の連帯債務者の1人が別段の意思を表示したときは、その意思に従う（441条） |

⚠️ **つまずきやすい**：2017年（平成29年）改正前は、履行の請求・免除・時効の完成も絶対効でした。現行法では相対効なので、連帯債務者の1人に対して請求しても、他の連帯債務者の時効の完成は猶予されません。

### 求償（442条〜445条）

- 連帯債務者の1人が弁済をし、その他自己の財産をもって共同の免責を得たときは、その免責を得た額が**自己の負担部分を超えるかどうかにかかわらず**、他の連帯債務者に対し、各自の負担部分に応じた額の求償権を有する（442条1項）
- 他の連帯債務者があることを知りながら、事前・事後の通知を怠った場合には、求償が制限される（443条）
- 償還をする資力のない者があるときは、その償還をすることができない部分は、求償者及び他の資力のある者の間で、各自の負担部分に応じて分割して負担する（444条）

## 保証債務

保証人は、主たる債務者がその債務を履行しないときに、その履行をする責任を負います（446条1項）。保証契約は、債権者と保証人の間で締結され、主たる債務者の委託は要件ではありません。

### 書面要件（446条2項・3項）

保証契約は、**書面**でしなければ、その効力を生じません。電磁的記録によってされたときは、書面によってされたものとみなします。

### 保証債務の性質

| 性質 | 内容 |
|---|---|
| 付従性 | 主たる債務が成立しなければ成立せず、消滅すれば消滅する。保証人の負担が債務の目的又は態様において主たる債務より重いときは、主たる債務の限度に減縮される（448条1項）。主たる債務の目的又は態様が保証契約の締結後に加重されたときであっても、保証人の負担は加重されない（448条2項） |
| 随伴性 | 主たる債務が移転すれば保証債務も移転する |
| 補充性 | 主たる債務者が履行しない場合に初めて履行する責任を負う（催告の抗弁権・検索の抗弁権） |

### 催告の抗弁・検索の抗弁

- **催告の抗弁権**（452条）：債権者が保証人に債務の履行を請求したときは、保証人は、まず主たる債務者に催告をすべき旨を請求することができる（主たる債務者が破産手続開始の決定を受けたとき、又はその行方が知れないときを除く）
- **検索の抗弁権**（453条）：保証人が主たる債務者に**弁済をする資力**があり、かつ、**執行が容易**であることを証明したときは、債権者は、まず主たる債務者の財産について執行をしなければならない

### 主たる債務者について生じた事由の効力（457条）

- 主たる債務者に対する履行の請求その他の事由による時効の完成猶予及び更新は、**保証人に対しても**その効力を生ずる
- 保証人は、主たる債務者が主張することができる抗弁をもって債権者に対抗することができる
- 主たる債務者が債権者に対して相殺権、取消権又は解除権を有するときは、これらの権利の行使によって主たる債務者がその債務を免れるべき限度において、保証人は、債権者に対して**債務の履行を拒むことができる**

保証人について生じた事由は、弁済など債務を消滅させるものを除き、主たる債務者に効力を及ぼしません。

## 連帯保証

| | 通常の保証 | 連帯保証 |
|---|---|---|
| 催告の抗弁権 | あり | **なし**（454条） |
| 検索の抗弁権 | あり | **なし**（454条） |
| 分別の利益（456条） | あり（共同保証人は頭割りの額のみ負担） | **なし** |
| 連帯保証人について生じた事由 | 主たる債務者に及ばない | 更改・相殺・混同は主たる債務者にも及ぶ（458条で438条・439条1項・440条・441条を準用） |

🎯 **試験で狙われる**：連帯保証人に対する履行の請求は、主たる債務者に対して効力を生じません（相対効。458条が準用する441条）。主たる債務者に対する請求は、保証人にも効力が及びます（457条1項）。この非対称は頻出です。

## 保証人の求償権

| 保証の種類 | 求償の範囲 |
|---|---|
| 主たる債務者の委託を受けた保証人（459条） | 支出した財産の額（そのために消滅した債務の額を超える場合は消滅した額）＋免責のあった日以後の法定利息＋避けることができなかった費用その他の損害の賠償 |
| 委託を受けない保証人で、主たる債務者の意思に反しないもの（462条1項） | 主たる債務者がその当時利益を受けた限度 |
| 主たる債務者の意思に反して保証をした者（462条2項） | 主たる債務者が現に利益を受けている限度 |

委託を受けた保証人は、主たる債務者が破産手続開始の決定を受け、かつ、債権者がその破産財団の配当に加入しないときなどには、あらかじめ求償権を行使することができます（事前求償権、460条）。

## 情報提供義務

| 条文 | 義務者 | 内容 |
|---|---|---|
| 458条の2 | 債権者 | 委託を受けた保証人の請求があったときは、主たる債務の元本・利息・違約金等の不履行の有無並びにこれらの残額及びそのうち弁済期が到来しているものの額に関する情報を提供しなければならない（保証人は法人でもよい） |
| 458条の3 | 債権者 | 主たる債務者が期限の利益を喪失したときは、保証人（**個人に限る**）に対し、その利益の喪失を知った時から**2か月以内**に、その旨を通知しなければならない。通知しなかったときは、期限の利益を喪失した時から通知を現にするまでに生じた遅延損害金を保証人に請求できない |
| 465条の10 | 主たる債務者 | 事業のために負担する債務の保証を個人に委託するときは、財産及び収支の状況、主たる債務以外に負担している債務の有無等の情報を提供しなければならない。これを怠り又は事実と異なる情報を提供したために保証人が誤認し、債権者がそれを知り又は知ることができたときは、保証人は保証契約を取り消すことができる |

## 個人根保証・事業のための借入れの保証

| 制度 | 内容 |
|---|---|
| 個人根保証契約（465条の2） | 一定の範囲に属する不特定の債務を主たる債務とする保証契約で、保証人が法人でないもの。**極度額**を定めなければ効力を生じない（書面要件も適用） |
| 個人貸金等根保証契約の元本確定期日（465条の3） | 定めるときは契約締結の日から5年以内。定めがないときは締結の日から3年を経過する日 |
| 元本確定事由（465条の4） | 保証人の財産への強制執行、保証人の破産手続開始、主たる債務者又は保証人の死亡など |
| 事業のための貸金等債務の個人保証（465条の6） | 保証契約の締結の日前**1か月以内**に作成された**公正証書**で保証人が保証債務を履行する意思を表示していなければ、効力を生じない |
| 公正証書が不要な場合（465条の9） | 主たる債務者が法人である場合の理事・取締役・執行役等、総株主の議決権の過半数を有する者など／主たる債務者が個人である場合の共同事業者、主たる債務者が行う事業に現に従事している配偶者 |

## よくある勘違い

- ❌「連帯債務者の1人に対する履行の請求は、他の連帯債務者に対しても効力を生ずる」→ 現行法では相対効です
- ❌「保証契約は口頭でも成立する」→ 書面（電磁的記録を含む）でしなければ効力を生じません
- ❌「連帯保証人にも検索の抗弁権がある」→ 連帯保証人には催告の抗弁権も検索の抗弁権もありません
