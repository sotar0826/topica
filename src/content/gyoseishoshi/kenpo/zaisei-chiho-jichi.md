## このページで学ぶこと

- 財政民主主義と租税法律主義の内容を確認します
- 予算・予備費・決算の手続と、公金支出の禁止を整理します
- ゴール：地方自治の条文（92条〜95条）と、憲法改正の手続を正確に説明できるようになる

> **端的にいうと**：国の財政を処理する権限は、国会の議決に基づいて行使しなければなりません。租税を課すには法律が必要です。憲法改正は、各議院の総議員の3分の2以上の賛成で国会が発議し、国民投票で過半数の賛成を得て成立します。

## 財政

| 条文 | 内容 |
|---|---|
| 83条（財政民主主義） | 国の財政を処理する権限は、国会の議決に基いて、これを行使しなければならない |
| 84条（租税法律主義） | あらたに租税を課し、又は現行の租税を変更するには、**法律又は法律の定める条件**によることを必要とする |
| 85条（国費の支出・債務負担） | 国費を支出し、又は国が債務を負担するには、国会の議決に基くことを必要とする |
| 86条（予算） | 内閣は、毎会計年度の予算を作成し、国会に提出して、その審議を受け議決を経なければならない |
| 87条（予備費） | 予見し難い予算の不足に充てるため、国会の議決に基いて予備費を設け、内閣の責任でこれを支出することができる。すべて予備費の支出については、内閣は、**事後に国会の承諾**を得なければならない |
| 88条（皇室財産） | すべて皇室財産は、国に属する。すべて皇室の費用は、予算に計上して国会の議決を経なければならない |
| 89条（公金支出の禁止） | 公金その他の公の財産は、**宗教上の組織若しくは団体**の使用、便益若しくは維持のため、又は**公の支配に属しない慈善、教育若しくは博愛の事業**に対し、これを支出し、又はその利用に供してはならない |
| 90条（決算） | 国の収入支出の決算は、すべて毎年**会計検査院**がこれを検査し、内閣は、次の年度に、その検査報告とともに、これを国会に提出しなければならない |
| 91条（財政状況の報告） | 内閣は、国会及び国民に対し、定期に、少くとも毎年1回、国の財政状況について報告しなければならない |

### 租税法律主義に関する判例

- 租税法律主義は、課税要件のみならず、租税の賦課・徴収の手続も法律で定めることを求める
- 通達を機縁として課税が行われた場合でも、通達の内容が法の正しい解釈に合致するものであれば、その課税処分は法の根拠に基づく処分と解される（判例）
- 市町村が行う国民健康保険の保険料は、保険給付を受け得ることに対する反対給付として徴収されるものであるから、憲法84条の規定が直接に適用されることはないが、強制徴収される点で租税に類似する性質を有するので、84条の趣旨が及ぶ（判例）

⚠️ **つまずきやすい**：予備費の支出は「事後」に国会の承諾を得ればよく、承諾が得られなくても既にした支出の効力には影響しないと解されています。決算は国会の議決の対象ではなく「提出」されるものです。

## 地方自治

| 条文 | 内容 |
|---|---|
| 92条 | 地方公共団体の組織及び運営に関する事項は、**地方自治の本旨**に基いて、法律でこれを定める |
| 93条1項 | 地方公共団体には、法律の定めるところにより、その議事機関として**議会**を設置する |
| 93条2項 | 地方公共団体の**長、その議会の議員及び法律の定めるその他の吏員**は、その地方公共団体の住民が、**直接**これを選挙する |
| 94条 | 地方公共団体は、その財産を管理し、事務を処理し、及び行政を執行する権能を有し、**法律の範囲内で条例**を制定することができる |
| 95条 | 一の地方公共団体のみに適用される特別法は、法律の定めるところにより、その地方公共団体の**住民の投票においてその過半数の同意**を得なければ、国会は、これを制定することができない |

- 地方自治の本旨は、**住民自治**と**団体自治**から成る
- 93条2項の「住民」は、地方公共団体の区域内に住所を有する日本国民を意味し、在留外国人に地方選挙の選挙権を保障したものではない。ただし、永住者等に法律で選挙権を付与することは憲法上禁止されていない（判例）
- 東京都の特別区は、憲法上の地方公共団体には当たらないとするのが判例（区長公選制の廃止を合憲とした）
- 条例は住民の代表機関である議会の議決によって成立する民主的立法であるから、条例による罰則の委任は、相当な程度に具体的であり、限定されていれば足りる（判例）

詳しくは行政法の[地方公共団体の種類と事務](/gyoseishoshi/gyoseiho/chiho-kokyo-dantai/)・[条例・規則](/gyoseishoshi/gyoseiho/jorei-kisoku/)を参照してください。

## 憲法改正（96条）

> **96条1項**：この憲法の改正は、各議院の**総議員の3分の2以上**の賛成で、国会が、これを発議し、国民に提案してその承認を経なければならない。この承認には、特別の国民投票又は国会の定める選挙の際行はれる投票において、その**過半数**の賛成を必要とする。
>
> **96条2項**：憲法改正について前項の承認を経たときは、天皇は、**国民の名で**、この憲法と一体を成すものとして、直ちにこれを公布する。

日本国憲法の改正手続に関する法律（国民投票法）では、次のように定められています。

- 国民投票の投票権者は、年齢満**18年**以上の日本国民
- 国民投票は、国会が憲法改正を発議した日から起算して60日以後180日以内において、国会の議決した期日に行う
- 「過半数」とは、**投票総数（賛成の投票数と反対の投票数を合計した数）の2分の1**を超えることをいう
- 憲法改正原案の発議には、衆議院においては議員100人以上、参議院においては議員50人以上の賛成を要する

🎯 **試験で狙われる**：憲法改正の発議は「総議員」の3分の2以上（出席議員ではない）、国民の承認は投票の「過半数」です。天皇は「国民の名で」公布します。

> **端的にいうと**：憲法改正は「国会の発議（総議員の3分の2以上）→国民投票（過半数）→天皇が国民の名で公布」という3段階で行われます。

## よくある勘違い

- ❌「予備費を支出するには、事前に国会の承諾を得なければならない」→ 事後に国会の承諾を得れば足ります
- ❌「憲法93条2項により、地方公共団体の長は、議会の議員の中から選ばれる」→ 長は住民が直接選挙します
- ❌「地方特別法は、国会の議決のみで制定することができる」→ その地方公共団体の住民投票で過半数の同意が必要です

84条のとおりです。

<summary>【○×】公の支配に属しない教育の事業に対しては、公金を支出することができない。</summary>

</details>

<details>
<summary>【○×】一の地方公共団体のみに適用される特別法は、その地方公共団体の議会の同意を得なければ、国会はこれを制定することができない。</summary>

**答え：×**
議会の同意ではなく、住民の投票においてその過半数の同意が必要です（95条）。
</details>

<details>
<summary>【○×】憲法改正は、各議院の出席議員の3分の2以上の賛成で、国会が発議する。</summary>

**答え：×**
各議院の総議員の3分の2以上の賛成です（96条1項）。
</details>
