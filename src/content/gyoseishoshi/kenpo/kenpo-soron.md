## このページで学ぶこと

- 日本国憲法の3つの基本原理と、最高法規性を確認します
- 天皇の地位と国事行為、内閣の助言と承認の意味を理解します
- ゴール：9条に関する判例（統治行為論）と、憲法尊重擁護義務の名あて人を説明できるようになる

> **端的にいうと**：日本国憲法は、国民主権・基本的人権の尊重・平和主義を基本原理とします。天皇は日本国及び日本国民統合の象徴であり、国政に関する権能を有さず、内閣の助言と承認により憲法所定の国事行為のみを行います。

## 基本原理

| 原理 | 主な条文 |
|---|---|
| 国民主権 | 前文、1条（主権の存する日本国民の総意） |
| 基本的人権の尊重 | 11条（侵すことのできない永久の権利）、97条 |
| 平和主義 | 前文（平和的生存権）、9条 |

## 天皇

### 地位（1条・2条）

- 天皇は、日本国の**象徴**であり日本国民統合の象徴であって、この地位は、主権の存する日本国民の総意に基づく（1条）
- 皇位は、**世襲**のものであって、国会の議決した皇室典範の定めるところにより、これを継承する（2条）。皇室典範は法律である

### 国事行為（3条・4条・6条・7条）

- 天皇の国事に関するすべての行為には、**内閣の助言と承認**を必要とし、**内閣が、その責任を負ふ**（3条）
- 天皇は、この憲法の定める国事に関する行為のみを行ひ、**国政に関する権能を有しない**（4条1項）
- 天皇は、法律の定めるところにより、その国事に関する行為を委任することができる（4条2項）

| 条文 | 国事行為 |
|---|---|
| 6条1項 | 国会の指名に基づいて、**内閣総理大臣を任命**する |
| 6条2項 | 内閣の指名に基づいて、**最高裁判所の長たる裁判官を任命**する |
| 7条1号 | 憲法改正、法律、政令及び条約を公布すること |
| 7条2号 | 国会を召集すること |
| 7条3号 | 衆議院を解散すること |
| 7条4号 | 国会議員の総選挙の施行を公示すること |
| 7条5号 | 国務大臣及び法律の定めるその他の官吏の任免並びに全権委任状及び大使及び公使の信任状を認証すること |
| 7条6号 | 大赦、特赦、減刑、刑の執行の免除及び復権を認証すること |
| 7条7号 | 栄典を授与すること |
| 7条8号 | 批准書及び法律の定めるその他の外交文書を認証すること |
| 7条9号 | 外国の大使及び公使を接受すること |
| 7条10号 | 儀式を行ふこと |

⚠️ **つまずきやすい**：最高裁判所長官は「内閣の指名に基づいて天皇が任命」、最高裁判所の長官以外の裁判官は「内閣が任命」し天皇が認証、下級裁判所の裁判官は「最高裁判所の指名した者の名簿によつて内閣が任命」します。国務大臣の任免は内閣総理大臣が行い、天皇は認証するだけです。

### 摂政（5条）

皇室典範の定めるところにより摂政を置くときは、摂政は、天皇の名でその国事に関する行為を行います。

### 皇室財産（8条・88条）

- 皇室に財産を譲り渡し、又は皇室が、財産を譲り受け、若しくは賜与することは、**国会の議決**に基づかなければならない（8条）
- すべて皇室財産は、国に属する。すべて皇室の費用は、予算に計上して国会の議決を経なければならない（88条）

## 平和主義

> **9条1項**：日本国民は、正義と秩序を基調とする国際平和を誠実に希求し、国権の発動たる戦争と、武力による威嚇又は武力の行使は、国際紛争を解決する手段としては、永久にこれを放棄する。
>
> **9条2項**：前項の目的を達するため、陸海空軍その他の戦力は、これを保持しない。国の交戦権は、これを認めない。

**最大判昭和34年12月16日**（砂川事件）

旧日米安全保障条約の合憲性が争われた事件です。判例は、9条は我が国が主権国として持つ固有の自衛権を何ら否定するものではないとしたうえで、安保条約のような主権国としての我が国の存立の基礎に極めて重大な関係をもつ高度の政治性を有するものが違憲かどうかの法的判断は、純司法的機能をその使命とする司法裁判所の審査には原則としてなじまない性質のものであり、**一見極めて明白に違憲無効**であると認められない限りは、裁判所の司法審査権の範囲外のものであるとしました（要旨）。

🎯 **試験で狙われる**：砂川事件は「一見極めて明白に違憲無効と認められない限り」司法審査の範囲外とした点で、純粋な統治行為論（苫米地事件）とは異なる限定がついています。両者の違いが出題されます。

## 最高法規性

| 条文 | 内容 |
|---|---|
| 97条 | この憲法が日本国民に保障する基本的人権は、人類の多年にわたる自由獲得の努力の成果であつて、これらの権利は、過去幾多の試錬に堪へ、現在及び将来の国民に対し、侵すことのできない永久の権利として信託されたものである |
| 98条1項 | この憲法は、国の最高法規であつて、その条規に反する法律、命令、詔勅及び国務に関するその他の行為の全部又は一部は、その効力を有しない |
| 98条2項 | 日本国が締結した条約及び確立された国際法規は、これを誠実に遵守することを必要とする |
| 99条 | **天皇又は摂政及び国務大臣、国会議員、裁判官その他の公務員**は、この憲法を尊重し擁護する義務を負ふ |

> **端的にいうと**：99条の憲法尊重擁護義務の名あて人に「国民」は含まれていません。憲法は国家権力を拘束するものだからです。

## よくある勘違い

- ❌「天皇は、内閣の助言と承認に基づいて国務大臣を任命する」→ 国務大臣の任命は内閣総理大臣が行い、天皇は認証します
- ❌「天皇の国事行為について、天皇自身が責任を負う」→ 内閣が責任を負います（3条）
- ❌「憲法99条により、国民も憲法を尊重し擁護する義務を負う」→ 名あて人に国民は含まれていません
