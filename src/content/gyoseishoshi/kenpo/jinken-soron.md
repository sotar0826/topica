## このページで学ぶこと

- 外国人・法人に人権がどこまで保障されるかを判例で確認します
- 私人間効力と、13条から導かれる新しい人権の判例を理解します
- ゴール：14条1項に関する主要な違憲判決・合憲判決を区別して説明できるようになる

> **端的にいうと**：人権は、権利の性質上日本国民のみを対象とするものを除き、外国人にも保障されます。人権規定は私人間に直接適用されず、民法90条などの一般条項を通じて間接的に適用されます（間接適用説）。

## 人権の享有主体

### 外国人

**最大判昭和53年10月4日**（マクリーン事件）

基本的人権の保障は、権利の性質上日本国民のみをその対象としていると解されるものを除き、我が国に在留する外国人に対しても等しく及ぶ（**権利性質説**）。政治活動の自由についても、我が国の政治的意思決定又はその実施に影響を及ぼす活動等外国人の地位にかんがみこれを認めることが相当でないと解されるものを除き、その保障が及ぶ。しかし、外国人に対する憲法の基本的人権の保障は、外国人在留制度の枠内で与えられているにすぎず、在留期間中の政治活動を在留期間の更新の際に消極的な事情として斟酌されないことまでの保障が与えられているものではないとしました（要旨）。

| 権利 | 判例・通説の考え方 |
|---|---|
| 入国の自由 | 保障されない（国際慣習法上、国家の裁量） |
| 在留の権利・再入国の自由 | 保障されない |
| 出国の自由 | 保障される |
| 国政選挙の選挙権 | 保障されない |
| 地方選挙の選挙権 | 憲法上保障されていないが、永住者等に法律で付与することは憲法上禁止されていない（判例） |
| 社会権 | 限られた財源の下で自国民を優先的に扱うことも許される（判例） |

### 法人

**最大判昭和45年6月24日**（八幡製鉄政治献金事件）

憲法第3章に定める国民の権利及び義務の各条項は、性質上可能なかぎり、内国の法人にも適用されるとし、会社は、自然人たる国民と同様、国や政党の特定の政策を支持、推進し又は反対するなどの政治的行為をなす自由を有するとして、会社による政治資金の寄附も、客観的、抽象的に観察して会社の社会的役割を果たすためになされたものと認められる限り、会社の権利能力の範囲に属するとしました（要旨）。

これに対し、強制加入団体である税理士会が政党など政治資金規正法上の政治団体に金員を寄付することは、会員の思想・信条の自由との関係から、税理士会の目的の範囲外の行為であるとされました（最判平成8年3月19日の要旨、南九州税理士会事件）。

## 私人間効力

**最大判昭和48年12月12日**（三菱樹脂事件）

憲法19条・14条の規定は、もっぱら国又は公共団体と個人との関係を規律するものであり、私人相互の関係を直接規律することを予定するものではないとし、私的自治に対する一般的制限規定である民法1条・90条や不法行為に関する諸規定等の適切な運用によって、基本的な自由や平等の利益を保護すべきであるとしました（**間接適用説**）。そのうえで、企業者は経済活動の一環として契約締結の自由を有し、特定の思想・信条を有する者をそのゆえをもって雇い入れることを拒んでも、当然に違法とすることはできないとしました（要旨）。

**最判昭和56年3月24日**（日産自動車事件）

女子の定年年齢を男子より低く定めた就業規則の部分は、専ら女子であることのみを理由として差別したことに帰着するものであり、性別のみによる不合理な差別を定めたものとして**民法90条により無効**であるとしました（要旨）。

## 特別な法律関係

公務員や在監者など、国家と特別な関係にある者の人権も、その関係の目的を達成するために必要かつ合理的な範囲でのみ制限されます。

- **公務員の政治活動**：国家公務員の政治的行為を禁止する国家公務員法の規定を合憲とした（最大判昭和49年11月6日の要旨、猿払事件）
- **在監者の閲読の自由**：未決拘禁者の新聞閲読の制限は、監獄内の規律及び秩序の維持に放置することのできない程度の障害が生ずる相当の蓋然性があると認められる場合に、必要かつ合理的な範囲においてのみ許されるとした（最大判昭和58年6月22日の要旨、よど号ハイジャック記事抹消事件）

## 幸福追求権（13条）から導かれる権利

> **13条**：すべて国民は、個人として尊重される。生命、自由及び幸福追求に対する国民の権利については、公共の福祉に反しない限り、立法その他の国政の上で、最大の尊重を必要とする。

| 判例 | 要旨 |
|---|---|
| 最大判昭和44年12月24日（京都府学連事件） | 何人も、その承諾なしに、みだりにその**容ぼう・姿態を撮影されない自由**を有する。ただし、現に犯罪が行われ若しくは行われたのち間がないと認められる場合で、証拠保全の必要性・緊急性があり、撮影が一般的に許容される限度を超えない相当な方法で行われるときは、本人の同意や令状がなくても許容される |
| 最判昭和56年4月14日（前科照会事件） | 前科及び犯罪経歴は人の名誉、信用に直接にかかわる事項であり、前科等のある者もこれを**みだりに公開されないという法律上の保護に値する利益**を有する。市区町村長が弁護士会の照会に漫然と応じて前科等のすべてを報告することは、公権力の違法な行使に当たる |
| 最判平成12年2月29日（エホバの証人輸血拒否事件） | 患者が、輸血を受けることは自己の宗教上の信念に反するとして、輸血を伴う医療行為を拒否するとの明確な意思を有している場合、このような**意思決定をする権利は、人格権の一内容として尊重されなければならない**。医師が輸血の方針について説明を怠ったことは、患者の人格権を侵害する |
| 最判平成20年3月6日（住基ネット事件） | 住基ネットによって管理・利用等される本人確認情報は、個人の内面に関わるような秘匿性の高い情報とはいえず、行政機関が住基ネットにより住民の本人確認情報を管理、利用等する行為は、個人に関する情報をみだりに第三者に開示又は公表されない自由を侵害するものではない |

## 法の下の平等（14条）

> **14条1項**：すべて国民は、法の下に平等であつて、人種、信条、性別、社会的身分又は門地により、政治的、経済的又は社会的関係において、差別されない。

判例は、14条1項は事柄の性質に即応した合理的な根拠に基づくものでない限り差別的な取扱いを禁止する趣旨であり（**相対的平等**）、合理的な区別は許されるとしています。

### 違憲判断がされた主な判例

| 判例 | 内容 |
|---|---|
| 最大判昭和48年4月4日（尊属殺重罰規定違憲判決） | 尊属殺を重く処罰すること自体は直ちに違憲ではないが、法定刑を死刑又は無期懲役に限っている点で、立法目的達成のため必要な限度をはるかに超え、著しく不合理な差別的取扱いとして違憲 |
| 最大判昭和51年4月14日（衆議院議員定数不均衡） | 選挙権の平等は投票価値の平等も含む。違憲と判断しつつ、選挙を無効とせず違法を宣言するにとどめた（事情判決の法理） |
| 最大判平成20年6月4日（国籍法違憲判決） | 日本国民である父と外国人の母との間に出生後に父から認知された子について、父母の婚姻を国籍取得の要件とする規定は、遅くとも上告人が国籍取得届を提出した当時には、合理的な理由のない差別として違憲 |
| 最大決平成25年9月4日（非嫡出子相続分違憲決定） | 嫡出でない子の相続分を嫡出子の2分の1とする民法の規定は、遅くとも本件相続が開始した平成13年7月当時において違憲 |
| 最大判平成27年12月16日（再婚禁止期間違憲判決） | 女性の再婚禁止期間のうち100日を超える部分は、合理性を欠いた過剰な制約として違憲 |

### 合憲判断がされた主な判例

- 夫婦同氏制を定める民法750条は14条1項・24条に違反しない（最大判平成27年12月16日、最大決令和3年6月23日の要旨）
- 給与所得者に必要経費の実額控除を認めない所得税法の規定は14条1項に違反しない（最大判昭和60年3月27日の要旨、サラリーマン税金訴訟）

🎯 **試験で狙われる**：平成27年12月16日には、再婚禁止期間（違憲）と夫婦同氏制（合憲）の2つの大法廷判決が同じ日に出されています。結論を取り違えないようにしましょう。

## よくある勘違い

- ❌「外国人には、権利の性質を問わず、日本国民と同様に人権が保障される」→ 権利の性質上日本国民のみを対象とするものは除かれます（権利性質説）
- ❌「三菱樹脂事件判決は、憲法19条が私人間にも直接適用されるとした」→ 間接適用説をとりました
- ❌「尊属殺重罰規定違憲判決は、尊属殺を普通殺より重く処罰すること自体が違憲であるとした」→ 法定刑が極端に重い点を違憲としました
