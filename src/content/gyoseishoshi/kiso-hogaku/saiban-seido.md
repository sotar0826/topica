## このページで学ぶこと

- 裁判所の種類と、三審制の仕組みを確認します
- 民事訴訟・刑事訴訟の基本原則と、裁判員制度の概要を理解します
- ゴール：調停・仲裁など裁判外の紛争解決手続の特徴を説明できるようになる

> **端的にいうと**：日本の裁判所は、最高裁判所と、高等裁判所・地方裁判所・家庭裁判所・簡易裁判所の下級裁判所から成り、原則として三審制がとられています。一定の重大な刑事事件では、国民が裁判員として審理に参加します。

## 裁判所の種類

| 裁判所 | 主な役割 |
|---|---|
| 最高裁判所 | 終審裁判所。大法廷（15人全員）と小法廷（5人ずつ3つ）。法令等の違憲判断や判例変更は大法廷で行う |
| 高等裁判所 | 全国8か所（支部あり）。主に控訴審。内乱罪の第一審、選挙訴訟の第一審なども扱う。知的財産高等裁判所は東京高裁の特別の支部 |
| 地方裁判所 | 原則的な第一審裁判所。簡易裁判所の民事判決に対する控訴審 |
| 家庭裁判所 | 家事審判・家事調停、人事訴訟の第一審、少年保護事件 |
| 簡易裁判所 | 訴訟の目的の価額が140万円を超えない請求の民事事件、罰金以下の刑に当たる罪などの軽微な刑事事件 |

## 審級制度

| 用語 | 意味 |
|---|---|
| 控訴 | 第一審判決に対する上訴 |
| 上告 | 控訴審判決に対する上訴（原則として憲法違反、判例違反などの理由に限られる） |
| 抗告 | 決定・命令に対する上訴 |
| 飛躍上告（民事） | 第一審判決に対し、当事者双方が上告をする権利を留保して控訴をしない旨の合意をした場合に、直接上告すること |
| 跳躍上告（刑事） | 第一審判決が法律等を違憲とした場合などに、直接最高裁判所に上告すること |

民事訴訟では、簡易裁判所が第一審の事件は、地方裁判所が控訴審、高等裁判所が上告審となります。上級審の裁判所の裁判における判断は、その事件について下級審の裁判所を拘束します（裁判所法4条）。

## 民事訴訟の基本原則

| 原則 | 内容 |
|---|---|
| 処分権主義 | 訴訟の開始、審判の対象・範囲、訴訟の終了（訴えの取下げ・請求の放棄・認諾・和解）を当事者の意思に委ねる |
| 弁論主義 | 判決の基礎となる事実と証拠の収集・提出を当事者の権能かつ責任とする。①当事者が主張しない事実を判決の基礎としてはならない、②当事者間に争いのない事実はそのまま判決の基礎としなければならない、③争いのある事実を認定するには当事者が申し出た証拠によらなければならない |
| 口頭主義・公開主義 | 口頭弁論は公開の法廷で行われる |
| 自由心証主義 | 裁判官は、口頭弁論の全趣旨及び証拠調べの結果をしん酌して、自由な心証により事実を認定する |

少額訴訟（60万円以下の金銭の支払請求）では、原則として1回の期日で審理を終え、直ちに判決を言い渡します。

## 刑事訴訟の基本原則

| 原則 | 内容 |
|---|---|
| 国家訴追主義・起訴独占主義 | 公訴は、検察官がこれを行う（刑事訴訟法247条） |
| 起訴便宜主義 | 犯罪の嫌疑があっても、犯人の性格・年齢・境遇、犯罪の軽重・情状、犯罪後の情況により訴追を必要としないときは、公訴を提起しないことができる（起訴猶予、248条） |
| 当事者主義 | 訴訟の追行を検察官と被告人・弁護人の主導に委ねる |
| 無罪の推定 | 有罪判決が確定するまでは、被告人は無罪と推定される。「疑わしきは被告人の利益に」 |
| 証拠裁判主義 | 事実の認定は、証拠による |

### 検察審査会

検察官が公訴を提起しない処分（不起訴処分）の当否を審査する機関で、選挙権を有する国民の中からくじで選ばれた11人の検察審査員で構成されます。起訴相当の議決後、検察官が再度不起訴処分をした場合などに、検察審査会が再審査を行い、8人以上の多数で**起訴議決**をしたときは、裁判所が指定した弁護士が公訴を提起します（強制起訴）。

## 裁判員制度

| 事項 | 内容 |
|---|---|
| 対象事件 | ①死刑又は無期拘禁刑に当たる罪に係る事件、②法定合議事件であって、故意の犯罪行為により被害者を死亡させた罪に係るもの |
| 審理する裁判所 | 地方裁判所の第一審 |
| 構成 | 原則として裁判官**3人**、裁判員**6人** |
| 裁判員の選任 | 衆議院議員の選挙権を有する者の中から、くじで選ばれる |
| 裁判員の権限 | 事実の認定、法令の適用、刑の量定に関与する（法令の解釈・訴訟手続の判断は裁判官のみ） |
| 評決 | 構成裁判官及び裁判員の双方の意見を含む合議体の員数の**過半数**の意見による |
| 守秘義務 | 評議の秘密等について守秘義務を負う（終了後も） |

⚠️ **つまずきやすい**：裁判員が関与するのは第一審だけで、控訴審・上告審は裁判官のみで審理します。また、有罪とするには、過半数であっても、裁判官と裁判員のそれぞれ1人以上が賛成していることが必要です。

## 裁判外紛争解決手続（ADR）

| 手続 | 内容 | 合意の効力 |
|---|---|---|
| 和解（裁判上・裁判外） | 当事者が互いに譲歩して争いをやめることを約する | 裁判上の和解は確定判決と同一の効力 |
| 調停 | 第三者（調停委員会）が当事者の間に入り、合意による解決を促す。民事調停、家事調停 | 調停調書の記載は確定判決（又は確定した審判）と同一の効力 |
| 仲裁 | 当事者の合意（仲裁合意）により、紛争の解決を第三者（仲裁人）の判断に委ね、その判断に従う | 仲裁判断は確定判決と同一の効力（執行には執行決定が必要）。仲裁合意があると、原則として訴えを提起できない |

裁判外紛争解決手続の利用の促進に関する法律（ADR法）は、民間の紛争解決事業者について法務大臣の**認証**制度を設けています。認証紛争解決手続によって紛争が解決しなかった場合、手続終了の通知を受けた日から1か月以内に訴えを提起したときは、時効の完成猶予について、紛争解決手続における請求の時に訴えの提起があったものとみなされます。

家事事件の一部（離婚など）については、訴えを提起する前にまず家庭裁判所の調停を経なければならない（**調停前置主義**）とされています。

🎯 **試験で狙われる**：調停は第三者が合意を促すもので、当事者は調停案に従う義務を負いません。仲裁は、第三者の判断に従うことを当事者があらかじめ合意する点で調停と異なります。

## 法曹

| 法曹 | 役割 |
|---|---|
| 裁判官 | 最高裁判所長官・判事、高等裁判所長官、判事、判事補、簡易裁判所判事 |
| 検察官 | 刑事事件について公訴を行い、裁判所に法の正当な適用を請求し、裁判の執行を監督する。検事総長・次長検事・検事長・検事・副検事 |
| 弁護士 | 当事者その他関係人の依頼又は官公署の委嘱によって、訴訟事件、非訟事件及び行政庁に対する不服申立事件に関する行為その他一般の法律事務を行う |

司法制度改革により、法科大学院制度、裁判員制度、日本司法支援センター（法テラス）などが導入されました。

## よくある勘違い

- ❌「簡易裁判所は、民事事件について訴訟の目的の価額が200万円を超えない請求を扱う」→ 140万円を超えない請求です
- ❌「裁判員は、法令の解釈についても裁判官とともに判断する」→ 法令の解釈は裁判官のみが判断します
- ❌「調停によって成立した合意には、確定判決と同一の効力はない」→ 調停調書の記載は確定判決と同一の効力を有します

## 確認問題

<details>
<summary>【○×】裁判員の参加する合議体は、原則として裁判官3人及び裁判員6人で構成される。</summary>

**答え：○**
裁判員法2条2項のとおりです。
</details>

<details>
<summary>【○×】起訴便宜主義とは、犯罪の嫌疑がある場合には、検察官は必ず公訴を提起しなければならないとする原則である。</summary>

**答え：×**
訴追を必要としないときは公訴を提起しないことができるとする原則です。説明は起訴法定主義のものです。
</details>

<details>
<summary>【○×】仲裁合意の対象となる民事上の紛争について訴えが提起されたときは、原則として、被告の申立てにより、裁判所は訴えを却下しなければならない。</summary>

**答え：○**
仲裁法14条1項のとおりです。
</details>

<details>
<summary>【○×】弁論主義の下では、当事者が主張しない事実であっても、証拠から認定できれば、裁判所はそれを判決の基礎とすることができる。</summary>

**答え：×**
当事者が主張しない事実を判決の基礎とすることはできません（弁論主義の第1テーゼ）。
</details>
