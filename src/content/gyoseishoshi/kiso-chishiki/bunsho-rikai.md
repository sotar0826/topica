## このページで学ぶこと

- 文章理解の3つの出題形式と、それぞれの解き方の手順を確認します
- 接続語・指示語を手がかりに文章の論理構造をつかむ方法を理解します
- ゴール：時間をかけすぎずに安定して正解するための、選択肢の検討方法を身につける

> **端的にいうと**：文章理解は、例年3問程度出題され、基礎知識科目の基準点を確保するための重要な得点源です。自分の感想ではなく、本文に書かれていることだけを根拠に選択肢を判断するのが鉄則です。

## 出題形式

| 形式 | 内容 | 主な手がかり |
|---|---|---|
| 要旨把握 | 本文の主旨・筆者の主張として妥当なものを選ぶ | 筆者の主張が現れる部分（結論、逆接の後、繰り返されるキーワード） |
| 空欄補充 | 本文中の空欄に入る語句・文を選ぶ | 空欄の前後の文脈、接続語、対比・言い換えの関係 |
| 並べ替え | ばらばらにされた文を正しい順序に並べる | 指示語、接続語、話題の転換、具体と抽象の関係 |

## 要旨把握の解き方

1. **先に選択肢を軽く確認する**：何がテーマになっているかの見当をつける
2. **本文を読み、筆者の主張に印をつける**：「しかし」「つまり」「〜ではないか」「〜べきである」の周辺に主張が現れやすい
3. **具体例と主張を区別する**：具体例・引用・一般論の紹介は、要旨そのものではない
4. **選択肢を検討する**：本文の主張と一致し、かつ本文全体を過不足なく反映しているものを選ぶ

### 誤りの選択肢の典型

| 型 | 内容 |
|---|---|
| 本文に書かれていない | 一般論としては正しくても、本文に根拠がない |
| 言い過ぎ・断定 | 「必ず」「すべて」「〜だけ」など、本文より強い表現になっている |
| 部分的 | 本文の一部（具体例など）だけを取り出しており、全体の要旨になっていない |
| 因果・対比の逆転 | 原因と結果、肯定と否定、AとBの関係が本文と逆になっている |
| 筆者が批判している見解 | 本文で紹介されているが、筆者は否定している見解を主張として示している |

⚠️ **つまずきやすい**：自分の常識や知識で「正しそう」と感じる選択肢を選ぶと誤ります。判断の根拠は常に本文の記述に求めましょう。

## 空欄補充の解き方

1. 空欄を含む一文と、その前後の文を丁寧に読む
2. 空欄の前後にある**接続語**や、**対比・言い換え**の関係を確認する
3. 空欄に入る語句の品詞・文法的なつながりを確認する
4. 候補を空欄に入れて読み直し、文脈が自然につながるかを確かめる

## 並べ替えの解き方

1. **冒頭になりうる文**を探す：指示語（「これ」「その」）や接続語（「しかし」「また」）で始まる文は、冒頭になりにくい
2. **指示語の指す内容**を探し、前の文とつなげる
3. **接続語**の働きから、前後の文の関係を判断する
4. 選択肢を活用し、確実なつながり（「AのあとにB」）を手がかりに絞り込む
5. 最後に全体を通して読み、論理が自然に流れているかを確認する

## 接続語の働き

| 働き | 主な接続語 | 読み方のポイント |
|---|---|---|
| 逆接 | しかし、だが、ところが、にもかかわらず | 後ろに筆者の主張がくることが多い |
| 順接 | だから、したがって、そのため、それゆえ | 前が理由、後ろが結論 |
| 言い換え・要約 | つまり、すなわち、要するに | 後ろに前の内容のまとめがくる。要旨把握の重要な手がかり |
| 例示 | たとえば | 後ろは具体例。主張そのものではない |
| 添加・並列 | また、さらに、そして、しかも | 前と同じ方向の内容を付け加える |
| 対比・選択 | 一方、それに対して、あるいは | 2つの事柄を比べる。どちらが筆者の立場かを確認する |
| 理由 | なぜなら、というのは | 後ろに理由がくる（文末は「〜からである」） |
| 転換 | ところで、さて | 話題が変わる |

## 時間配分と取り組み方

- 文章理解は、知識がなくても読解力で正解できるため、確実に得点したい分野です
- 1問に時間をかけすぎないよう、目安の時間（例えば1問5〜7分程度）を決めて解く練習をしておきましょう
- 過去問や他の公務員試験の文章理解の問題を使って、出題形式に慣れておくことが有効です

🎯 **試験で狙われる**：要旨把握では、「本文の内容と矛盾しないが、要旨とはいえない」選択肢がよく用意されます。本文の中心的な主張を含んでいるかどうかを基準に判断しましょう。

## よくある勘違い

- ❌「本文の内容と矛盾しない選択肢であれば、要旨として正解になる」→ 要旨把握では、中心的な主張を過不足なく表しているかが基準です
- ❌「具体例の部分に書かれていることが、筆者の主張である」→ 具体例は主張を支える材料であり、主張そのものではありません
- ❌「並べ替えでは、すべての文の順序を最初から決める必要がある」→ 確実なつながりから選択肢を絞り込むほうが効率的です

## 確認問題

<details>
<summary>【○×】「たとえば」に続く部分は具体例であることが多く、筆者の主張そのものではない場合が多い。</summary>

**答え：○**
例示の接続語の後は具体例であり、主張はその前後に示されることが多いです。
</details>

<details>
<summary>【○×】要旨把握の問題では、一般的に正しい内容であれば、本文に書かれていなくても正解となりうる。</summary>

**答え：×**
判断の根拠は本文の記述に限られます。
</details>

<details>
<summary>【○×】並べ替えの問題で、「これは」「しかし」で始まる文は、冒頭の文になりにくい。</summary>

**答え：○**
指示語や接続語で始まる文は、前に受ける文があることを示しています。
</details>

<details>
<summary>【○×】「つまり」「要するに」の後には、前の内容をまとめた記述がくることが多く、要旨把握の手がかりとなる。</summary>

**答え：○**
言い換え・要約の接続語は、筆者の主張をつかむ重要な手がかりです。
</details>
