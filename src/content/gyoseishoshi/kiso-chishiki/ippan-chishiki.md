## このページで学ぶこと

- 選挙制度・財政・金融・社会保障など、出題が続いている分野の基本的な仕組みを確認します
- 時事問題に対応するための「土台となる制度知識」を整理します
- ゴール：ニュースで目にする制度用語を、仕組みとあわせて説明できるようになる

> **端的にいうと**：一般知識の出題範囲は広く、すべてを網羅することはできません。制度の仕組み（選挙制度、予算と国債、日銀の金融政策、社会保険の構造など）を押さえたうえで、新聞などで最新の動向を補うのが効率的です。基礎知識科目は足切り（基準点）があるため、文章理解・業務関連法令・個人情報保護と合わせて確実に得点を積み上げます。

## 政治

### 選挙制度

| | 衆議院 | 参議院 |
|---|---|---|
| 定数 | 465人（小選挙区289人、比例代表176人） | 248人（選挙区148人、比例代表100人） |
| 選挙制度 | 小選挙区比例代表並立制。比例代表は全国11ブロックの拘束名簿式 | 選挙区（原則都道府県単位。一部合区）と、全国1区の比例代表（非拘束名簿式。特定枠あり） |
| 重複立候補 | 可能（惜敗率による復活当選あり） | 不可 |
| 任期 | 4年（解散あり） | 6年（3年ごとに半数改選） |

- 選挙権年齢は**18歳以上**（2016年から）。被選挙権は衆議院議員・市町村長・地方議会議員が25歳以上、参議院議員・都道府県知事が30歳以上
- 比例代表の議席配分には**ドント式**が用いられる
- 公職選挙法により、戸別訪問は禁止されている。インターネットを利用した選挙運動は2013年から一定の範囲で解禁されている（電子メールによる選挙運動は政党・候補者に限られる）

### 政党と政治資金

- 政党助成法は、一定の要件（国会議員5人以上、又は国会議員1人以上かつ直近の国政選挙で得票率2%以上）を満たす政党に、政党交付金を交付する
- 政治資金規正法は、政治団体の収支の公開、寄附の制限（会社・労働組合等の政治家個人への寄附の禁止など）を定めている

### 行政の仕組み

- 中央省庁は1府12省庁体制（2001年の中央省庁再編）を基本とし、その後、復興庁（2012年）、デジタル庁（2021年）、こども家庭庁（2023年）などが設置された
- 内閣人事局（2014年）により、幹部職員人事の一元管理が行われている

## 経済

### 財政

| 用語 | 内容 |
|---|---|
| 一般会計・特別会計 | 国の基本的な収支を扱う一般会計と、特定の事業・資金を区分して扱う特別会計 |
| 本予算・補正予算・暫定予算 | 年度開始前に成立する本予算、年度途中に追加・変更する補正予算、本予算が年度開始までに成立しない場合の暫定予算 |
| 建設国債 | 財政法4条ただし書に基づき、公共事業費等の財源として発行される国債 |
| 特例国債（赤字国債） | 財政法上は発行が認められていないため、特例公債法を制定して発行される国債 |
| 市中消化の原則 | 財政法5条により、日本銀行による国債の直接引受けは原則として禁止されている |
| プライマリーバランス | 国債費を除いた歳出と、国債発行による収入を除いた歳入との収支 |
| 財政投融資 | 財投債の発行などにより調達した資金を、政策的に必要な分野に投資・融資する仕組み |

### 租税

| 分類 | 内容 | 例 |
|---|---|---|
| 直接税 | 納税者と担税者が同じ | 所得税、法人税、相続税、住民税、固定資産税 |
| 間接税 | 納税者と担税者が異なる | 消費税、酒税、たばこ税、関税 |
| 国税・地方税 | 国が課すか、地方公共団体が課すか | 所得税・法人税・消費税（国税）／住民税・固定資産税・事業税（地方税） |

- **累進課税**：所得が高いほど高い税率を適用する（所得税）。所得の再分配機能をもつ
- **消費税**の標準税率は10%（うち地方消費税2.2%）、飲食料品（酒類・外食を除く）と定期購読の新聞には**軽減税率**8%が適用される。2023年10月からインボイス制度（適格請求書等保存方式）が導入された
- **ふるさと納税**は、地方公共団体に対する寄附金について、一定の上限まで所得税・住民税から控除される制度

### 金融

- **日本銀行**は、日本の中央銀行として、発券銀行・銀行の銀行・政府の銀行の役割を担う。日本銀行法は、日本銀行の金融政策の自主性を尊重しなければならないと定めている
- 金融政策は、日本銀行の**政策委員会**（金融政策決定会合）で決定される。主な手段は公開市場操作（オペレーション）
- 金融緩和は、市場に資金を供給して金利を引き下げ、景気を刺激する。金融引締めはその逆
- 日本銀行は、2016年にマイナス金利政策を導入したが、2024年3月にマイナス金利政策を解除し、その後政策金利を段階的に引き上げている

### 国際経済

| 用語 | 内容 |
|---|---|
| 円高・円安 | 円高は輸入に有利・輸出に不利、円安は輸出に有利・輸入に不利に働く |
| WTO | 世界貿易機関。自由・無差別・多角的な貿易体制の維持を目的とする |
| EPA・FTA | 経済連携協定・自由貿易協定。特定の国・地域の間で関税の撤廃などを行う |
| CPTPP | 環太平洋パートナーシップに関する包括的及び先進的な協定 |
| RCEP | 地域的な包括的経済連携協定（日本・中国・韓国・ASEANなど） |

## 社会

### 社会保障制度の4つの柱

| 柱 | 内容 | 例 |
|---|---|---|
| 社会保険 | 保険料を財源に、病気・老齢・失業などのリスクに備える | 医療保険、年金保険、雇用保険、労災保険、介護保険 |
| 公的扶助 | 税を財源に、生活に困窮する者に最低限度の生活を保障する | 生活保護 |
| 社会福祉 | 児童・高齢者・障害者などへのサービス | 児童福祉、障害者福祉 |
| 公衆衛生 | 国民の健康の保持増進 | 感染症対策、予防接種 |

### 年金・医療・介護

- **公的年金**：20歳以上60歳未満の全国民が加入する国民年金（基礎年金）と、会社員・公務員が加入する厚生年金の**2階建て**の構造。公務員の共済年金は2015年に厚生年金に一元化された
- **医療保険**：すべての国民がいずれかの公的医療保険に加入する**国民皆保険**。75歳以上の者は後期高齢者医療制度に加入する
- **介護保険**：市町村（特別区）が保険者。**40歳以上**の者が被保険者となり、65歳以上の第1号被保険者と、40歳以上65歳未満の医療保険加入者である第2号被保険者に分かれる。要介護・要支援の認定を受けてサービスを利用する
- **生活保護**：生活保護法に基づき、生活扶助・住宅扶助・教育扶助・医療扶助・介護扶助など8種類の扶助がある。補足性の原理（資産・能力等を活用してもなお最低限度の生活を維持できない場合に保護する）がとられている

### 労働

- 労働三法：労働基準法、労働組合法、労働関係調整法
- 働き方改革関連法（2019年から順次施行）により、時間外労働の上限規制、年次有給休暇の取得義務化（年5日）、同一労働同一賃金などが導入された

### 環境

- パリ協定（2015年採択）は、世界の平均気温上昇を産業革命以前に比べて2℃より十分低く保ち、1.5℃に抑える努力を追求することを目標とする
- 日本は、2050年までに温室効果ガスの排出を全体としてゼロにする**カーボンニュートラル**を目指すことを宣言している

🎯 **試験で狙われる**：一般知識は、直前期の時事（法改正、選挙、経済指標、国際情勢）からの出題も多い分野です。この単元の制度知識を土台に、受験年度の政府白書や新聞で最新の数値・動向を確認しておきましょう。

⚠️ **つまずきやすい**：基礎知識科目の基準点（14問中6問以上の正答）を確保するには、一般知識だけに頼らず、得点が安定しやすい文章理解（例年3問）と、業務関連法令・個人情報保護の分野で確実に正解することが重要です。

## よくある勘違い

- ❌「参議院議員の選挙でも、選挙区と比例代表の重複立候補ができる」→ 重複立候補ができるのは衆議院議員の選挙です
- ❌「特例国債（赤字国債）は、財政法4条に基づいて発行される」→ 財政法上は認められておらず、特例公債法に基づいて発行されます
- ❌「介護保険の被保険者は65歳以上の者に限られる」→ 40歳以上65歳未満の医療保険加入者も第2号被保険者です

## 確認問題

<details>
<summary>【○×】衆議院議員の選挙は小選挙区比例代表並立制で行われ、比例代表選挙は全国を11ブロックに分けて行われる。</summary>

**答え：○**
比例代表は全国11ブロックの拘束名簿式です。
</details>

<details>
<summary>【○×】財政法は、日本銀行に公債を引き受けさせることを原則として禁止している。</summary>

**答え：○**
財政法5条の市中消化の原則です。
</details>

<details>
<summary>【○×】公的年金制度は、国民年金と厚生年金の2階建ての構造となっており、公務員は現在も共済年金に加入している。</summary>

**答え：×**
公務員の共済年金は、2015年に厚生年金に一元化されました。
</details>

<details>
<summary>【○×】消費税の軽減税率は、外食や酒類を含む飲食料品全般に適用される。</summary>

**答え：×**
軽減税率8%の対象となる飲食料品からは、酒類と外食が除かれています。
</details>
