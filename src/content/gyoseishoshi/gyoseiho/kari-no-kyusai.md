## このページで学ぶこと

- 取消訴訟における執行停止の積極要件・消極要件を確認します
- 内閣総理大臣の異議の制度を理解します
- ゴール：仮の義務付け・仮の差止めの要件を、執行停止と比較して説明できるようになる

> **端的にいうと**：取消訴訟を提起しても処分の執行は止まりません。止めるには執行停止の申立てが必要で、「重大な損害を避けるため緊急の必要」があることが要件です。仮の義務付け・仮の差止めは、より厳しい「償うことのできない損害」と「本案について理由があるとみえる」ことが要件です。

## 執行不停止の原則（25条1項）

処分の取消しの訴えの提起は、処分の効力、処分の執行又は手続の続行を妨げません。民事保全法に規定する仮処分をすることもできません（44条）。

## 執行停止（25条2項〜）

### 要件

| | 要件 |
|---|---|
| 積極要件 | ①処分の取消しの訴えの提起があること（本案の係属）<br>②申立てがあること<br>③処分、処分の執行又は手続の続行により生ずる**重大な損害を避けるため緊急の必要**があること |
| 消極要件 | ④公共の福祉に重大な影響を及ぼすおそれがあるとき、又は<br>⑤本案について理由がないとみえるとき<br>には、執行停止をすることができない（25条4項） |

- 裁判所が**職権で**執行停止をすることはできません（申立てが必要）
- 重大な損害を生ずるか否かを判断するに当たっては、損害の回復の困難の程度を考慮するものとし、損害の性質及び程度並びに処分の内容及び性質をも勘案します（25条3項）
- 処分の効力の停止は、処分の執行又は手続の続行の停止によって目的を達することができる場合には、することができません（25条2項ただし書）

### 手続

- 執行停止の決定は、疎明に基づいてする（25条5項）
- 口頭弁論を経ないですることができるが、あらかじめ当事者の意見をきかなければならない（25条6項）
- 執行停止の申立てに対する決定に対しては、即時抗告をすることができる。即時抗告は、執行停止の決定の執行を停止する効力を有しない（25条7項・8項）
- 執行停止の決定が確定した後に、その理由が消滅し、その他事情が変更したときは、裁判所は、相手方の申立てにより、決定をもって、執行停止の決定を取り消すことができる（26条）
- 執行停止の決定には、第三者効と拘束力が準用される（32条2項、33条4項）

## 内閣総理大臣の異議（27条）

執行停止の申立てがあった場合には、**内閣総理大臣**は、裁判所に対し、異議を述べることができます。執行停止の決定があった後においても、同様です。

- 異議には理由を付さなければならない。理由においては、処分の効力を存続し、処分を執行し、又は手続を続行しなければ、公共の福祉に重大な影響を及ぼすおそれのある事情を示す
- 異議があったときは、裁判所は、執行停止をすることができず、また、すでに執行停止の決定をしているときは、これを**取り消さなければならない**
- 内閣総理大臣は、やむをえない場合でなければ異議を述べてはならず、また、異議を述べたときは、次の常会において国会にこれを報告しなければならない

⚠️ **つまずきやすい**：内閣総理大臣の異議は、執行停止の決定の前でも後でも述べることができます。異議が述べられれば、裁判所は異議の当否を審査することなく、執行停止をすることができなくなります。

## 仮の義務付け・仮の差止め（37条の5）

| | 仮の義務付け | 仮の差止め |
|---|---|---|
| 前提 | 義務付けの訴えの提起 | 差止めの訴えの提起 |
| 申立て | 必要 | 必要 |
| 損害の要件 | 処分又は裁決がされないことにより生ずる**償うことのできない損害を避けるため緊急の必要**があること | 処分又は裁決がされることにより生ずる**償うことのできない損害を避けるため緊急の必要**があること |
| 本案の見通し | 本案について**理由があるとみえる**とき | 本案について**理由があるとみえる**とき |
| 消極要件 | 公共の福祉に重大な影響を及ぼすおそれがあるときは、することができない | 同左 |

仮の義務付け・仮の差止めについても、内閣総理大臣の異議の規定が準用されます（37条の5第4項）。

> **端的にいうと**：執行停止は「重大な損害」と「本案について理由がないとみえるときはできない」（消極要件）、仮の義務付け・仮の差止めは「償うことのできない損害」と「本案について理由があるとみえる」（積極要件）です。後者のほうが要件が厳格です。

## 行政不服審査法の執行停止との比較

| | 行政事件訴訟法 | 行政不服審査法 |
|---|---|---|
| 判断機関 | 裁判所 | 審査庁 |
| 職権による執行停止 | できない | 上級行政庁又は処分庁である審査庁はできる |
| 停止以外の措置 | できない | 上級行政庁又は処分庁である審査庁はできる |
| 内閣総理大臣の異議 | あり | なし |
| 必要的執行停止 | なし（裁量） | 重大な損害を避けるため緊急の必要があるとき等 |

🎯 **試験で狙われる**：「裁判所は、必要があると認めるときは、職権で執行停止をすることができる」という肢は誤りです。行政不服審査法と行政事件訴訟法で、職権の可否が異なる点が頻出です。

## よくある勘違い

- ❌「取消訴訟を提起すれば、処分の執行は当然に停止される」→ 執行不停止が原則です
- ❌「執行停止の要件は、償うことのできない損害を避けるため緊急の必要があることである」→ 執行停止は「重大な損害」です。「償うことのできない損害」は仮の義務付け・仮の差止めの要件です
- ❌「内閣総理大臣の異議は、執行停止の決定がされる前に限り述べることができる」→ 決定後も述べることができます

## 確認問題

<details>
<summary>【○×】裁判所は、処分の取消しの訴えの提起があった場合において、重大な損害を避けるため緊急の必要があるときは、職権で処分の執行を停止することができる。</summary>

**答え：×**
執行停止には申立てが必要です（25条2項）。
</details>

<details>
<summary>【○×】執行停止は、本案について理由がないとみえるときは、することができない。</summary>

**答え：○**
25条4項の消極要件です。
</details>

<details>
<summary>【○×】内閣総理大臣の異議があったときは、裁判所は、すでにした執行停止の決定を取り消さなければならない。</summary>

**答え：○**
27条4項のとおりです。
</details>

<details>
<summary>【○×】仮の差止めは、処分がされることにより生ずる重大な損害を避けるため緊急の必要があれば、本案について理由があるとみえなくても、することができる。</summary>

**答え：×**
仮の差止めには「償うことのできない損害」を避ける緊急の必要と、「本案について理由があるとみえる」ことが必要です。
</details>
