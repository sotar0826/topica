## このページで学ぶこと

- 行政手続法が規律する4つの対象（処分・行政指導・届出・命令等）を確認します
- 2条の定義、特に「不利益処分」から除外されるものを理解します
- ゴール：地方公共団体の機関の行為にどこまで行政手続法が適用されるかを説明できるようになる

> **端的にいうと**：行政手続法は、処分・行政指導・届出・命令等を定める手続について共通のルールを定める法律です。地方公共団体の機関の行為でも、法律に基づく処分と届出には適用されますが、条例・規則に基づく処分と届出、行政指導、命令等を定める行為には適用されません。

## 目的（1条）

行政手続法は、処分、行政指導及び届出に関する手続並びに命令等を定める手続に関し、共通する事項を定めることによって、行政運営における**公正の確保と透明性の向上**を図り、もって国民の権利利益の保護に資することを目的としています。

透明性とは、行政上の意思決定について、その内容及び過程が国民にとって明らかであることをいいます（1条1項かっこ書）。

行政手続法は、行政上の手続の一般法です。他の法律に特別の定めがある場合は、その定めが優先します（1条2項）。

⚠️ **つまずきやすい**：行政手続法の対象は「処分」「行政指導」「届出」「命令等を定める手続」の4つです。行政計画、行政契約、行政調査の手続は、一般的な規律の対象になっていません。

## 主な定義（2条）

| 用語 | 定義の要点 |
|---|---|
| 処分 | 行政庁の処分その他公権力の行使に当たる行為 |
| 申請 | 法令に基づき、行政庁の許可、認可、免許その他の自己に対し何らかの利益を付与する処分（許認可等）を求める行為であって、当該行為に対して行政庁が諾否の応答をすべきこととされているもの |
| 不利益処分 | 行政庁が、法令に基づき、特定の者を名あて人として、直接に、これに義務を課し、又はその権利を制限する処分 |
| 行政機関 | 内閣府・省・外局等の国の機関、地方公共団体の機関（議会を除く）など |
| 行政指導 | 行政機関がその任務又は所掌事務の範囲内において一定の行政目的を実現するため特定の者に一定の作為又は不作為を求める指導、勧告、助言その他の行為であって処分に該当しないもの |
| 届出 | 行政庁に対し一定の事項の通知をする行為（申請に該当するものを除く）であって、法令により直接に当該通知が義務付けられているもの |
| 命令等 | 法律に基づく命令（処分の要件を定める告示を含む）又は規則、審査基準、処分基準、行政指導指針 |

### 不利益処分から除外されるもの（2条4号ただし書）

1. 事実上の行為、及び事実上の行為をするに当たりその範囲・時期等を明らかにするために法令上必要とされている手続としての処分
2. 申請により求められた許認可等を拒否する処分その他申請に基づき当該申請をした者を名あて人としてされる処分
3. 名あて人となるべき者の同意の下にすることとされている処分
4. 許認可等の効力を失わせる処分であって、当該許認可等の基礎となった事実が消滅した旨の届出があったことを理由としてされるもの

🎯 **試験で狙われる**：申請拒否処分は不利益処分ではありません。したがって聴聞・弁明の手続は不要で、申請に対する処分の規定（理由提示など）が適用されます。

## 適用除外（3条・4条）

### 3条1項：一定の処分・行政指導

性質上、行政手続法の手続になじまないものとして、次のような処分・行政指導が除外されています。

- 国会・地方議会の議決によってされる処分
- 裁判所・裁判官の裁判により、又は裁判の執行としてされる処分
- 刑事事件に関する法令に基づいて検察官・司法警察職員がする処分・行政指導
- 国税・地方税の犯則事件に関する法令に基づく処分・行政指導
- 学校・講習所等において、教育・講習・訓練の目的を達成するために学生・生徒・研修生等に対してされる処分・行政指導
- 刑務所等において、収容の目的を達成するためにされる処分・行政指導
- 公務員（地方公務員を含む）の職務又は身分に関してされる処分・行政指導
- 外国人の出入国、難民の認定等に関する処分・行政指導
- 試験・検定の結果についての処分
- 審査請求などの不服申立てに対する行政庁の裁決・決定その他の処分
- 聴聞・弁明の機会の付与の手続などの中でされる処分・行政指導
- 報告・物件の提出を命ずる処分など、情報の収集を直接の目的としてされる処分・行政指導

### 3条3項：地方公共団体の機関の行為

| 行為 | 根拠 | 行政手続法の適用 |
|---|---|---|
| 処分 | 法律・政令・省令 | **適用あり** |
| 処分 | 条例・規則 | 適用なし |
| 届出 | 法律・政令・省令 | **適用あり** |
| 届出 | 条例・規則 | 適用なし |
| 行政指導 | 根拠を問わない | 適用なし |
| 命令等を定める行為 | — | 適用なし |

適用が除外される部分については、地方公共団体は、行政手続法の規定の趣旨にのっとり、行政運営における公正の確保と透明性の向上を図るため必要な措置を講ずるよう努めなければなりません（46条）。多くの自治体が行政手続条例を定めています。

> **端的にいうと**：自治体の機関の行為で行政手続法が適用されるのは、「法律に基づく処分」と「法律に基づく届出」だけです。行政指導と命令等は根拠を問わず適用されません。

### 4条：国の機関等に対する処分

国の機関又は地方公共団体若しくはその機関に対する処分（これらの機関又は団体がその固有の資格において当該処分の名あて人となるものに限る）及び行政指導などについては、行政手続法は適用されません。

## よくある勘違い

- ❌「地方公共団体の機関がする行政指導には、法律に基づくものであれば行政手続法が適用される」→ 行政指導は根拠を問わず適用除外です
- ❌「申請に対する拒否処分は、名あて人に不利益なので不利益処分に当たる」→ 2条4号ロで明文で除外されています
- ❌「公務員に対する懲戒処分には、行政手続法の聴聞手続が適用される」→ 公務員の職務・身分に関する処分は適用除外です

**答え：○**

<summary>【○×】地方公共団体の機関がする処分であって、その根拠となる規定が条例に置かれているものについては、行政手続法の処分に関する規定は適用されない。</summary>

**答え：○**
3条3項により適用除外です。根拠が法律に置かれている処分には適用されます。

**答え：×**
地方公共団体の機関がする行政指導は、根拠にかかわらず適用除外です。
</details>

**答え：○**
2条4号ハにより不利益処分から除外されています。
