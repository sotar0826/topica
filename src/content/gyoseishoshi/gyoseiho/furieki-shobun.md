## このページで学ぶこと

- 不利益処分の前に必要な意見陳述手続（聴聞・弁明の機会の付与）の振り分けを理解します
- 聴聞手続の流れと、当事者・参加人の権利を整理します
- ゴール：聴聞と弁明の機会の付与の違い、不利益処分の理由提示のルールを説明できるようになる

> **端的にいうと**：許認可の取消しや資格の剝奪のような重い不利益処分には、口頭で争える聴聞が必要です。それ以外の不利益処分には、原則として書面で行う弁明の機会の付与で足ります。

## 処分基準（12条）

処分基準とは、不利益処分をするかどうか又はどのような不利益処分とするかについてその法令の定めに従って判断するために必要とされる基準です。

- 処分基準を定め、かつ、これを公にしておくよう**努めなければならない**（12条1項）
- 処分基準を定めるに当たっては、不利益処分の性質に照らしてできる限り具体的なものとしなければならない（12条2項）

## 意見陳述のための手続の区分（13条）

### 聴聞が必要な場合（13条1項1号）

1. 許認可等を取り消す不利益処分をしようとするとき
2. 名あて人の資格又は地位を直接にはく奪する不利益処分をしようとするとき
3. 名あて人が法人である場合におけるその役員の解任を命ずる不利益処分、名あて人の業務に従事する者の解任を命ずる不利益処分又は名あて人の会員である者の除名を命ずる不利益処分をしようとするとき
4. 上記以外の場合で、行政庁が相当と認めるとき

### 弁明の機会の付与（13条1項2号）

聴聞が必要な場合以外の不利益処分（営業停止命令など）をしようとするときは、弁明の機会を付与します。

### 意見陳述手続が不要な場合（13条2項）

- 公益上、緊急に不利益処分をする必要があるため、意見陳述手続をとることができないとき
- 一定の資格がないことが判明した場合に必ず不利益処分をすべきことが法令上定められている場合で、その資格の不存在が裁判所の判決書又は決定書などの客観的な資料により直接証明されたとき
- 施設・設備の設置等について技術的な基準が法令で明確に定められている場合で、その不充足が計測・試験等の客観的な認定方法により確認されたとき
- 納付すべき金銭の額を確定し、一定の額の金銭の納付を命じ、又は金銭の給付決定の取消しその他の金銭の給付を制限する不利益処分をしようとするとき
- 当該不利益処分の性質上、それによって課される義務の内容が著しく軽微なものであるため名あて人の意見をあらかじめ聴くことを要しないものとして政令で定める処分をしようとするとき

🎯 **試験で狙われる**：「営業停止命令をするときは聴聞が必要」は誤りです。停止は許認可の取消しではないため、原則は弁明の機会の付与です（ただし行政庁が相当と認めれば聴聞も可）。

## 理由の提示（14条）

行政庁は、不利益処分をする場合には、その名あて人に対し、**同時に**、当該不利益処分の理由を示さなければなりません。ただし、理由を示さないで処分をすべき差し迫った必要がある場合は、この限りでなく、その場合は処分後相当の期間内に理由を示さなければなりません（名あて人の所在が判明しない場合などを除く）。処分を書面でするときは、理由も書面で示します。

**最判平成23年6月7日**（一級建築士免許取消事件）

公表されている処分基準が複雑な内容であるにもかかわらず、処分の原因となる事実と根拠法条を示すだけで、処分基準の適用関係が示されていなかった免許取消処分について、名あて人においていかなる理由に基づいてどのような処分基準の適用によって免許取消処分が選択されたのかを知ることができないとして、行政手続法14条1項本文の定める理由提示の要件を欠き違法であるとしました（要旨）。

## 聴聞の手続

| 段階 | 条 | 内容 |
|---|---|---|
| 通知 | 15条 | 聴聞の期日までに相当な期間をおいて、予定される不利益処分の内容・根拠法令、原因となる事実、期日・場所、担当組織などを**書面**で通知。名あて人の所在不明時は掲示による通知が可能 |
| 代理人 | 16条 | 当事者は代理人を選任できる。代理人の資格は書面で証明 |
| 参加人 | 17条 | 主宰者は、当事者以外の者で処分の根拠法令に照らし利害関係を有するものに、聴聞への参加を求め又は許可できる |
| 文書等の閲覧 | 18条 | 当事者及び自己の利益を害される参加人は、聴聞の通知があった時から聴聞が終結する時までの間、調書その他の資料の閲覧を求めることができる。行政庁は第三者の利益を害するおそれその他正当な理由がなければ拒めない |
| 主宰者 | 19条 | 行政庁が指名する職員その他政令で定める者が主宰。当事者・参加人やその親族などは主宰者になれない |
| 期日の審理 | 20条 | 冒頭で行政庁の職員が処分の内容・根拠法令・原因事実を説明。当事者・参加人は意見を述べ、証拠書類等を提出し、主宰者の許可を得て行政庁の職員に質問できる。補佐人とともに出頭可。原則**非公開** |
| 陳述書 | 21条 | 当事者・参加人は、期日への出頭に代えて陳述書・証拠書類等を提出できる |
| 調書・報告書 | 24条 | 主宰者は聴聞調書を作成し、聴聞終結後速やかに、当事者等の主張に理由があるかどうかについての意見を記載した報告書を作成して、調書とともに行政庁に提出する。当事者・参加人は調書・報告書の閲覧を求めることができる |
| 処分の決定 | 26条 | 行政庁は、調書の内容及び報告書に記載された主宰者の意見を**十分に参酌**して処分を決定する |

⚠️ **つまずきやすい**：文書閲覧請求ができるのは聴聞だけです。弁明の機会の付与には準用されません。また、行政庁は主宰者の意見に拘束されるのではなく、「十分に参酌」すれば足ります。

行政庁又は主宰者が聴聞の節の規定に基づいてした処分又はその不作為については、審査請求をすることができません（27条）。

## 弁明の機会の付与の手続（29条〜31条）

- 弁明は、行政庁が口頭ですることを認めたときを除き、**弁明書**を提出してする（29条1項）
- 弁明をするときは、証拠書類等を提出できる（29条2項）
- 行政庁は、弁明書の提出期限までに相当な期間をおいて、予定される処分の内容・根拠法令、原因事実、弁明書の提出先・提出期限を書面で通知する（30条）
- 代理人の規定などが準用される（31条）

| | 聴聞 | 弁明の機会の付与 |
|---|---|---|
| 対象 | 許認可の取消し・資格の剝奪など重大な処分 | それ以外の不利益処分 |
| 方式 | 口頭審理（期日） | 原則書面（弁明書） |
| 主宰者 | あり | なし |
| 文書閲覧 | あり | なし |
| 参加人 | あり | なし |
| 調書・報告書 | あり | なし |

## よくある勘違い

- ❌「聴聞は原則として公開で行う」→ 行政庁が公開を相当と認めるときを除き、非公開です
- ❌「行政庁は主宰者の報告書の意見に従って処分をしなければならない」→ 十分に参酌すれば足ります
- ❌「処分基準を定めることは行政庁の法的義務である」→ 努力義務です

## 確認問題

**答え：○**
13条1項1号イのとおりです。
</details>

<details>
<summary>【○×】弁明の機会の付与は、行政庁が口頭ですることを認めたときを除き、弁明書を提出してするものとされている。</summary>

**答え：○**
29条1項のとおりです。
</details>

<details>
<summary>【○×】弁明の機会の付与の通知を受けた者は、当該不利益処分の原因となる事実を証する資料の閲覧を求めることができる。</summary>

**答え：×**
文書等の閲覧（18条）は聴聞についての規定で、弁明の機会の付与には準用されていません。
</details>

<details>
<summary>【○×】聴聞の主宰者は、当事者の許可を得て、行政庁の職員に対し質問を発することができる。</summary>

**答え：×**
質問をするのは当事者・参加人で、それには主宰者の許可が必要です（20条2項）。
</details>

**答え：×**
複雑な処分基準の適用関係が示されていない以上、理由提示の要件を欠き違法であるとしました。
