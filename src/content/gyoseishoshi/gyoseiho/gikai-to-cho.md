## このページで学ぶこと

- 議会の議決事件・招集・会議の原則を確認します
- 長と議会の対立を調整する仕組み（再議・不信任・専決処分）を理解します
- ゴール：特別多数決が必要な場面と、執行機関としての委員会・委員を説明できるようになる

> **端的にいうと**：地方公共団体は、住民が直接選ぶ長と議会がそれぞれ民主的正統性をもつ二元代表制です。長は議会の議決に対して再議を求めることができ、議会は長に不信任議決をすることができ、長はこれに対して議会を解散することができます。

## 議会

### 組織

- 議員の定数は条例で定める（90条・91条）
- 議員の任期は4年（93条）
- 町村は、条例で、議会を置かず、選挙権を有する者の総会（町村総会）を設けることができる（94条）
- 議員は、衆議院議員・参議院議員、他の地方公共団体の議員、常勤の職員などと兼職できない（92条）

### 議決事件（96条）

条例の制定改廃、予算を定めること、決算を認定すること、地方税の賦課徴収等、政令で定める基準に従い条例で定める契約の締結、財産の取得・処分（条例で定めるもの）などを議決しなければなりません。条例で、法定受託事務の一部（国の安全に関することなどを除く）を含め、議決事件を追加することができます（96条2項）。

### 調査権（100条）

普通地方公共団体の議会は、当該普通地方公共団体の事務に関する調査を行うことができ、選挙人その他の関係人の出頭及び証言並びに記録の提出を請求することができます（いわゆる百条調査権）。正当な理由がないのに出頭・証言・記録の提出を拒んだときは、罰則があります。

### 招集と会期

| 項目 | 内容 |
|---|---|
| 招集権者 | **長**（101条1項） |
| 定例会 | 毎年、条例で定める回数招集する（102条） |
| 臨時会 | 必要がある場合に、その事件に限り招集する |
| 臨時会の招集請求 | 議長は議会運営委員会の議決を経て、議員は定数の4分の1以上の者により、長に対し、会議に付議すべき事件を示して臨時会の招集を請求できる。長は請求のあった日から**20日以内**に招集しなければならない |
| 長が招集しない場合 | 議長の請求の場合は議長が、議員の請求の場合は議長が（請求した議員の申出に基づき）臨時会を招集できる |
| 通年会期 | 条例で、定例会・臨時会とせず、毎年条例で定める日から翌年の当該日の前日までを会期とすることができる（102条の2） |

### 会議の原則

- **定足数**：議員の定数の半数以上の議員が出席しなければ、会議を開くことができない（113条）
- **議決**：出席議員の過半数で決し、可否同数のときは議長の決するところによる（116条）。議長は議員として議決に加わる権利を有しない
- **会議公開の原則**：会議は公開する。ただし、議長又は議員3人以上の発議により、出席議員の3分の2以上の多数で議決したときは、秘密会を開くことができる（115条）

### 特別多数決が必要な主な場面

| 事項 | 要件 |
|---|---|
| 事務所の位置を定める条例の制定・改廃（4条3項） | 出席議員の3分の2以上の同意 |
| 秘密会の開催（115条） | 出席議員の3分の2以上の多数 |
| 条例・予算についての再議で同じ議決をする（176条3項） | 出席議員の3分の2以上の同意 |
| 議員の資格決定（127条）で資格なしとする | 出席議員の3分の2以上の多数 |
| 議員の除名（135条3項） | 議員の3分の2以上の出席、その4分の3以上の同意 |
| 長の不信任議決（178条3項） | 議員の3分の2以上の出席、その4分の3以上の同意 |
| 解散後初めての議会での再度の不信任議決 | 議員の3分の2以上の出席、その過半数の同意 |
| 主要公務員の解職請求に基づく解職（87条） | 議員の3分の2以上の出席、その4分の3以上の同意 |
| 重要な公の施設の廃止・長期独占利用（244条の2第2項） | 出席議員の3分の2以上の同意 |

## 長

- 都道府県に知事、市町村に市町村長を置く（139条）。任期は4年（140条）
- 被選挙権は、知事は年齢満**30年**以上、市町村長は年齢満**25年**以上の日本国民（公職選挙法10条）。住所要件はない
- 長は、当該普通地方公共団体を統轄し、これを代表し（147条）、その事務を管理し及びこれを執行する（148条）
- 議案の提出、予算の調製・執行、地方税の賦課徴収、決算の議会への提出、会計の監督、財産の取得・管理・処分などを担任する（149条）
- 補助機関として、副知事・副市町村長（議会の同意を得て長が選任）、会計管理者、職員などを置く

## 長と議会の関係

### 再議（176条・177条）

| 種類 | 要件 | 効果 |
|---|---|---|
| 一般的拒否権（176条1項） | 議会の議決について異議があるとき | 長は、送付を受けた日から10日以内に理由を示して再議に付すことができる（任意）。条例の制定改廃・予算に関する議決は、出席議員の3分の2以上の同意で同じ議決をすれば確定 |
| 違法な議決・選挙（176条4項） | 議会の議決又は選挙がその権限を超え又は法令若しくは会議規則に違反すると認めるとき | 長は理由を示して再議に付し又は再選挙を行わせ**なければならない**。なお違法と認めるときは、知事は総務大臣、市町村長は知事に審査を申し立てることができ、さらに裁定に不服があれば裁判所に出訴できる |
| 義務費の削除・減額（177条） | 法令により負担する経費などを削除・減額する議決をしたとき | 長は再議に付さなければならない。なお削除・減額したときは、長はその経費を予算に計上して支出することができる |
| 非常災害対策費等の削除・減額（177条） | 非常の災害による応急・復旧の施設のために必要な経費等を削除・減額したとき | 再議に付さなければならない。なお削除・減額したときは、長はその議決を不信任の議決とみなすことができる |

### 不信任議決と解散（178条）

1. 議会が長の不信任の議決（議員の3分の2以上出席、4分の3以上の同意）をしたときは、議長は直ちにその旨を長に通知する
2. 長は、通知を受けた日から**10日以内**に議会を解散することができる
3. 10日以内に解散しないときは、長は10日を経過した日に**失職**する
4. 解散後初めて招集された議会において再び不信任の議決（議員の3分の2以上出席、過半数の同意）があり、議長から長に通知があったときは、長は通知があった日に失職する

### 専決処分（179条・180条）

**179条（法律による専決処分）**：次の場合には、長は、議会が議決すべき事件について処分（専決処分）をすることができます。

1. 議会が成立しないとき
2. 113条ただし書の場合においてなお会議を開くことができないとき
3. 長において議会の議決すべき事件について特に緊急を要するため議会を招集する時間的余裕がないことが明らかであると認めるとき
4. 議会において議決すべき事件を議決しないとき

ただし、副知事・副市町村長、指定都市の総合区長の選任の同意については、専決処分をすることができません。専決処分をしたときは、次の会議においてこれを議会に報告し、その承認を求めなければなりません。条例の制定改廃又は予算に関する処置について承認を求める議案が否決されたときは、長は、速やかに、必要と認める措置を講ずるとともに、その旨を議会に報告しなければなりません。

**180条（議会の委任による専決処分）**：議会の権限に属する軽易な事項で、その議決により特に指定したものは、長において専決処分にすることができます。この場合は議会への報告で足ります（承認は不要）。

⚠️ **つまずきやすい**：179条の専決処分について議会の承認が得られなくても、専決処分の効力には影響がないと解されています。ただし、条例・予算については、長は必要な措置を講じ議会に報告する義務を負います。

## 執行機関多元主義

普通地方公共団体には、長のほかに、法律の定めるところにより、委員会又は委員を執行機関として置きます（138条の4）。

| 必ず置く委員会・委員 | 都道府県 | 市町村 |
|---|---|---|
| 教育委員会、選挙管理委員会、人事委員会又は公平委員会、監査委員 | ○ | ○ |
| 公安委員会、労働委員会、収用委員会、海区漁業調整委員会、内水面漁場管理委員会 | ○ | — |
| 農業委員会、固定資産評価審査委員会 | — | ○ |

監査委員の定数は、都道府県と政令で定める市は4人、その他の市と町村は2人です（条例で増加可）。識見を有する者と議員のうちから、長が議会の同意を得て選任します（条例で議員のうちから選任しないこともできる）。

🎯 **試験で狙われる**：長の不信任議決は「3分の2以上出席・4分の3以上同意」、解散後の再度の不信任議決は「3分の2以上出席・過半数同意」です。数字の組み合わせを正確に区別しましょう。

## よくある勘違い

- ❌「議会の招集は議長が行う」→ 招集権者は原則として長です
- ❌「長は、議会の議決に異議があるときは、常に再議に付さなければならない」→ 一般的拒否権としての再議は任意です。違法な議決などについては義務です
- ❌「不信任の議決を受けた長が議会を解散しないときは、直ちに失職する」→ 通知を受けた日から10日を経過した日に失職します

## 確認問題

<details>
<summary>【○×】普通地方公共団体の議会の議長は、議会運営委員会の議決を経て、長に対し、臨時会の招集を請求することができ、長は請求のあった日から20日以内に臨時会を招集しなければならない。</summary>

**答え：○**
101条2項・4項のとおりです。
</details>

<details>
<summary>【○×】長の不信任の議決は、議員数の3分の2以上の者が出席し、その4分の3以上の者の同意がなければならない。</summary>

**答え：○**
178条3項のとおりです。
</details>

<details>
<summary>【○×】長は、副知事又は副市町村長の選任の同意について、専決処分をすることができる。</summary>

**答え：×**
179条1項ただし書により、副知事・副市町村長の選任の同意は専決処分の対象外です。
</details>

<details>
<summary>【○×】議会の議決により特に指定された軽易な事項について長が専決処分をしたときは、次の会議において議会の承認を求めなければならない。</summary>

**答え：×**
180条の専決処分は議会への報告で足り、承認は不要です。
</details>
