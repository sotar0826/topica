## このページで学ぶこと

- 行政行為の分類（許可・特許・認可・下命など）と附款の種類を理解します
- 公定力・不可争力・自力執行力・不可変更力の意味を区別します
- ゴール：無効と取消しの区別、職権取消しと撤回の違いを、判例を踏まえて説明できるようになる

> **端的にいうと**：行政行為は、行政庁が法律に基づき、一方的に国民の権利義務を具体的に決める行為です。違法でも取り消されるまでは有効として扱われ（公定力）、争える期間が過ぎれば争えなくなります（不可争力）。ただし、重大かつ明白な瑕疵がある行政行為は初めから無効です。

## 行政行為とは

行政行為とは、行政庁が、法律に基づき、公権力の行使として、特定の国民の権利義務を直接・具体的に決定する行為をいいます（講学上の概念）。行政事件訴訟法上の「処分」とおおむね重なります。

行政立法（一般的・抽象的な定め）、行政契約（双方の合意による）、行政指導（法的拘束力がない）、事実行為は、行政行為に当たりません。

## 行政行為の分類

### 法律行為的行政行為

| 分類 | 種類 | 意味 | 例 |
|---|---|---|---|
| 命令的行為 | 下命・禁止 | 作為・不作為の義務を課す | 違法建築物の除却命令、営業停止 |
| | 許可 | 一般的な禁止を特定の場合に解除する | 自動車運転免許、飲食店営業許可 |
| | 免除 | 作為義務を特定の場合に解除する | 納税の猶予 |
| 形成的行為 | 特許 | 新たな権利・法律上の地位を設定する | 公有水面埋立免許、河川の占用許可、帰化許可 |
| | 認可 | 第三者の法律行為を補充して効力を完成させる | 農地の権利移転の許可、銀行の合併認可 |
| | 代理 | 第三者がすべき行為を行政庁が代わって行う | 土地収用の裁決 |

⚠️ **つまずきやすい**：法令上の名称と講学上の分類は一致しません。農地法3条の「許可」は講学上の認可、河川の「占用許可」は講学上の特許です。名称ではなく、何をする行為かで判断します。

🎯 **試験で狙われる**：許可を受けずにした行為は、処罰の対象にはなっても、私法上の効力は原則として否定されません（無許可営業の売買契約は有効）。これに対し、認可を受けずにした行為は効力を生じません（許可を得ない農地の売買は所有権移転の効力を生じない）。

### 準法律行為的行政行為

1. **確認**：特定の事実・法律関係の存否を公に判断して確定する（当選人の決定、建築確認）
2. **公証**：特定の事実・法律関係の存在を公に証明する（住民票への記載、選挙人名簿への登録）
3. **通知**：特定の事項を知らせる（納税の督促、代執行の戒告）
4. **受理**：他人の行為を有効な行為として受け付ける

## 附款

附款とは、行政行為の主たる内容に付加される従たる意思表示です。法律が附款を付すことを認めている場合か、行政行為の内容の決定に裁量が認められる場合に付すことができ、その目的に照らして必要な限度を超えてはなりません。

| 種類 | 内容 |
|---|---|
| 条件 | 効力の発生・消滅を発生不確実な事実にかからせる |
| 期限 | 効力の発生・消滅を発生確実な事実にかからせる |
| 負担 | 相手方に特別の義務を命じる（道路占用許可に占用料の納付を命じる）。負担を履行しなくても行政行為の効力は当然には失われない |
| 撤回権の留保 | 一定の場合に撤回することがある旨をあらかじめ示す |
| 法律効果の一部除外 | 法律が通常認めている効果の一部を発生させない |

附款だけを対象に取消訴訟を提起できるかは、附款が本体の行政行為と不可分かどうかで判断されます。附款が本体と不可分一体であれば、附款だけの取消しを求めることはできません。

## 行政行為の効力

1. **公定力**：違法な行政行為であっても、権限ある機関（処分庁・審査庁・裁判所）によって取り消されるまでは、有効なものとして扱われる効力。根拠は、取消訴訟という特別の手続が用意されていること（取消訴訟の排他的管轄）に求められる
2. **不可争力**：審査請求期間や出訴期間が経過すると、相手方は行政行為の効力を争えなくなる効力。行政庁が職権で取り消すことは妨げられない
3. **自力執行力**：行政行為で課された義務を相手方が履行しないとき、行政庁が裁判所の判決を得ずに自ら強制執行できる効力。ただし、強制執行には別に法律の根拠が必要
4. **不可変更力**：審査請求に対する裁決のように争訟を裁断する行為について、行政庁自身も取り消し・変更できなくなる効力

公定力は、行政行為の効力を否定するときにだけ働きます。そのため、違法な行政行為によって損害を受けた者が**国家賠償**を請求する場合には、あらかじめ取消訴訟で行政行為を取り消しておく必要はありません。判例も、行政処分の違法を理由として国家賠償を請求するために、あらかじめ取消しや無効確認の判決を得る必要はないとしています（最判昭和36年4月21日の要旨）。

公定力は刑事訴訟にも及ばないと解されています。違法な命令に従わなかったことを理由に起訴された被告人は、刑事訴訟で命令の違法を主張できます。

## 行政行為の瑕疵

### 無効と取消し

行政行為に違法（瑕疵）がある場合、原則として取り消しうる行政行為になり、取り消されるまでは公定力によって有効です。これに対し、瑕疵が**重大かつ明白**である場合には、初めから効力を生じない無効の行政行為となります（重大明白説が判例・通説）。

| | 取り消しうる行政行為 | 無効の行政行為 |
|---|---|---|
| 公定力 | あり | なし |
| 争い方 | 取消訴訟（出訴期間の制限あり） | 無効等確認訴訟・争点訴訟・当事者訴訟（期間制限なし） |
| 不可争力 | 期間経過で生じる | 生じない |

明白性は、処分の外形上、客観的に誤認が一見看取できるかどうかで判断されます。もっとも、課税処分のように第三者の信頼保護を考慮する必要がない場面では、明白性を要件とせずに無効を認めた判例もあります（要旨）。

### 瑕疵の治癒・違法行為の転換・違法性の承継

- **瑕疵の治癒**：行政行為の時点では瑕疵があったが、その後の事情で要件が満たされた場合に、瑕疵がなかったものとして扱うこと。ただし、理由提示の不備を後の審査請求の裁決で補っても治癒されないとするのが判例の考え方です
- **違法行為の転換**：ある行政行為としては違法でも、別の行政行為としてみれば適法である場合に、別の行為として有効と扱うこと
- **違法性の承継**：先行行為の違法を理由に、後行行為の取消しを求めることができるか。原則として認められませんが、先行行為と後行行為が一連の手続を構成し、同一の法効果の実現を目的とする場合（農地買収計画と買収処分など）には認められます

## 職権取消しと撤回

| | 職権取消し | 撤回 |
|---|---|---|
| 理由 | 成立当初から瑕疵がある（原始的瑕疵） | 成立後の事情の変化（後発的事情） |
| 効果 | 原則として遡及する | 将来に向かってのみ |
| 権限をもつ者 | 処分庁（監督庁も可能とする見解が多い） | 処分庁のみ |
| 法律の根拠 | 不要 | 不要（判例） |

授益的な行政行為（許可など）の取消し・撤回は、相手方の既得の利益や信頼を害するため、取消し・撤回によって得られる公益上の必要と、相手方が受ける不利益とを比較衡量して制限されます。

**最判昭和63年6月17日**（実子あっせん指定医師取消事件）

人工妊娠中絶を行う指定医師の指定を受けた医師が、いわゆる実子あっせんを繰り返し行い、刑事罰も受けたことから、指定が撤回された事案です。判例は、撤回によって医師の被る不利益を考慮しても、なお撤回すべき公益上の必要性が高いと認められるから、法令上その撤回について直接明文の規定がなくても、指定を撤回することができるとしました（要旨）。

> **端的にいうと**：撤回も職権取消しも法律の根拠なしにできますが、授益的行政行為の場合は、公益上の必要性と相手方の不利益の比較衡量によって制限されます。

## よくある勘違い

- ❌「違法な行政処分による国家賠償請求には、先に取消判決が必要」→ 不要です（公定力は国家賠償に及ばない）
- ❌「撤回は法律に根拠規定がない限り許されない」→ 判例は明文の規定がなくても撤回を認めています
- ❌「不可争力が生じると、行政庁も職権で取り消せなくなる」→ 不可争力は相手方からの争いを封じるだけです

## 確認問題

<details>
<summary>【○×】農地法3条の許可を受けずにした農地の売買契約は、所有権移転の効力を生じない。</summary>

**答え：○**
同条の許可は講学上の認可であり、許可を受けない行為は効力を生じません。
</details>

<details>
<summary>【○×】行政処分が違法であることを理由に国家賠償を請求するには、あらかじめ当該処分の取消判決を得ておく必要がある。</summary>

**答え：×**
判例は、あらかじめ取消しや無効確認の判決を得る必要はないとしています。
</details>

<details>
<summary>【○×】行政行為の撤回は、原則としてその効果が行政行為の成立時に遡る。</summary>

**答え：×**
撤回は後発的事情を理由とするもので、将来に向かってのみ効力を失わせます。遡及効が原則なのは職権取消しです。
</details>

<details>
<summary>【○×】負担が付された行政行為において、相手方が負担を履行しない場合、行政行為は当然に効力を失う。</summary>

**答え：×**
負担の不履行によって当然に効力が失われるわけではありません。撤回の理由や強制執行の対象になりうるにとどまります。
</details>

<details>
<summary>【○×】判例によれば、行政行為が無効となるのは、原則としてその瑕疵が重大かつ明白な場合である。</summary>

**答え：○**
重大明白説が判例・通説です。
</details>
