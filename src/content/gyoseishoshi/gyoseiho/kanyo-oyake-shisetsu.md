## このページで学ぶこと

- 関与の基本原則（法定主義・一般原則）と基本類型を確認します
- 自治事務と法定受託事務で可能な関与の違いを理解します
- ゴール：国地方係争処理委員会の手続と、公の施設・指定管理者制度を説明できるようになる

> **端的にいうと**：国や都道府県が地方公共団体の事務に関与するには、法律又はこれに基づく政令の根拠が必要で、必要最小限でなければなりません。関与に不服がある地方公共団体は、国地方係争処理委員会に審査を申し出て、さらに高等裁判所に訴えを提起できます。

## 関与の基本原則

- **関与の法定主義**（245条の2）：普通地方公共団体は、その事務の処理に関し、法律又はこれに基づく政令によらなければ、国又は都道府県の関与を受け、又は要することとされることはない
- **関与の基本原則**（245条の3）：関与は、その目的を達成するために必要な最小限度のものとするとともに、普通地方公共団体の自主性及び自立性に配慮しなければならない

### 関与の基本類型（245条）

| 類型 | 自治事務 | 法定受託事務 |
|---|---|---|
| 助言又は勧告 | ○ | ○ |
| 資料の提出の要求 | ○ | ○ |
| 是正の要求 | ○ | — |
| 同意 | 一定の場合 | ○ |
| 許可・認可・承認 | 一定の場合 | ○ |
| 指示 | 一定の場合 | ○（是正の指示） |
| 代執行 | **できない** | ○ |
| 協議 | ○ | ○ |

### 是正の要求・是正の指示

| | 是正の要求（245条の5） | 是正の指示（245条の7） |
|---|---|---|
| 対象 | 主として自治事務 | 法定受託事務 |
| 要件 | 法令の規定に違反しているとき、又は著しく適正を欠き、かつ、明らかに公益を害しているとき | 同左 |
| 効果 | 地方公共団体は、違反の是正又は改善のため必要な措置を講じなければならない（措置の内容は地方公共団体が判断） | 具体的な措置の内容まで指示できる |

市町村の自治事務については、各大臣は都道府県の執行機関に対し、市町村に是正の要求をするよう指示することができます。緊急を要するときその他特に必要があると認めるときは、各大臣が自ら市町村に是正の要求をすることもできます。都道府県の執行機関は、市町村の自治事務について、是正の勧告（245条の6）をすることができます。

### 代執行（245条の8）

法定受託事務の管理・執行が法令に違反するもの又はその管理・執行を怠るものがある場合で、他の方法によって是正を図ることが困難であり、かつ、それを放置することにより著しく公益を害することが明らかであるときは、各大臣は、

1. 文書により勧告
2. 期限までに勧告に係る事項を行わないときは、文書により指示
3. 期限までに指示に係る事項を行わないときは、**高等裁判所**に対し、訴えをもって、当該事項を行うべきことを命ずる旨の裁判を請求
4. 高等裁判所が命ずる旨の裁判をし、期限までに行わないときは、各大臣が代わって当該事項を行う

⚠️ **つまずきやすい**：代執行は法定受託事務についてだけ認められ、自治事務には認められていません。また、行政代執行法上の代執行とは別の制度で、高等裁判所の裁判を経る必要があります。

### 関与の手続

- 助言・勧告・資料の提出の要求・是正の要求などを書面以外の方法でした場合、相手方から書面の交付を求められたときは、これを交付しなければならない（247条〜249条）
- 国の行政機関は、地方公共団体の申請等に係る許認可等の基準を定め、公表しなければならず、標準処理期間を定めるよう努める（250条の2・250条の3）

## 紛争処理

### 国地方係争処理委員会（250条の7以下）

| 項目 | 内容 |
|---|---|
| 設置 | 総務省 |
| 委員 | 5人。優れた識見を有する者のうちから、両議院の同意を得て総務大臣が任命 |
| 審査の対象 | 国の関与のうち是正の要求、許可の拒否その他の処分その他公権力の行使に当たるもの、国の不作為、協議 |
| 申出期間 | 原則として関与があった日から**30日以内** |
| 審査期間 | 審査の申出があった日から**90日以内**に審査・勧告 |
| 結果 | 関与が違法（自治事務については違法又は不当）であると認めるときは、国の行政庁に対し、必要な措置を講ずべきことを勧告 |

### 国の関与に関する訴え（251条の5）

国地方係争処理委員会の審査の結果や勧告に不服があるとき、勧告に対する国の行政庁の措置に不服があるときなどは、地方公共団体の長その他の執行機関は、**高等裁判所**に対し、当該関与の取消し又は国の不作為の違法の確認を求める訴えを提起することができます。審査の申出を経ることが必要です（審査申出前置）。行政事件訴訟法上の機関訴訟に当たります。

### 自治紛争処理委員（251条以下）

都道府県の関与に関する市町村の不服や、地方公共団体相互間の紛争については、事件ごとに、総務大臣又は都道府県知事が任命する自治紛争処理委員が審査・調停を行います（常設の機関ではない）。

### 国等による不作為の違法確認訴訟（251条の7）

是正の要求や是正の指示を受けた地方公共団体が、審査の申出もせず、必要な措置も講じないときは、各大臣は、高等裁判所に対し、当該地方公共団体の不作為の違法の確認を求めることができます。

🎯 **試験で狙われる**：国の関与に関する訴えの第一審は**高等裁判所**です。地方裁判所ではありません。

## 公の施設（244条〜244条の4）

公の施設とは、住民の福祉を増進する目的をもってその利用に供するための施設です（体育館、公民館、図書館、公営住宅、保育所など）。

- 普通地方公共団体（次条の指定管理者を含む）は、**正当な理由がない限り**、住民が公の施設を利用することを拒んではならない（244条2項）
- 住民が公の施設を利用することについて、**不当な差別的取扱い**をしてはならない（244条3項）
- 公の施設の設置及びその管理に関する事項は、**条例**で定めなければならない（244条の2第1項）
- 条例で定める特に重要な公の施設のうち条例で定める特に重要なものを廃止し、又は条例で定める長期かつ独占的な利用をさせようとするときは、議会において出席議員の**3分の2以上**の同意を得なければならない（244条の2第2項）
- 他の地方公共団体と協議して、その区域外にも公の施設を設けることができる（244条の3）

### 指定管理者制度（244条の2第3項以下）

| 項目 | 内容 |
|---|---|
| 指定管理者 | 法人その他の団体であって、当該普通地方公共団体が指定するもの（**個人は不可**） |
| 条例で定める事項 | 指定の手続、管理の基準、業務の範囲その他必要な事項 |
| 指定の手続 | 期間を定めて行い、あらかじめ**議会の議決**を経なければならない |
| 利用料金 | 適当と認めるときは、利用料金を指定管理者の収入として収受させることができる。利用料金は条例の定めるところにより指定管理者が定める（地方公共団体の承認が必要） |
| 監督 | 長等は、指定管理者に報告を求め、調査し、指示をすることができる。指示に従わないときなどは、指定の取消し・業務の停止ができる |

### 利用に関する処分についての審査請求（244条の4）

普通地方公共団体の長以外の機関（指定管理者を含む）がした公の施設を利用する権利に関する処分についての審査請求は、普通地方公共団体の**長**に対してするものとします。

> **端的にいうと**：公の施設は、条例で設置・管理を定め、正当な理由なく利用を拒否できません。管理は議会の議決を経て法人その他の団体を指定管理者に委ねることができます。

## よくある勘違い

- ❌「各大臣は、自治事務の処理が法令に違反しているときは、代執行をすることができる」→ 代執行は法定受託事務のみです
- ❌「国の関与に関する訴えは、地方裁判所に提起する」→ 高等裁判所です
- ❌「指定管理者には個人も指定することができる」→ 法人その他の団体に限られます

## 確認問題

<details>
<summary>【○×】普通地方公共団体は、その事務の処理に関し、法律又はこれに基づく政令によらなければ、国又は都道府県の関与を受けることはない。</summary>

**答え：○**
245条の2の関与の法定主義です。
</details>

<details>
<summary>【○×】国地方係争処理委員会は、審査の申出があった日から90日以内に審査を行い、勧告等をしなければならない。</summary>

**答え：○**
250条の14第5項のとおりです。
</details>

<details>
<summary>【○×】普通地方公共団体は、指定管理者の指定をしようとするときは、あらかじめ議会の議決を経なければならない。</summary>

**答え：○**
244条の2第6項のとおりです。
</details>

<details>
<summary>【○×】指定管理者がした公の施設を利用する権利に関する処分についての審査請求は、当該指定管理者に対してする。</summary>

**答え：×**
244条の4第1項により、普通地方公共団体の長に対してします。
</details>
