## このページで学ぶこと

- 募集株式の発行の決定機関を、公開会社・非公開会社で区別します
- 発行の差止事由と、発行無効の訴えの無効原因を判例とともに理解します
- ゴール：新株予約権と社債の基本的な仕組みを説明できるようになる

> **端的にいうと**：公開会社では、取締役会の決議で募集株式を発行できます（授権資本制度）が、特に有利な払込金額で発行するには株主総会の特別決議が必要です。非公開会社では、株主総会の特別決議が原則です。法令・定款違反や著しく不公正な方法による発行は、株主が差止めを請求できます。

## 募集株式の発行等の決定

募集株式の発行等には、新株の発行と自己株式の処分が含まれます（199条1項）。

| | 公開会社 | 非公開会社 |
|---|---|---|
| 募集事項の決定（原則） | **取締役会**の決議（201条1項） | 株主総会の**特別決議**（199条2項、309条2項5号） |
| 決定の委任 | — | 株主総会の特別決議により、募集株式の数の上限と払込金額の下限を定めて取締役（会）に委任できる（委任の有効期間は1年） |
| 有利発行（払込金額が募集株式を引き受ける者に特に有利な金額である場合） | 株主総会の**特別決議**。取締役は、株主総会で有利な払込金額で募集することを必要とする理由を説明しなければならない | 同左 |
| 株主への通知・公告 | 払込期日（期間の初日）の**2週間前**までに、募集事項を株主に通知又は公告（201条3項・4項） | — |
| 株主割当て | 取締役会の決議 | 株主総会の特別決議（定款で取締役（会）の決定とすることも可） |

公開会社の発行可能株式総数は、定款変更により増加する場合でも、発行済株式の総数の**4倍**を超えることができません（113条3項）。

### 支配株主の異動を伴う募集株式の発行（206条の2）

公開会社が、募集株式の引受人が総株主の議決権の**2分の1**を超える議決権を有することとなる募集株式の割当てをする場合には、払込期日の2週間前までに、株主に対し、当該引受人の氏名等を通知・公告しなければなりません。総株主の議決権の**10分の1**以上を有する株主が反対する旨を通知したときは、原則として、株主総会の普通決議による承認を受けなければなりません。

### 出資の履行

- 募集株式の引受人は、払込期日又は払込期間内に、払込金額の全額を払い込まなければならない（208条1項）
- 出資の履行をしないときは、募集株式の株主となる権利を**失う**（208条5項）
- 引受人は、払込期日に、又は払込期間を定めた場合には出資の履行をした日に、株主となる（209条）
- 現物出資の場合は、原則として検査役の調査が必要（207条。少額・市場価格のある有価証券・弁護士等の証明などの例外は設立の場合と同様）

## 募集株式の発行の差止め（210条）

次の場合において、株主が**不利益を受けるおそれ**があるときは、株主は、株式会社に対し、募集株式の発行等をやめることを請求することができます。

1. 当該募集株式の発行等が**法令又は定款に違反**する場合
2. 当該募集株式の発行等が**著しく不公正な方法**により行われる場合

著しく不公正な方法による発行の典型は、会社の支配権をめぐる争いがある場合に、現経営陣が自己の支配権を維持・強化することを主要な目的として発行する場合です（いわゆる**主要目的ルール**として裁判例上用いられている判断枠組み）。

## 募集株式の発行等の無効の訴え（828条1項2号・3号）

| 事項 | 内容 |
|---|---|
| 提訴期間 | 株式の発行の効力が生じた日から、**公開会社は6か月以内**、**非公開会社は1年以内** |
| 提訴権者 | 株主等（株主、取締役、監査役、執行役、清算人） |
| 判決の効力 | 対世効あり。将来に向かってのみ効力を有する（遡及効なし） |

### 無効原因に関する判例

| 判例 | 要旨 |
|---|---|
| 最判平成9年1月28日 | 公開会社において、募集事項の公示（通知・公告）を欠くことは、株主が差止めの機会を奪われることになるから、**差止事由がないためにこれを欠いても差止めが許容されない場合でない限り**、新株発行の無効原因となる |
| 最判平成24年4月24日 | **非公開会社**において、株主総会の特別決議を経ないまま株主割当て以外の方法による募集株式の発行がされた場合には、その発行手続には重大な法令違反があり、無効原因となる。株主総会から委任を受けた取締役会が、委任の範囲を超えて新株予約権の行使条件を変更した場合、その条件に反した新株予約権の行使による株式の発行も、無効原因がある |

一般に、公開会社において、取締役会の決議を経ずに代表取締役が新株を発行した場合や、有利発行について株主総会の特別決議を経なかった場合、著しく不公正な方法による発行の場合でも、発行された株式が既に流通している可能性があることから、取引の安全を重視して、無効原因にはならないとするのが判例の傾向です。

⚠️ **つまずきやすい**：非公開会社は既存株主の持株比率の維持に強い利益をもつため、株主総会決議を欠く発行は無効原因となります。公開会社で取締役会決議を欠く発行とは結論が異なります。

## 新株予約権

新株予約権とは、株式会社に対して行使することにより当該株式会社の株式の交付を受けることができる権利をいいます（2条21号）。

- 募集新株予約権の発行の決定機関は、募集株式の発行と同様（公開会社は取締役会、非公開会社は株主総会の特別決議。有利発行は株主総会の特別決議）
- 新株予約権無償割当てもできる（277条）
- 新株予約権付社債は、新株予約権を付した社債である

## 社債

社債とは、会社法の規定により会社が行う割当てにより発生する当該会社を債務者とする金銭債権であって、募集事項の定めに従い償還されるものをいいます（2条23号）。株式会社だけでなく、持分会社も発行できます。

| 事項 | 内容 |
|---|---|
| 発行の決定 | 取締役会設置会社では、募集社債の総額その他の重要な事項は**取締役会**が決定（362条4項5号）。代表取締役に委任できない |
| 社債管理者（702条） | 社債を発行する場合には、原則として、社債管理者（銀行、信託会社等）を定め、社債権者のために、弁済の受領、債権の保全その他の社債の管理を行うことを委託しなければならない。各社債の金額が1億円以上である場合などは不要 |
| 社債管理補助者（714条の2） | 社債管理者を定めることを要しない場合には、社債管理補助者を定めることができる |
| 社債権者集会（715条〜） | 社債の種類ごとに組織され、会社法に規定する事項及び社債権者の利害に関する事項について決議をすることができる。決議は、**裁判所の認可**を受けなければ、その効力を生じない |
| 社債原簿 | 社債を発行した日以後遅滞なく、社債原簿を作成しなければならない |

| | 株式 | 社債 |
|---|---|---|
| 法的地位 | 会社の構成員（社員） | 会社の債権者 |
| 経営への参加 | 議決権あり | なし |
| 利益の分配 | 剰余金の配当（分配可能額の範囲内） | 利息（分配可能額と無関係に支払義務） |
| 元本の返還 | なし（自己株式の取得等の場合を除く） | 償還期限に償還 |
| 解散時 | 債権者に劣後して残余財産の分配 | 株主に優先して弁済 |

🎯 **試験で狙われる**：社債権者集会の決議は、裁判所の認可を受けなければ効力を生じません。また、社債は株式会社だけでなく、合名会社・合資会社・合同会社も発行できます。

## よくある勘違い

- ❌「公開会社が募集株式を発行するには、常に株主総会の特別決議が必要である」→ 原則は取締役会決議で、特別決議が必要なのは有利発行の場合です
- ❌「募集株式の発行等の無効の訴えは、非公開会社でも6か月以内に提起しなければならない」→ 非公開会社は1年以内です
- ❌「社債を発行できるのは株式会社に限られる」→ 持分会社も発行できます
