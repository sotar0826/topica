## このページで学ぶこと

- 機関設計のルールと、株主総会の招集・決議要件を確認します
- 取締役会の決議事項と、競業取引・利益相反取引の規制を判例とともに理解します
- ゴール：役員の会社に対する責任・第三者に対する責任と、株主代表訴訟の要件を説明できるようになる

> **端的にいうと**：すべての株式会社には株主総会と取締役が必要です。公開会社は取締役会を置かなければならず、取締役会設置会社では、重要な財産の処分や多額の借財などの重要な業務執行の決定を代表取締役に委任できません。取締役が任務を怠ったときは会社に対して損害賠償責任を負い、株主は代表訴訟によってその責任を追及できます。

## 機関設計

| ルール | 条文 |
|---|---|
| すべての株式会社は、株主総会と1人以上の取締役を置く | 295条、326条1項 |
| **公開会社**、監査役会設置会社、監査等委員会設置会社、指名委員会等設置会社は、**取締役会**を置かなければならない | 327条1項 |
| 取締役会設置会社は、原則として監査役を置かなければならない（監査等委員会設置会社・指名委員会等設置会社及び非公開の会計参与設置会社を除く） | 327条2項 |
| 会計監査人設置会社は、監査役を置かなければならない（監査等委員会設置会社・指名委員会等設置会社を除く） | 327条3項 |
| **大会社**（資本金5億円以上又は負債200億円以上）は、会計監査人を置かなければならない | 328条 |
| 公開会社である大会社は、監査役会及び会計監査人（又は監査等委員会・指名委員会等）を置かなければならない | 328条1項 |

## 株主総会

### 権限（295条）

- 取締役会設置会社でない会社：会社法に規定する事項及び株式会社の組織、運営、管理その他株式会社に関する**一切の事項**について決議できる
- 取締役会設置会社：会社法に規定する事項及び**定款で定めた事項**に限り決議できる

### 招集（296条〜299条）

| 事項 | 内容 |
|---|---|
| 招集権者 | 原則として取締役（取締役会設置会社では取締役会の決議に基づき代表取締役） |
| 少数株主による招集請求 | 総株主の議決権の100分の3以上を6か月前から引き続き有する株主（非公開会社は保有期間要件なし）は、取締役に招集を請求でき、遅滞なく招集手続が行われない場合等は、裁判所の許可を得て自ら招集できる |
| 招集通知の発送期限 | 公開会社は株主総会の日の**2週間前**まで。非公開会社は**1週間前**まで（取締役会設置会社以外の会社は定款でさらに短縮可） |
| 書面による通知 | 取締役会設置会社、書面投票・電子投票を認める場合は書面（又は電磁的方法）で通知 |
| 招集手続の省略（300条） | 株主の全員の同意があるときは、招集の手続を経ることなく開催できる（書面投票・電子投票を定めた場合を除く） |

### 決議要件（309条）

| 決議 | 要件 | 主な決議事項 |
|---|---|---|
| 普通決議 | 議決権を行使することができる株主の議決権の**過半数**を有する株主が出席し、出席株主の議決権の**過半数**（定足数は定款で排除・変更可。役員の選任・解任は3分の1未満にできない） | 取締役・監査役の選任、取締役の解任（累積投票によって選任された取締役を除く）、計算書類の承認、剰余金の配当 |
| 特別決議 | 議決権の過半数を有する株主が出席し（定款で3分の1まで軽減可）、出席株主の議決権の**3分の2以上** | 定款変更、事業譲渡、合併・会社分割・株式交換・株式移転、監査役の解任、株式の併合、非公開会社の募集株式の発行、特定の株主からの自己株式取得、資本金の額の減少（原則）など |
| 特殊決議 | 議決権を行使することができる株主の半数以上であって、当該株主の議決権の3分の2以上 等 | 全部の株式を譲渡制限株式とする定款変更など |

株主総会の目的である事項について提案があった場合において、株主の全員が書面又は電磁的記録により同意の意思表示をしたときは、その提案を可決する旨の株主総会の決議があったものとみなされます（**書面決議**、319条）。

### 決議の瑕疵を争う訴え

| 訴え | 原因 | 提訴期間 |
|---|---|---|
| 決議取消しの訴え（831条） | ①招集の手続又は決議の方法が法令若しくは定款に違反し、又は著しく不公正なとき、②決議の内容が**定款**に違反するとき、③特別の利害関係を有する者が議決権を行使したことによって、著しく不当な決議がされたとき | 決議の日から**3か月以内** |
| 決議無効確認の訴え（830条2項） | 決議の内容が**法令**に違反すること | 制限なし |
| 決議不存在確認の訴え（830条1項） | 決議が存在しないこと | 制限なし |

招集の手続又は決議の方法が法令又は定款に違反するときであっても、裁判所は、その違反する事実が**重大でなく**、かつ、**決議に影響を及ぼさないもの**であると認めるときは、取消しの請求を棄却することができます（**裁量棄却**、831条2項）。

⚠️ **つまずきやすい**：決議の内容が「定款」に違反する場合は取消事由、「法令」に違反する場合は無効事由です。

## 取締役

| 事項 | 内容 |
|---|---|
| 員数 | 1人以上。取締役会設置会社では**3人以上**（331条5項） |
| 任期（332条） | 選任後**2年以内**に終了する事業年度のうち最終のものに関する定時株主総会の終結の時まで。非公開会社（監査等委員会設置会社・指名委員会等設置会社を除く）は定款で**10年**まで伸長可 |
| 選任・解任（329条・339条） | 株主総会の普通決議。解任は**いつでも**できるが、正当な理由がない解任には損害賠償責任が生じうる |
| 欠格事由（331条） | 法人、会社法等の罪により刑に処せられ一定期間を経過しない者など（成年被後見人・被保佐人も一定の手続を経て就任可） |
| 報酬（361条） | 定款又は株主総会の決議で定める（お手盛り防止） |

公開会社では、取締役が株主でなければならない旨を定款で定めることはできません（331条2項）。

### 取締役会（362条）

取締役会は、①業務執行の決定、②取締役の職務の執行の監督、③代表取締役の選定及び解職を行います。次の事項その他の**重要な業務執行の決定**を取締役に委任することはできません（362条4項）。

1. **重要な財産の処分及び譲受け**
2. **多額の借財**
3. 支配人その他の重要な使用人の選任及び解任
4. 支店その他の重要な組織の設置、変更及び廃止
5. 社債を引き受ける者の募集に関する重要な事項
6. 内部統制システムの整備
7. 定款の定めに基づく役員等の責任の一部免除

| 判例 | 要旨 |
|---|---|
| 最判平成6年1月20日 | 「重要な財産の処分」に当たるかどうかは、当該財産の価額、その会社の総資産に占める割合、当該財産の保有目的、処分行為の態様及び会社における従来の取扱い等の事情を**総合的に考慮**して判断すべき |
| 最判昭和40年9月22日 | 代表取締役が、取締役会の決議を経てすることを要する対外的な個々的取引行為を、決議を経ないでした場合でも、その取引行為は、内部的意思決定を欠くにとどまるから、原則として有効であって、ただ、相手方が決議を経ていないことを**知り又は知り得べかりしとき**に限って、無効である |

取締役会の決議は、議決に加わることができる取締役の過半数が出席し、その過半数をもって行います。決議について**特別の利害関係を有する取締役は、議決に加わることができません**（369条）。

### 代表取締役（349条）

代表取締役は、株式会社の業務に関する一切の裁判上又は裁判外の行為をする権限を有し、この権限に加えた制限は、善意の第三者に対抗することができません。社長、副社長その他株式会社を代表する権限を有するものと認められる名称を付した取締役がした行為については、会社は、善意の第三者に対してその責任を負います（**表見代表取締役**、354条）。

### 競業取引・利益相反取引（356条・365条）

取締役が次の取引をしようとするときは、株主総会（取締役会設置会社では**取締役会**）において、当該取引につき重要な事実を開示し、その承認を受けなければなりません。

1. **競業取引**：自己又は第三者のために株式会社の事業の部類に属する取引をしようとするとき
2. **直接取引**：自己又は第三者のために株式会社と取引をしようとするとき
3. **間接取引**：株式会社が取締役の債務を保証することその他取締役以外の者との間において株式会社と当該取締役との利益が相反する取引をしようとするとき

取締役会設置会社では、これらの取引をした取締役は、取引後遅滞なく、取引についての重要な事実を取締役会に報告しなければなりません（365条2項）。

**最大判昭和43年12月25日**

取締役個人の債務について、取締役が会社を代表して債権者に対して債務引受けをする行為は、利益相反取引（間接取引）に当たるとし、承認を受けないでした取引は、会社と取締役の間では無効であるが、会社は、第三者に対しては、その取引について承認を受けなかったことのほか、相手方である第三者が承認を受けなかったことについて**悪意**であることを主張・立証して初めて、その無効をその相手方である第三者に主張することができるとしました（**相対的無効説**。要旨）。

## 役員等の責任

### 会社に対する責任（423条）

取締役、会計参与、監査役、執行役又は会計監査人（役員等）は、その任務を怠ったときは、株式会社に対し、これによって生じた損害を賠償する責任を負います。

- 承認を受けないで競業取引をしたときは、取引によって取締役又は第三者が得た利益の額は、損害の額と推定される（423条2項）
- 利益相反取引によって会社に損害が生じたときは、当該取締役、取引をすることを決定した取締役、承認の決議に賛成した取締役は、任務を怠ったものと推定される（423条3項）
- 自己のために直接取引をした取締役は、任務を怠ったことが自己の責めに帰することができない事由によるものであることをもって責任を免れることができない（**無過失責任**、428条）

**最判平成22年7月15日**（アパマンショップ事件）

事業再編計画の一環として子会社株式を買い取る際の価格の決定について、その決定の過程、内容に**著しく不合理な点がない限り**、取締役としての善管注意義務に違反するものではないとしました（経営判断の原則。要旨）。

### 責任の免除

| 方法 | 要件 |
|---|---|
| 全部免除（424条） | **総株主の同意** |
| 一部免除（425条） | 職務を行うにつき善意でかつ重大な過失がないときに、株主総会の特別決議 |
| 定款に基づく一部免除（426条） | 取締役会決議等（定款の定めが必要） |
| 責任限定契約（427条） | 非業務執行取締役等との間で、定款の定めに基づき締結 |

### 株主代表訴訟（847条）

| 要件 | 内容 |
|---|---|
| 原告 | 6か月前から引き続き株式を有する株主（**公開会社**の場合。非公開会社は保有期間要件なし）。単元未満株主は定款で排除可 |
| 提訴請求 | まず会社に対し、書面等で責任追及等の訴えの提起を請求する |
| 提訴 | 会社が請求の日から**60日以内**に訴えを提起しないときは、株主は会社のために訴えを提起できる（回復することができない損害が生ずるおそれがある場合は直ちに提訴可） |
| 訴額 | 財産権上の請求でない請求に係る訴えとみなされ、手数料は一律（13,000円） |

### 第三者に対する責任（429条）

役員等がその職務を行うについて**悪意又は重大な過失**があったときは、当該役員等は、これによって第三者に生じた損害を賠償する責任を負います。

**最大判昭和44年11月26日**

本条の責任は、第三者保護のために法律が特別に定めた責任（**法定責任説**）であり、取締役がその職務を行うについて悪意又は重大な過失により会社に対する任務を懈怠し、これによって第三者に損害を被らせたときは、取締役の任務懈怠の行為と第三者の損害との間に相当の因果関係がある限り、会社がこれによって損害を被った結果、ひいて第三者に損害を生じた場合（間接損害）であると、直接第三者が損害を被った場合（直接損害）であるとを問うことなく、当該取締役が直接に第三者に対し損害賠償の責に任ずべきとしました（要旨）。

## 監査役・会計監査人等

| 機関 | 主な内容 |
|---|---|
| 監査役（381条〜） | 取締役の職務の執行を監査する（業務監査＋会計監査）。任期は**4年**（非公開会社は定款で10年まで伸長可。短縮不可）。株式会社・子会社の取締役・使用人等を兼ねることができない。非公開会社（監査役会設置会社・会計監査人設置会社を除く）は、定款で監査の範囲を会計に関するものに限定できる |
| 監査役会（390条〜） | 監査役**3人以上**で、そのうち**半数以上**は社外監査役 |
| 会計監査人（396条〜） | 計算書類等を監査する。**公認会計士又は監査法人**でなければならない。任期は1年（定時株主総会で別段の決議がなければ再任されたものとみなす） |
| 会計参与（374条〜） | 取締役と共同して計算書類等を作成する。公認会計士・監査法人又は税理士・税理士法人 |
| 指名委員会等設置会社 | 指名委員会・監査委員会・報酬委員会（各委員会は委員3人以上、過半数が社外取締役）と執行役を置く |
| 監査等委員会設置会社 | 監査等委員である取締役（3人以上、過半数が社外取締役）で構成する監査等委員会を置く |

🎯 **試験で狙われる**：取締役の任期は原則2年、監査役の任期は原則4年で、監査役の任期は定款によっても短縮できません。非公開会社ではいずれも定款で10年まで伸長できます。

## よくある勘違い

- ❌「取締役会設置会社の株主総会は、株式会社に関する一切の事項について決議できる」→ 法律と定款で定めた事項に限られます
- ❌「決議の内容が法令に違反する株主総会決議は、取消しの訴えによって争う」→ 内容の法令違反は無効確認の訴えです
- ❌「取締役会の決議を経ずに代表取締役がした重要な財産の処分は、常に無効である」→ 原則有効で、相手方が知り又は知り得べかりしときに限り無効です

## 確認問題

<details>
<summary>【○×】公開会社は、取締役会を置かなければならない。</summary>

**答え：○**
会社法327条1項1号のとおりです。
</details>

<details>
<summary>【○×】株主総会の決議取消しの訴えは、決議の日から6か月以内に提起しなければならない。</summary>

決議の日から3か月以内です（831条1項）。
</details>

<details>
<summary>【○×】取締役会設置会社の取締役が自己のために会社と取引をしようとするときは、取締役会において重要な事実を開示し、その承認を受けなければならない。</summary>

**答え：○**
会社法356条1項2号・365条1項のとおりです。
</details>

<details>
<summary>【○×】判例によれば、会社法429条1項の責任は、直接損害の場合に限られ、会社が損害を被った結果第三者に損害が生じた間接損害の場合には及ばない。</summary>

**答え：×**
最大判昭和44年11月26日は、直接損害・間接損害のいずれも含むとしました。
</details>
