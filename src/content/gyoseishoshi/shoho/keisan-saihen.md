## このページで学ぶこと

- 剰余金の配当の手続と、分配可能額を超える配当の責任を確認します
- 事業譲渡と組織再編（合併・会社分割・株式交換・株式移転）の手続を比較します
- ゴール：簡易組織再編・略式組織再編と、組織再編の無効の訴えを説明できるようになる

> **端的にいうと**：剰余金の配当は、分配可能額の範囲内で、原則として株主総会の普通決議によって行います。合併や会社分割などの組織再編には、原則として株主総会の特別決議と債権者保護手続が必要で、反対株主には株式買取請求権が認められます。

## 計算

### 計算書類（435条〜）

株式会社は、各事業年度に係る計算書類（貸借対照表、損益計算書、株主資本等変動計算書、個別注記表）及び事業報告並びにこれらの附属明細書を作成しなければなりません。計算書類は、定時株主総会の**承認**を受けなければなりません（438条2項）。ただし、会計監査人設置会社で一定の要件を満たす場合には、取締役会の承認で確定し、定時株主総会には報告で足ります（439条）。

貸借対照表（大会社は損益計算書も）は、定時株主総会の終結後遅滞なく、公告しなければなりません（440条1項）。

### 資本金と準備金

- 株式会社の資本金の額は、原則として、設立又は株式の発行に際して株主となる者が当該株式会社に対して払込み又は給付をした財産の額とする（445条1項）
- 払込み又は給付に係る額の**2分の1**を超えない額は、資本金として計上しないことができる（資本準備金として計上）（445条2項・3項）
- 剰余金の配当をする場合には、配当により減少する剰余金の額の**10分の1**を、資本準備金又は利益準備金として計上しなければならない（準備金の額が資本金の額の4分の1に達するまで）（445条4項）
- 資本金・準備金の額を減少するには、原則として**債権者保護手続**（異議を述べることができる旨の公告・催告）が必要（449条）

## 剰余金の配当

| 事項 | 内容 |
|---|---|
| 決定機関（454条） | 株主総会の**普通決議**（現物配当で金銭分配請求権を与えない場合は特別決議） |
| 中間配当（454条5項） | 取締役会設置会社は、一事業年度の途中において1回に限り、取締役会の決議によって金銭による剰余金の配当をすることができる旨を定款で定めることができる |
| 取締役会への授権（459条） | 会計監査人設置会社で、取締役の任期が1年以内であるなど一定の要件を満たす会社は、定款で、剰余金の配当等を取締役会が定めることができる旨を定められる |
| 純資産額による制限（458条） | 純資産額が**300万円**を下回る場合には、剰余金の配当をすることができない |
| 財源規制（461条） | 剰余金の配当により株主に対して交付する金銭等の帳簿価額の総額は、効力発生日における**分配可能額**を超えてはならない |

### 分配可能額を超える配当（違法配当）の責任（462条・463条）

| 責任を負う者 | 責任の内容 |
|---|---|
| 金銭等の交付を受けた株主 | 交付を受けた金銭等の帳簿価額に相当する金銭を支払う義務（**善意・悪意を問わない**） |
| 業務執行者（当該行為に関する職務を行った業務執行取締役等）、株主総会・取締役会に議案を提案した取締役 | 株主と連帯して支払義務を負う。ただし、その職務を行うについて**注意を怠らなかったことを証明**した場合は責任を負わない（過失責任） |

- 業務執行者等の責任は、総株主の同意があっても、行為時の**分配可能額を超える部分**については免除することができない（462条3項）
- 業務執行者等が義務を履行した場合、**善意の株主**に対しては求償することができない（463条1項）
- 会社債権者は、株主に対し、交付を受けた金銭等の帳簿価額（債権額が上限）に相当する金銭を自己に支払わせることができる（463条2項）

## 事業譲渡（467条）

次の行為をする場合には、効力発生日の前日までに、株主総会の**特別決議**による承認を受けなければなりません。

1. 事業の**全部**の譲渡
2. 事業の**重要な一部**の譲渡（譲渡資産の帳簿価額が総資産額の5分の1を超えないものを除く）
3. 子会社の株式等の全部又は一部の譲渡で一定の要件を満たすもの
4. 他の会社の事業の**全部**の譲受け
5. 事業の全部の賃貸、事業の全部の経営の委任 など

反対株主には株式買取請求権が認められます（469条）。他方、事業譲渡では、債務は個別に移転させる必要があり（債権者の承諾が必要）、債権者保護手続は設けられていません。

譲受会社が譲渡会社の商号を引き続き使用する場合には、譲受会社も譲渡会社の事業によって生じた債務を弁済する責任を負います（会社法22条1項）。

## 組織再編

| 行為 | 内容 |
|---|---|
| 吸収合併 | 会社が他の会社とする合併であって、合併により消滅する会社の権利義務の全部を合併後存続する会社に承継させるもの |
| 新設合併 | 2以上の会社がする合併であって、合併により消滅する会社の権利義務の全部を合併により設立する会社に承継させるもの |
| 吸収分割 | 株式会社又は合同会社がその事業に関して有する権利義務の全部又は一部を分割後他の会社に承継させること |
| 新設分割 | 1又は2以上の株式会社又は合同会社がその事業に関して有する権利義務の全部又は一部を分割により設立する会社に承継させること |
| 株式交換 | 株式会社がその発行済株式の全部を他の株式会社又は合同会社に取得させること（完全親子会社関係の創設） |
| 株式移転 | 1又は2以上の株式会社がその発行済株式の全部を新たに設立する株式会社に取得させること |
| 株式交付 | 株式会社が他の株式会社をその子会社とするために当該他の株式会社の株式を譲り受け、その対価として自社株式を交付すること |

### 共通する手続

| 手続 | 内容 |
|---|---|
| 契約・計画の作成 | 合併契約、吸収分割契約、新設分割計画、株式交換契約、株式移転計画 |
| 事前開示 | 契約等の内容を記載した書面等を本店に備え置く |
| 株主総会の承認 | 原則として**特別決議** |
| 反対株主の株式買取請求 | 認められる |
| 債権者保護手続 | 合併では必要。会社分割では分割後に分割会社に債務の履行を請求できない債権者等について必要。株式交換・株式移転では原則不要 |
| 登記 | 吸収型は効力発生日に効力発生。新設型は設立の登記によって効力発生 |
| 事後開示 | 効力発生後、一定事項を記載した書面等を備え置く |

### 簡易組織再編・略式組織再編

- **簡易組織再編**：存続会社等が交付する対価の額が存続会社等の純資産額の**5分の1**を超えない場合などは、存続会社等の株主総会決議を省略できる（796条2項など）
- **略式組織再編**：一方の会社が他方の会社の総株主の議決権の**10分の9**以上を有する場合（特別支配会社）、支配される側の会社の株主総会決議を省略できる（784条1項、796条1項）

### 会社分割と詐害行為取消権

**最判平成24年10月12日**

株式会社を設立する新設分割がされた場合において、新設分割設立株式会社にその債権に係る債務が承継されず、新設分割について異議を述べることもできない新設分割株式会社の債権者は、民法424条の規定により、詐害行為取消権を行使して新設分割を取り消すことができるとしました（要旨）。現行法では、残存債権者は、承継会社等に対して、承継した財産の価額を限度として債務の履行を請求できる旨の規定（759条4項、764条4項など）も設けられています。

### 組織再編の無効の訴え（828条）

組織再編の無効は、効力が生じた日から**6か月以内**に、訴えをもってのみ主張することができます。無効判決は対世効を有し、将来に向かってのみ効力を有します。

🎯 **試験で狙われる**：簡易組織再編は「5分の1」、略式組織再編は「10分の9」です。事業譲渡では債権者保護手続がなく、合併では必要という違いも頻出です。

## 解散と清算

| 事項 | 内容 |
|---|---|
| 解散事由（471条） | 定款で定めた存続期間の満了、定款で定めた解散事由の発生、株主総会の特別決議、合併（消滅会社）、破産手続開始の決定、解散を命ずる裁判 |
| 休眠会社のみなし解散（472条） | 最後の登記から**12年**を経過した株式会社は、法務大臣の公告から2か月以内に届出をしないときは、解散したものとみなされる |
| 会社の継続（473条） | 存続期間の満了・解散事由の発生・株主総会決議による解散の場合は、清算が結了するまで、株主総会の特別決議によって会社を継続できる |
| 清算（475条〜） | 解散した会社は清算をしなければならず、清算の目的の範囲内において、清算が結了するまではなお存続するものとみなされる |

## よくある勘違い

- ❌「剰余金の配当は、取締役会設置会社では取締役会の決議によって行う」→ 原則は株主総会の普通決議です（中間配当や459条の授権の場合を除く）
- ❌「違法配当を受けた株主は、善意であれば返還義務を負わない」→ 株主は善意・悪意を問わず支払義務を負います
- ❌「事業譲渡にも、合併と同様に債権者保護手続が必要である」→ 事業譲渡には債権者保護手続はありません
