## このページで学ぶこと

- 管財人の職務の全体像と、各局面で申立代理人に求められる協力を学びます
- 管財人面接・債権者集会の実際を学びます
- ゴール：管財人を「対立相手」ではなく「最短で免責に至るための協働相手」として扱えるようになる

> **端的にいうと**：管財人の心証は免責意見（250条）に直結します。申立代理人の仕事は、管財人が**追加調査なしで職務を遂行できる状態**を作ること。資料は「求められる前に出す」が鉄則です。

## 管財人の職務

| 職務 | 内容 | 申立代理人の対応 |
|---|---|---|
| 財産の占有・管理（79条） | 財団財産の占有取得・現況確認 | 鍵・通帳・権利証の即時引き継ぎ |
| **換価**（184条以下） | 任意売却・債権回収・訴訟追行 | 買い手候補・債務者の情報提供 |
| **調査** | 財産状況・否認対象行為・役員責任の調査 | 説明義務（40条）の履行補助 |
| 否認権の行使（160条以下） | 流出財産の回復 | 対象行為の経緯説明 |
| 債権調査 | 届出債権の認否 | 債権者一覧の正確性が前提 |
| **配当** | 財団債権の弁済→破産債権への配当 | — |
| **免責に関する調査・意見**（250条） | 個人破産での免責相当性の調査 | 改善状況の報告・裏付け提出 |

## 管財人面接

開始決定の前後（東京では申立て後・開始決定前に行う運用）に、管財人・申立代理人・破産者本人の三者で行われます。

**準備すべきこと**

- 申立書一式の論点（要説明事項）を代理人側で先に整理したメモ
- 現金・通帳・実印・カード類の引き継ぎ（その場で引き継げる状態で臨む）
- 自由財産拡張の希望と疎明資料
- 免責上の問題（4号事由等）についての本人の説明のリハーサル——本人が自分の言葉で、金額・期間を正確に説明できるようにしておく

⚠️ **実務の落とし穴**：面接で本人が代理人の同席に安心して「いや、実は……」と**申立書に書いていない事実**を話し出すのが最悪のパターンです。受任段階の聴取で全部出し切り、申立書と本人の認識を一致させてから面接に臨むこと。面接は「答え合わせ」の場であって「新事実が出る」場ではありません。

## 債権者集会

- 第1回は開始決定から約3か月後に設定されるのが標準。管財人が財産状況を報告（158条）
- 換価未了なら**続行期日**（さらに3か月後）が重ねられる
- 破産者には**出頭・説明義務**がある。申立代理人は同行し、債権者からの質問への対応を補助
- 消費者破産では債権者の出席はまれだが、個人債権者（親族・知人・被害感情のある相手）がいる事案では質問・紛糾がありうるため、想定問答を準備する

## 手続の終わり方

| 終局 | 場面 |
|---|---|
| **異時廃止**（217条） | 財団から手続費用を支弁できないことが判明（配当なし）。個人の少額管財の多数はこれ |
| 配当→**終結**（220条） | 配当可能な財団が形成された場合 |
| 免責許可決定（個人） | 廃止・終結の前後に免責の判断 |

## 📋 実務チェックリスト（管財人対応）

- [ ] 引き継ぎセット（通帳・印鑑・カード・保険証券・車検証・鍵）の準備
- [ ] 申立書の要説明事項の整理メモ
- [ ] 本人の説明リハーサル（免責上の問題点）
- [ ] 自由財産拡張の申出と疎明資料
- [ ] 管財人からの追加調査依頼への即応体制（期限厳守）
- [ ] 債権者集会の日程確保と本人への出頭指導
- [ ] 個人債権者がいる場合の想定問答
- [ ] 免責観察対応（家計収支表の月次報告）が必要な事案の管理

## 確認問題

<details>
<summary>【○×】破産管財人は、個人破産の免責許可の判断について、裁判所に意見を述べる職務を負う。</summary>

**答え：○**
裁判所は免責不許可事由の有無等について管財人に調査をさせ、意見を提出させることができます（250条）。実務では管財人の免責意見が判断を事実上左右します。
</details>

<details>
<summary>【○×】破産者は、債権者集会への出頭を申立代理人に委ねることができ、本人が出頭する必要はない。</summary>

**答え：×**
破産者本人には説明義務（40条）があり、債権者集会への出頭・説明は本人の義務です。代理人の同行は補助であって代替ではありません。
</details>

<details>
<summary>【事例】管財人から「破産者の母名義の口座に毎月3万円の振込みがある。説明されたい」との照会が来た。対応の手順を述べよ。</summary>

**解答例**
①直ちに本人から事実関係を聴取する（振込の趣旨——母への生活費援助か、母名義口座への財産移転〔隠匿〕か、借入金の返済〔偏頗弁済〕か）。②裏付け資料（母の生活状況、口座の管理者が誰か）を収集する。③聴取結果を整理した報告書を速やかに管財人に提出する。仮に財産移転・偏頗弁済の性格があれば、その旨を含めて正確に報告する——ここで取り繕うと本人の説明義務違反（免責不許可事由）に発展する。申立前の通帳精査でこの振込みを把握し、申立書で先回りして説明しておくのが本来のあるべき処理であった点も、今後の教訓として振り返る。
</details>
