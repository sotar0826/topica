## 文章理解

### 問58

次の文章の要旨として、最も妥当なものはどれか。

> 調べればすぐに答えが手に入る時代になった。わからない言葉は端末で検索すれば数秒で意味が表示され、複雑な手続も画面の指示どおりに進めれば済む。こうした環境は、間違いなく私たちの生活を豊かにした。しかし、答えにたどり着くまでの時間が短くなるにつれて、私たちは「なぜそうなるのか」を考える機会を、少しずつ手放してきたのではないだろうか。
>
> 答えを知っていることと、理解していることは同じではない。理解しているとは、答えに至る筋道を自分でたどり直せること、そして、前提が少し変わったときに答えがどう変わるかを見通せることである。検索で得た答えは、前提が変わった瞬間に役に立たなくなることが多い。
>
> もちろん、すべてを自分の頭で考え直す必要はない。限られた時間を、どこで立ち止まって考えるかを選ぶことこそが重要である。便利な道具に頼る部分と、自分で筋道を確かめる部分とを意識して分けること。それが、情報があふれる時代に考える力を保つための、現実的な方法なのである。

1. 情報を容易に入手できる環境は私たちの生活を豊かにしたので、もはや自分の頭で考える必要はなくなった。
2. 答えを知っていることは理解していることと同じであり、検索で得た答えであっても、前提が変われば応用することができる。
3. 便利な道具はできる限り使わず、すべてを自分の頭で考え直すことが、考える力を保つ唯一の方法である。
4. 便利な道具に頼る部分と自分で筋道を確かめる部分とを意識して分け、立ち止まって考える場面を選ぶことが、考える力を保つために重要である。
5. 検索で得られる答えには誤りが多いため、信頼できる情報源を見分ける能力を身につけることが何より重要である。

<details>
<summary>正解と解説</summary>

**正解：4**

最終段落の「便利な道具に頼る部分と、自分で筋道を確かめる部分とを意識して分けること」が筆者の結論です。

1. 誤り。本文は考える機会を手放すことへの懸念を示しており、逆の内容です。
2. 誤り。本文は、知っていることと理解していることは同じではないとしています。
3. 誤り。「すべてを自分の頭で考え直す必要はない」とする本文と矛盾し、「唯一の方法」も言い過ぎです。
5. 誤り。情報源の信頼性は本文で論じられていません。

関連：[文章理解](/gyoseishoshi/kiso-chishiki/bunsho-rikai/)
</details>

### 問59

次の文章の空欄［　　］に入る文として、最も妥当なものはどれか。

> 規則は、多くの人が同じ状況で同じように行動できるようにするための道具である。規則があるおかげで、私たちは一つひとつの場面で一から判断をやり直さずに済む。［　　］。現実の状況は無数に異なっており、規則を作った時点では想定されていなかった事態が必ず生じるからである。そのため、規則を運用する者には、規則の文言だけでなく、その規則が何のために作られたのかという目的に立ち返って判断することが求められる。

1. だから、規則は一度作れば、どのような場合にも文言どおりに適用すればよい
2. つまり、規則が多ければ多いほど、人々の判断の負担は重くなる
3. たとえば、交通規則は、地域ごとに異なる内容で定められている
4. また、規則を作る者は、その規則を守る者と同じでなければならない
5. しかし、規則はどれほど丁寧に作っても、あらゆる場面を書き尽くすことはできない

<details>
<summary>正解と解説</summary>

**正解：5**

空欄の直後の文が「〜からである」と理由を述べており、その内容（想定されていなかった事態が必ず生じる）は、規則の限界を示しています。空欄には、規則の利点を述べた前の文と逆の方向の内容（逆接）で、直後の理由と対応する文が入ります。

1. 誤り。直後の「想定されていなかった事態が必ず生じる」と矛盾します。
2. 誤り。直後の理由と対応しません。
3. 誤り。例示が入る文脈ではありません。
4. 誤り。本文の論旨と関係がありません。

関連：[文章理解](/gyoseishoshi/kiso-chishiki/bunsho-rikai/)

### 問60

次のア〜オの文を並べ替えて意味の通る文章にする場合、最も妥当な順序はどれか。

- ア　そのため、図書館の価値は、所蔵する本の数だけでは測れなくなっている。
- イ　かつて図書館は、何よりもまず本を保存し、貸し出す場所であった。
- ウ　むしろ、人々が出会い、学び合う「場」を提供できるかどうかが問われているのである。
- エ　しかし、情報の多くがインターネットを通じて手に入るようになり、本を借りるためだけに図書館を訪れる人は減っている。
- オ　実際、近年では講座や交流イベントを開き、地域の拠点として利用者を増やしている図書館も少なくない。

1. イ → ア → エ → オ → ウ
2. エ → イ → ウ → ア → オ
3. イ → エ → ア → ウ → オ
4. イ → エ → オ → ア → ウ
5. エ → ア → イ → ウ → オ

<details>
<summary>正解と解説</summary>

**正解：3**（イ → エ → ア → ウ → オ）

- 「かつて」で始まるイが冒頭になります
- エの「しかし」が、イの過去の図書館像と現在の変化を対比します
- アの「そのため」が、エの変化の結果を述べます
- ウの「むしろ」が、アの「本の数だけでは測れない」を受けて、問われている価値を示します
- オの「実際」が、ウの主張を裏付ける具体例となります
