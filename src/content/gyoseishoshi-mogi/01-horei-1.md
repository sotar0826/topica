## 基礎法学

### 問1

法令用語に関する次の記述のうち、妥当なものはどれか。

1. 法令上「みなす」とされた事項は、反対の証拠を挙げれば覆すことができる。
2. 「A若しくはB又はC」という表現では、AとBとが小さな選択の関係にあり、その組とCとが大きな選択の関係にある。
3. 「10日以上」には、10日は含まれない。
4. 「遅滞なく」は、「直ちに」よりも時間的な即時性が強い。
5. 「科する」は、租税を負わせる場合に用いられる。

<details>
<summary>正解と解説</summary>

**正解：2**

1. 誤り。反証によって覆すことができるのは「推定する」です。「みなす」は反証を許しません。
2. 正しい。選択が2段階のときは、小さな選択に「若しくは」、大きな選択に「又は」を用います。
3. 誤り。「以上」は基準となる数を含みます。
4. 誤り。即時性は「直ちに」＞「速やかに」＞「遅滞なく」の順です。
5. 誤り。租税や義務を負わせるのは「課する」、刑罰・制裁を加えるのが「科する」です。

関連：[法令用語](/gyoseishoshi/kiso-hogaku/horei-yougo/)
</details>

### 問2

法の効力と解釈に関する次の記述のうち、妥当でないものはどれか。

1. 法の適用に関する通則法によれば、法律は、法律でこれと異なる施行期日を定めたときを除き、公布の日から起算して20日を経過した日から施行される。
2. 同等の効力を有する法令の内容が抵触する場合には、原則として、後に制定された法令が優先する。
3. 前に制定された特別法と後に制定された一般法とが抵触する場合には、原則として、後の一般法が優先して適用される。
4. 刑罰法規について、被告人に不利益な類推解釈をすることは、罪刑法定主義に反し許されない。
5. 公の秩序又は善良の風俗に反しない慣習は、法令の規定により認められたもの又は法令に規定されていない事項に関するものに限り、法律と同一の効力を有する。

<details>
<summary>正解と解説</summary>

**正解：3**

1. 正しい。通則法2条のとおりです。
2. 正しい。後法優先の原則です。
3. 誤り。前の特別法と後の一般法が抵触する場合は、原則として前の特別法が優先します（後の一般法は前の特別法を改廃しない）。
4. 正しい。類推解釈の禁止は罪刑法定主義の派生原則です。
5. 正しい。通則法3条のとおりです。

関連：[法の分類と法源](/gyoseishoshi/kiso-hogaku/ho-no-bunrui/)・[法の解釈と適用](/gyoseishoshi/kiso-hogaku/ho-no-kaishaku/)
</details>

## 憲法

### 問3

人権の享有主体に関する次の記述のうち、最高裁判所の判例に照らし、妥当なものはどれか。

1. 外国人の在留中の政治活動は憲法上保障されているから、法務大臣が在留期間の更新の際にこれを消極的な事情として考慮することは許されない。
2. 強制加入団体である税理士会が、政党など政治資金規正法上の政治団体に寄付するために会員から特別会費を徴収する旨の決議は、税理士会の目的の範囲内の行為として有効である。
3. 外国人には、我が国に入国する自由が憲法上保障されているが、在留する権利は保障されていない。
4. 会社は、自然人たる国民と同様、国や政党の特定の政策を支持、推進し又は反対するなどの政治的行為をなす自由を有し、政治資金の寄附もその自由の一環である。
5. 憲法第3章の規定は、性質上可能なかぎり内国の法人にも適用されるが、外国人には一切適用されない。

<details>
<summary>正解と解説</summary>

**正解：4**

1. 誤り。マクリーン事件判決は、在留期間中の政治活動を更新の際に消極的な事情として斟酌されないことまでの保障はないとしました。
2. 誤り。南九州税理士会事件判決は、目的の範囲外の行為で無効としました。
3. 誤り。外国人には入国の自由は保障されていません。
4. 正しい。八幡製鉄政治献金事件判決の内容です。
5. 誤り。権利の性質上日本国民のみを対象とするものを除き、外国人にも人権の保障は及びます（権利性質説）。

関連：[人権総論](/gyoseishoshi/kenpo/jinken-soron/)
</details>

### 問4

表現の自由・学問の自由に関する次の記述のうち、最高裁判所の判例に照らし、妥当でないものはどれか。

1. 傍聴人が法廷においてメモを取る自由は、憲法21条1項によって直接保障されている表現の自由そのものであるから、裁判長がこれを制限することは許されない。
2. 検閲とは、行政権が主体となって、思想内容等の表現物を対象とし、その全部又は一部の発表の禁止を目的として、網羅的一般的に、発表前にその内容を審査したうえ、不適当と認めるものの発表を禁止することをいい、税関検査はこれに当たらない。
3. 裁判所による出版物の事前差止めは、検閲には当たらないが、厳格かつ明確な要件のもとにおいてのみ許容される。
4. 報道のための取材の自由は、憲法21条の精神に照らし十分尊重に値するが、公正な刑事裁判の実現のために取材フィルムの提出を命ずることが許される場合がある。
5. 普通教育の教師にも一定の範囲における教授の自由が保障されるが、完全な教授の自由を認めることは許されない。

<details>
<summary>正解と解説</summary>

2. 正しい。税関検査事件判決の内容です。
3. 正しい。北方ジャーナル事件判決の内容です。
4. 正しい。博多駅事件決定の内容です。
5. 正しい。旭川学力テスト事件判決の内容です。

関連：[精神的自由権](/gyoseishoshi/kenpo/seishinteki-jiyu/)

2. イ・エ
3. ウ・オ
4. エ・オ
5. ア・ウ

### 問6

国会に関する次の記述のうち、妥当なものはどれか。

1. 参議院が衆議院の可決した法律案を受け取った後、国会休会中の期間を除いて30日以内に議決しないときは、衆議院の議決が国会の議決となる。
2. 両議院は、各々その総議員の過半数の出席がなければ、議事を開き議決することができない。
3. 予算は、さきに衆議院に提出しなければならないが、条約の承認については、衆議院の先議は要求されていない。
4. 両議院の議員は、院外における現行犯であっても、国会の会期中は逮捕されない。
5. 憲法改正は、各議院の出席議員の3分の2以上の賛成で、国会がこれを発議する。

<details>
<summary>正解と解説</summary>

**正解：3**

1. 誤り。法律案は、60日以内に議決しないとき参議院が否決したものとみなすことができ、衆議院で出席議員の3分の2以上の多数で再可決する必要があります（59条）。
2. 誤り。定足数は総議員の3分の1以上です（56条1項）。
3. 正しい。予算には衆議院の先議権がありますが（60条1項）、条約の承認に準用されるのは60条2項だけです（61条）。
4. 誤り。院外の現行犯は不逮捕特権の例外です（50条、国会法33条）。
5. 誤り。各議院の総議員の3分の2以上の賛成です（96条1項）。

関連：[国会](/gyoseishoshi/kenpo/kokkai/)
</details>

## 行政法

### 問8

行政組織に関する次の記述のうち、妥当なものはどれか。

1. 権限の委任には法律の根拠が必要であり、委任を受けた行政機関は、自己の名と責任においてその権限を行使する。
2. 権限の委任がされた場合であっても、委任をした行政機関は、引き続きその権限を行使することができる。
3. 専決は、行政庁の権限を補助機関に移すものであるから、対外的には補助機関の名で処分が行われる。
4. 諮問機関の答申は、行政庁の意思決定を法的に拘束する。
5. 通達は国民を拘束するものであるから、通達に反する処分は当然に違法となる。

<details>
<summary>正解と解説</summary>

**正解：1**

1. 正しい。委任は権限の所在を移すため法律の根拠が必要で、受任機関が自己の名で行使します。
2. 誤り。委任すると、委任機関は当該権限を失います。
3. 誤り。専決は権限を移さない内部的な事務処理で、対外的には本来の行政庁の名で行われます。
4. 誤り。行政庁を法的に拘束するのは参与機関の議決です。
5. 誤り。通達は行政内部を拘束するにとどまり、国民や裁判所を拘束しません。

関連：[行政組織](/gyoseishoshi/gyoseiho/gyosei-soshiki/)
</details>

### 問9

行政行為に関する次の記述のうち、妥当なものはどれか。

1. 農地法3条の許可は講学上の許可に当たるから、この許可を受けずにした農地の売買契約も、私法上は有効である。
2. 違法な行政処分によって損害を受けた者が国家賠償を請求するには、あらかじめ当該処分の取消判決を得ておかなければならない。
3. 不可争力が生じた行政行為であっても、処分庁が職権でこれを取り消すことは妨げられない。
4. 行政行為の撤回は、成立当初から存在した瑕疵を理由とするものであり、その効果は行政行為の成立時に遡る。
5. 判例によれば、授益的行政行為の撤回をするには、常に法律の明文の根拠が必要である。

<details>
<summary>正解と解説</summary>

**正解：3**

1. 誤り。農地法3条の許可は講学上の認可であり、許可を受けない売買は効力を生じません。
2. 誤り。判例は、あらかじめ取消しや無効確認の判決を得る必要はないとしています。
3. 正しい。不可争力は相手方からの争いを封じるだけです。
4. 誤り。それは職権取消しの説明です。撤回は後発的事情を理由とし、将来に向かってのみ効力を失わせます。
5. 誤り。実子あっせん指定医師取消事件判決は、明文の規定がなくても撤回できるとしました。

関連：[行政行為](/gyoseishoshi/gyoseiho/gyosei-koi/)
</details>

### 問11

4. 誤り。執行罰は刑罰ではなく、義務が履行されるまで繰り返し科すことができます。

### 問13

行政手続法に定める申請に対する処分に関する次のア〜オの記述のうち、妥当なものはいくつあるか。

- ア　行政庁は、審査基準を定めたときは、行政上特別の支障があるときを除き、これを公にしておかなければならない。

- ウ　行政庁は、申請がその事務所に到達したときは遅滞なく当該申請の審査を開始しなければならない。
- エ　行政庁は、申請により求められた許認可等を拒否する処分を書面でするときは、その理由も書面により示さなければならない。
- オ　行政庁は、申請者以外の者の利害を考慮すべきことが当該法令において許認可等の要件とされている処分を行う場合には、公聴会を開催しなければならない。

1. 一つ
2. 二つ
3. 三つ
4. 四つ
5. 五つ

<details>
<summary>正解と解説</summary>

**正解：3**（ア・ウ・エの三つ）

- ア　正しい。5条3項のとおりです。
- イ　誤り。標準処理期間を定めることは努力義務です（6条）。
- ウ　正しい。7条のとおりです。
- エ　正しい。8条2項のとおりです。
- オ　誤り。公聴会の開催等により意見を聴く機会を設けるよう努めなければならないという努力義務です（10条）。

行政事件訴訟の類型及び審査請求との関係に関する次の記述のうち、妥当なものはどれか。

2. 処分の取消しの訴えとその処分についての審査請求を棄却した裁決の取消しの訴えとを提起することができる場合には、裁決の取消しの訴えにおいても、処分の違法を理由として取消しを求めることができる。

### 問20

取消訴訟の審理及び判決に関する次の記述のうち、妥当なものはどれか。

1. 取消訴訟においては、裁判所は、職権で証拠調べをすることはできない。
2. 事情判決は、無効等確認訴訟においてもすることができる。
3. 取消訴訟においては、自己の法律上の利益に関係のない違法を理由として取消しを求めることもできる。
